## 观测结论

**已观测：在1%的五领域持续学习序列中，CL-MoE在任务刚学完时的优势，随之后的任务训练而缩小。** 对相同的19个任务、21454道测试题，分别在各任务训练结束时和第19个任务结束时计算五域宏F1。以共享q/v-r8 LoRA减CL-MoE计，OneVision的差距从−1.345变为−0.588点，Qwen2-VL从−1.797变为+0.901点。后续训练带来的相对变化分别为+0.757（配对95%区间[0.283, 1.223]）和+2.698点（[2.211, 3.202]）。共享LoRA分别使用0.541M和1.090M新增参数，CL-MoE使用37.159M和77.930M。医学域的追回最为明显：共享LoRA自身在原题上的F1后续提高6.332和7.222点，CL-MoE对应提高0.711和下降2.027点。这些区间以已训练模型为条件。两种方法的注入层、秩和更新规则均有差异，数据支持方法间的时序差异，参数量的独立因果作用仍待检验。[OneVision逐域对照](summary/parameter_efficiency_retention_20261118/onevision.json) · [Qwen2-VL逐域对照](summary/parameter_efficiency_retention_20261118/qwen.json) · [参数统计](summary/deployment_total_parameters_20261028/ADDED_MODEL_WEIGHT_PARAMETERS_20261030.json)

**已观测：训练预算提高后，动态组合的宏净收益增大，但领域间并不一致。** 相同CL-MoE实现、相同完整21454题TEST及相同TRAIN均值固定参照规则下，1%动态／固定五域宏token F1为42.774／42.689，10%为48.411／47.664；动态收益从0.085增至0.747点。图像簇配对95%区间分别为[−0.075，0.250]和[0.529，0.964]；两档收益差为+0.662点，区间[0.387，0.940]。分域收益变化为自然−0.379、医学+1.467、地理+0.820、金融+1.482、交通−0.078点，不能说所有领域均改善。10%动态全部逐题复现原结果，两臂完整结束并核验。区间条件于两个既有训练检查点，不涵盖训练种子；样本1313→13105与更新93→828同时变化，支持预算关联，尚不能单独归因为样本不足或优化不足。[10%完整对照](summary/pct10_dynamic_fixed_20261116/VERIFIED_PAIRED.json) · [完整配对区间](summary/pct10_dynamic_fixed_20261116/BUDGET_PAIRED_UNCERTAINTY.json) · [预算核对](summary/pct10_dynamic_fixed_20261116/BUDGET_COMPARISON.json) · [实验设计](summary/pct10_dynamic_fixed_20261116/PROTOCOL.md)

**已观测：提高样本预算也改变了医学测试图像的训练曝光，不能将医学增益直接解释为对未见图像的泛化。** 完整21454题的数据审计中，医学222题的图像已在1% TRAIN出现，另外726题的图像在10% TRAIN新增出现，1146题两档均未出现；交通新增4题。自然、地理、金融未发现TRAIN与TEST图像字节相同。地理和金融的动态收益仍分别增加0.820、1.482点，因此同图曝光不能解释全部预算相关增长；自然则下降0.379点，不能称未见图像领域均改善。进一步按全部医学测试题分解，收益总增量1.467点中，两档TRAIN均未见图像的题目贡献0.988点，10%新增曝光题目贡献0.296点，1%已曝光题目贡献0.182点；增益没有主要集中在新增同图曝光题目上。这是描述性分解，不是因果中介比例。[完整分数分解](summary/budget_matched_20261117/IMAGE_EXPOSURE_READOUT.json) 此处只核图像字节相同，不证明测试答案被用于训练，也不覆盖变换后的近重复图像。[完整图像曝光审计](summary/budget_matched_20261117/IMAGE_EXPOSURE_AUDIT.json)

**已观测：跨域降低动态额外收益，没有在两次预定训练重复中复现。** 采用既有图像曝光控制数据，每组1280条TRAIN、80次更新，目标任务完整228题TEST。动态减均匀固定的同域／跨域收益：seed42为1.974／0.439点，seed43为−0.439／1.974点，seed44为0.219／1.754点；跨域减同域依次为−1.535、+2.412、+1.535点，对应图像簇95%区间[−4.430，1.266]、[0，5.066]、[−1.948，5.000]。新两次改用TRAIN均值固定参照，收益差仍为正。不能继续将“多领域稳定使动态选择失效”作为已证前提，也不能由此宣称稳定正效应。新两次均从配对一致的初始参数独立训练，原seed42共享第一阶段检查点；种子与主机并未完全分离，不对三个点构造训练总体区间。[全部重复](summary/medical_domain_replication_20261116/REPLICATION_SYNTHESIS.json) · [seed43完整核验](summary/medical_domain_replication_20261116/VERIFIED_seed43.json) · [seed44完整核验](summary/medical_domain_replication_20261116/VERIFIED_seed44.json)

**已观测：旧任务绝对性能下降，与动态选择的额外收益下降是不同问题。** 上述三次训练中，跨域动态F1均低于同域，但其相对固定组合的额外收益没有一致降低。新两次uniform收益差中，X光/X-Ray表达匹配分别贡献0.439／0.219点，其余答案变化分别贡献1.974／1.316点；反转并非全部由这一表达差异贡献，其余答案变化也不等于独立语义准确率。这些结果支持继续研究旧任务能力保持，却不支持把绝对F1下降归因于动态选择特有的失效。[逐题原分数分解](summary/medical_domain_replication_20261116/ANSWER_EFFECT_DECOMPOSITION.json)

**已观测：在已测1%多领域持续学习设置中，动态组合相对固定组合的完整测试净收益较小。** CL-MoE同一检查点、同一专家集合的21454题对照中，动态五域宏token F1为42.774，固定为42.689，相差0.085个百分点；19998题F1相同，动态更好810题，固定更好646题。各领域的收益方向不同，不能将小宏差解释为每域等效。PASs-MoE完整对照为动态46.620、固定46.332，但其固定化包含折叠与精度变化，不能把差异全部归因于路由。[CL完整核验](summary/routing_mechanism_20261104/CL_FULL_VERIFIED.json)

**已观测：跨域动态收益较小的结论依赖固定参照，尚不能直接归结为“多领域使路由失效”。** 在相同1280题训练预算、80次更新的同域／跨域持续学习对照中，共同医学目标任务完整228题TEST上，动态相对均匀固定组合的收益分别为2.193、0.439个百分点；换成各自TRAIN问题上的平均路由权重作为固定组合后，收益分别为0.439、0.658个百分点，排序反转。两种固定系数均未按TEST选择，TRAIN均值也不是最优固定组合。该对照使用LLaVA-OneVision-Qwen2-0.5B、单种子；不能外推到全部领域、算法或数据比例。[完整阶段分数](summary/domain_cl_factorial_20261107/VERIFIED_BD_STAGE_T02.json) · [固定参照敏感性](summary/routing_history_intervention_20261107/EVIDENCE_SYNTHESIS_20261111.json)

**已观测：冻结跨域训练后的专家，重新学习组合能够恢复旧任务表现。** 固定基座及全部晚期专家，用同样256条旧任务TRAIN、64次更新分别学习动态组合与固定组合，完整228题TEST上得到76.754和72.588，动态高4.167个百分点，图像簇配对95%区间为[0.628，7.675]；原动态为71.491。固定组合已明显离开均匀权重，但仍不能称最优固定上界。该结果说明本次原动态表现没有充分体现重新学习组合可以达到的表现；旧TRAIN也可能向路由学习知识，因此不证明专家完整保留旧知识，也不是无回放CL方法成绩。[校准对照](summary/routing_recalibration_followup_20261113/SYNTHESIS.json)

**已识别的局部原因：推理时混入历史平均权重，会压制已校准路由的收益。** 原实现训练时只用当前输入的路由，推理时使用“50%当前路由＋50%历史任务平均权重”。冻结专家及重训后的原结构路由，仅去掉历史项，跨域组完整228题F1从73.684升至76.316，增加2.632个百分点，图像簇配对95%区间为[0.441，4.915]。但同域也有此现象；回到未经校准的原模型，去掉历史混合后，跨域专家更新仍使动态相对均匀固定的收益下降2.193个百分点。因此历史混合是本次校准收益受限的一个原因，尚不足以解释原始跨域收益下降，更不是已证明的多领域特有机制。[历史项干预](summary/routing_history_after_refit_20261113/VERIFIED_PAIRED.json) · [原模型阶段干预](summary/routing_history_expert_stage_20261113/VERIFIED_PAIRED.json)

**已观测：同域任务顺序训练使多个专家路径共同退化，但尚未证实它专门削弱动态选择的额外收益。** 在相同医学领域、完全相同1280条TRAIN与80次更新、相同五个优化器及合并边界下，只改变样本的时序组织。完整医学2094题TEST中，混合顺序／任务顺序的动态F1为59.279／54.576，均匀固定为57.110／52.622；八条单专家路径全部下降3.678–5.203点，说明损失在不使用动态选择的路径中也存在。动态相对固定的收益为2.168／1.954点，变化−0.215，图像簇配对95%区间[−1.307，0.895]，不能说顺序已证明专门损害路由。两组专家共同改善题占改善并集均约89%，这种重叠在同域混合训练中已存在。该全医学结果不能套到共同T02：其完整228题上两组动态F1相同。单种子对照尚不证明跨领域原因或共同退化的具体更新机制。[完整同域时序对照](summary/domain_cl_factorial_20261107/VERIFIED_AB_20261114.json)
