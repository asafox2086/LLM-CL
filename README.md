# 多领域视觉问答持续学习

主实验使用五个领域、19 个任务的 **100% 有效训练数据**。每项任务按原次序训练一轮，共 131,018 道训练题、8,197 次更新。完整测试集含 21,454 道题。两个基座分别为 LLaVA-OneVision-Qwen2-0.5B-OV 和 Qwen2-VL-2B-Instruct。

| 全量训练对照 | 要回答的问题 | 主要指标 |
|---|---|---|
| 共享 q/v-r8 LoRA 与 CL-MoE | 在相同基座、训练样本和更新次数下，增加专家参数能否提高序列末的答题表现？ | 新增参数量、末阶段可训练参数量、任务刚学完与序列结束时的宏 F1 |
| 同一 CL-MoE 的动态组合与固定组合 | 专家训练完成后，按输入改变专家权重能带来多少额外收益？ | 同一完整测试集上的动态减固定宏 F1，以及五个领域各自的差值 |

固定组合在每层使用一组常数权重。系数从冻结后的模型在全部训练题上的实际路由估计，先在每题答案与结束符的预测位置内求均值，再对训练题等权平均。测试使用原生成设置和 token F1，领域内按题平均，五个领域等权。
