# 从干扰与迁移线索出发的容量受限复用诊断

这是待检验的机制实验，不是已发表算法或已证明有效的新方法。实际 GPU 容量结果尚未产生。此前观察到旧自然 LoRA 对其他领域有迁移收益，部分后续训练改变旧任务损失；据此检验“保留旧模块、复用后训练是否有用”，而非预先宣称专业知识不足或模块冗余。

固定 LLaVA-OneVision-Qwen2-0.5B-OV、seed42、确定性默认 SDPA、原1313条1%训练QA、19个原生阶段、每阶段1epoch、rank8/alpha32、有效batch16、原调度器。四个上限分别为1/2/3/5，全部报告实际模块数量，不能按测试成绩挑选上限。每个上限使用独立进程，避免跨上限缓存污染内存比较。

## 只读训练信息的决策

1. 每任务事先按哈希取最多16个当前TRAIN探针；每个已学任务保留最多4个TRAIN探针ID。它们来自同一个1%训练池，原始QA不变，不另建验证集。历史探针用于损失测量，不参与回放SGD；这是额外历史标签访问，必须计入。
2. 从已保留LoRA中，按当前TRAIN探针平均NLL选择起点；没有模块时从固定基座开始。禁止选择当前／未来任务的独立适配器，禁止用测试答案选专家。
3. 从该起点训练一个临时候选，严格只完成当前原始TRAIN的一轮；不额外试多个训练候选。测量候选对当前探针及起点模块所承担旧任务探针的影响。旧任务按任务平均NLL汇总。
4. **仅当当前TRAIN损失下降、旧TRAIN损失上升且仍有容量，才将候选保留为新模块；否则覆盖所选旧模块。** 两个差值阈值预设为0，不按测试结果调节。上限1始终覆盖，必须每阶段权重逐元素复现新的确定性SeqFT参考。任何失败都保留证据并停止，不放宽门槛。

上限约束的是可部署的保留专家池；临时候选／备份和历史checkpoint不作为额外可部署专家使用，但其瞬时内存及磁盘字节仍需报告。每次只加载一个LoRA到GPU，其他专家CPU保存。实际保留LoRA参数为模块数×540672，原型、标签探针ID、额外计算及固定基座分别计量。

## 输入路由与辅助参考分开

对每个已学原生任务，从**全部该任务TRAIN问题和图像**拟合一个固定原型。特征是冻结词嵌入的问题均值与冻结视觉投影特征均值分别归一化，再相加归一化；不训练新的视觉模型。路由只根据问题／图像与已学原型的余弦，取最近原型对应的专家。它是数据拟合的原型路由，不称为已训练的神经路由器。原型数可随任务增加，其内存单列，不能藏在LoRA上限内。

路由特征不读取答案、任务标签、领域标签或额外context。GPU启动门槛会修改这些元数据，检查特征逐元素不变。实际QA前向仍使用所有方法共有的原生任务提示，不能宣称去除了公共实验协议提供的提示信息。

另报告已知任务身份映射的NLL，作为定位路由错误的辅助参考，不能当真实输入路由性能。旧模块强制评测与训练后候选强制评测只测NLL，隔离“复用”与“继续训练”差异；正式输入路由评测保留生成指标。所有推理仅使用当时已经学到的专家与原型。

## 数据、指标与全量确认

- 四上限诊断都使用同一500 QA及新确定性原生实验的155个生成探针。每阶段记录当前原生任务训练前／后输入路由结果、旧模块／候选的强制NLL；最终测全部500题并保留逐题路由记录。不能把辅助已知任务结果并入主成绩。
- 完整测试预先固定为上限1与3：一个严格SeqFT对照和一个中间部署预算，不按容量诊断成绩选优；其余上限只报告诊断结果。两个模型均对全部21454公开标注QA生成作答，不筛除题型或困难例子。
- 全集包括曾查看的500诊断题，因此不能称完全未触及的确认集。同时报告500与其余20954题的分组成绩，全部原始题仍进入全量结果。最终全量评测不能独自提供全量FWT/BWT；不能把诊断传递指标与全量准确率混称同一评测矩阵。

## 事实是否写入成功的额外核验

容量试验前，单独只读检查已有知识试验的checkpoint：评测16条作者事实的原训练问题格式及固定改写。比较原基座、首域LoRA、上下文控制，以及rank1／rank2／rank8知识权重；不追加优化更新。低相关与错配权重另测自己的训练目标，错配目标明确标为合成错误，不能称事实正确率。该核验仅判断事实记忆／格式泛化，不能当医学图文测试或独立专业知识泛化。核验失败会留待处理，独立容量试验仍可继续。

## 后台顺序与证据保存

`llmcl-onevision-capacity.service`使用nohup运行轻量CPU协调器，先等待确定性原生对照完整通过，再等待GPU1确实空闲；不会改动当前研究队列。按事实编码核验→上限1/2/3/5→预定上限1/3全量确认串行运行。每个上限／确认阶段独立进程，保留阶段池权重、原型、任务映射、候选、源代码／数据哈希、逐题输出及原始TRAIN梯度探针。

每次优化loss／真实梯度范数／正学习率、辅助TRAIN读取次数与耗时、原型特征计算、实际模块数、CPU RSS/PSS/USS与GPU allocated/reserved/NVML均记录。前后占用按同PID及进程启动时间取值，避免重启后PID复用导致错误差值；保留全进程峰值。训练后快照在最终推理前取，阶段诊断仍影响整体峰值，不能把缓存保留当参数增长。中断任务从边界重跑，半段优化日志隔离，不拼接不同权重评测。

局限：单seed／原顺序、少量训练探针、按任务拟合原型和离散增长规则都可能不稳定；复制旧模块可能产生高度相似专家。需要实际deltaW与路由误差分析、更多锚／顺序、同计算消融和正式全量结果，才能评价原因与增益。当前不声明提升。
