# 容量参照与论文主张边界：不把大训练空间包装成路由收益

独立审阅：literature_observation；本页记录root接受的范围判断，不启动新对照，不改变已冻结四臂。

目前已证实的是：给定已经训练好的1% PAS检查点，固定末态部署表示的完整五域宏46.331976585，相对teacher下降约0.288pp；总部署893675552神经参数、新增0，并有独立重载和五窗GPU测量。其宏高于all-r8的44.894422831约1.438pp，属于部署质量位置比较，**不能把这段差值归因条件路由或当前拟合目标**。

PAS有两套r128，普通all-r8只r8。相同投影覆盖下，单套r256的A/B坐标数量可匹配两套r128；常数混合的两个低秩更新可由堆叠A、拼接缩放B表示。这是数学参数化关系，不等于两者的初始化、有效scaling、梯度/Adam轨迹、阶段历史正则或最终质量相同。FullFT的参数化与优化也不同，不能当作匹配rank的替代因果控制。

**当前不新增all-r256。** 对“给定已训teacher的后处理功能承接”这一有限命题，最直接对照是同一teacher处理前后，以及固定四臂的相同学生图/同W/同lambda控制。all-r8和FOREVER提供低新增部署参照；FullFT完整结果仍待完成，未测不能算支持。无需为了排除尚未提出的训练最优性主张无限增加实验。

若后续论文要声称“同样允许大的临时训练空间，复杂条件训练后再折叠优于普通训练”，则普通all-r256容量对照成为必要：匹配168投影、A/B总坐标、W0、数据顺序/暴露/主更新数、优化器、dtype，并明确有效LoRA scaling；初始化/参数化不能自动视为等价。该对照只是排除容量解释，不能作为“简单扩容”的新方法创新。这里没有授权自动新增协议、run或更改主设置。

这不缩小总目标：最终仍需跨方法、双骨干与1%/10%完整质量和资源证据，公平比较FullFT、FOREVER、可折叠LoRA/OSFT等，提出对别人有用的性质与简单方法。当前单个PAS操作点及固定block先导都不足证明普适性，也未完成研究目标。
