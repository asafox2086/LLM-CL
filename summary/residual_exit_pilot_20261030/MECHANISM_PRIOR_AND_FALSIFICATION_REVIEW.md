# 残差出口pilot：先例、唯一证据缺口与可证伪结论

**结论：固定四臂足够检验一个窄的接口修复机制，无需追加候选。** 关键缺口是：在meanfold已改变的学生残差流上，局部修复能否在拟合外样本传递到最终输出分布。PAS-static的完整F1/单骨干资源已证明一个部署取舍实例；它不证明局部小残差必然端到端保质，也未识别哪个局部目标能修复失真。

## 哪些已有直接先例

- [CrossMean](https://arxiv.org/html/2610.14762v1) §3.3–3.4、Eq2/3已区分学生前缀输入与教师原输入，用前者预测后者的原输出。因此prefix mismatch及跨激活配对不能称本项目首次发现。§5.1/Table14通过改变cross统计的反对称部分做机制消融，再看独立test准确率；不是仅凭局部拟合loss下降断言可部署。
- [RegMean++](https://arxiv.org/html/2508.03121v2) §3.2/Algorithm1已有按深度重测合并前缀；Table6还包含小型Llama3.2-3B低于RegMean的负结果。顺序校正有先例，但不能自动保证本VLM有效。
- [BRECQ](https://arxiv.org/pdf/2102.05426) §3.2/Fig1/Table1已有保留shortcut、按残差block出口重构，并对比layer/block/stage/net粒度的实际验证准确率。局部loss更小不保证校准外效果，以及块内依赖，均非本项目新发现；其Hessian/Fisher近似不是我们任意Euclidean MSE到F1的保证。
- [OneS](https://arxiv.org/pdf/2201.10890) §4.3/Table4分别消融MoE知识聚合与蒸馏，Fig3控制总训练epochs，实际验证dense学生的下游能力。MoE到dense、初始化后再修复已有先例；本项目可主张经验证的CL适配，不能自称首次。

本项目新记录的具体PAS/CL数值及负耦合反例仍是实际证据；域间/域内矩分解本身是已知数学，不能换成新定理。已有方法不否定适配创新，但新颖性应由本场景的事实、控制和结果承担。

## 不能偷换成新性质的代数

实数加法下，教师出口oT=rT+yT、学生出口oS=rS+yS。如果C完美匹配down输出yS=yT，出口差仍为rS−rT。这是残差架构恒等，BRECQ已研究相关shortcut依赖，不是新定理或不可约误差下界：允许yS偏离yT即可补偿skip差，是否能由既有特征/单个W实现必须实测。真实FP16还含两次加法的舍入差；D的目标及实际出口/最终KL读数不能由实数恒等式替代。

## 当前四臂能证明什么

A是不修的meanfold；B/C同teacher down目标，只换Xt/Xs；C/D同Xs、G、lambda、Wprior及更新参数数目，只换down目标/完整残差出口目标。C/D的目标不同，不能以它们各自拟合loss的大小判断哪个更有效；应比较同20条拟合外TRAIN上的实际teacher block误差与完整词表KL。

若D的实际出口误差与最终KL均优于A/C，支持：**此固定block12的meanfold学生已有特征，可以经同一个existing down读出作出口对齐，并把改善传递到最终分布。** 这是固定容量的功能干预证据，不是扩容刷分。若B≈C而D更好，只支持出口目标的作用，不能声称仅换student-prefix输入已解决问题。D相对C还含实际舍入补偿，不能纯归因router或skip的单一原因。

| 完整结果 | 应作出的判断 |
| --- | --- |
| 仅80拟合池变好，20读出不改善 | 否决此固定配方的校准外收益；不调层/lambda救点 |
| D出口误差下降，但KL不胜C和A或反而恶化 | 未打通局部修复到最终分布的关键链路，不支持扩大 |
| C胜B/A而D无额外收益 | 支持prefix配对适配，未支持额外residual-exit目标 |
| D同时满足出口及KL比较 | 接受此固定点existing-feature出口读出性质，仍非全24block/自由生成/F1/全CL普适证明 |

平均KL改善也可能包含共同校准偏移，不能直接称恢复视觉条件判别或模型本来就有全部知识。两种router一致才有本次跨机制支持；单个成功不能抹掉另一个失败。当前已有四臂/逐QA读数足够作上述窄判别，尚不够证明“所有条件知识都可由单骨干无损承载”。本次只读原论文，未改冻结四臂、源码、统计、主表或启动模型。
