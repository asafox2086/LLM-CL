# 独立 FOREVER 图文接入门槛

这里只准入两个 backbone 的非正式 GPU 门槛，不是准入正式训练或填写主表。固定源见 `GPU_GATE_PLAN.json`，首次 GPU 启动后不可热改；失败保留，并以独立新版本修复，不自动重试。

新目录 `exp/two_backbone_forever_20261019_v1` 从 V2 原样复制共同实现；仅新增 FOREVER 方法、1% 入口范围和来源快照。活动 V2 文件一字节不改。相同 manifest、原始 QA、图像面积 401408、缓存 128MiB、FP16 基座／FP32 qv rank8 LoRA、原始 Answer F1、公共主训练一轮／batch16／micro1／floor warmup／cosine。主优化器和 loss scale=1 沿用共同框架。

回放是独立计费的作者机制：原答案类别抽样、24 步模型时间校准、阶段末两轮历史回放、强度 0.5–3、参考参数平方正则及系数 0.001。实际 HF AdamW、5 步 warmup、linear 调度和尾批行为保持并记录，不能宣称所有方法总计算相同。安装 HF 的实际梯度缩放与独立作者类 CPU 控制最终参数完全一致；不悄悄改写其梯度尺度。主训练与辅助回放设置分别报告，不称原作者长轮次实验的完整复现。

1. 仅旧服务器实际空闲 GPU0，已有三条基线 PID/startticks 和日志保全；新机研究及所有基线不动。该卡若被他人占用则门槛失败退出，不能抢卡或自动重试。
2. 依次 LLaVA-OneVision-0.5B、Qwen2-VL-2B。Qwen 在旧卡上只跑接入门槛，正式 Qwen 仍计划新机。共同 preflight 原 19 个 TRAIN 图文前向／反向作为非正式检查；继承的官方图文门槛包含既有 FinMME:5082 TEST 哨兵，不将全进程冒称零 TEST。无 TEST 成绩用于选择设置。
3. 额外用原 T02 一条 TRAIN 做一次正 LR 有限更新，再对历史 T01 作者选择的原 303 条 TRAIN 执行真正的两轮请求回放。记录 HF 实际 QA／更新次数、每次用到的 LR、梯度、参数改变、正则、CPU/GPU 前后及峰值。不把请求两轮等同于一定遍历 606 次，尾批由实际记录确认。
4. 作者 warmup 首步 LR=0 按原实现保留，明确计数；其余必须有正 LR、有限梯度和真实更新。若整个回放无有效更新则拒绝准入。公共 FP16 initial scale=1 的适配在首 backward 前校验，不冒充作者超参数。
5. 保存非正式 method graph，另进程重载检查同一 QA loss／有限反向。预检权重不能进入正式训练，成功后的大预检权重按既有 probe 清理，SHA 与证明保留。

CPU 真实 8 次 HF 更新／128 个合成样本曝光中，7 次正 LR 更新、1 次作者 warmup 零步，所有原始梯度有限；独立编译作者 ReplayTrainer 的最终参数 SHA 与新训练器逐位一致。这是接入证明，不是模型性能实验。第一版校验只因 ID 摘要采用不同编码失败，原代码已留档，改用原 JSON 编码后 303 个 ID 摘要精确一致；发生在 READY 前、无模型/GPU。

正式运行仍需两个 GPU 门槛全部完成，明确结果发布器与来源锁及当前实际硬件可用性，再启动独立正式 run。当前正式已核验仍为 4/14，FOREVER 不计入完成数，不填主表分数。其历史回放只来自冻结 1313 TRAIN，不增加外部数据；作者额外计算和缓冲实际大小均须公开。
