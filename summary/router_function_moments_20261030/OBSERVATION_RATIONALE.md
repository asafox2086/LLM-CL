# 2026-10-30：先识别条件功能，再谈少新增部署

## 已有事实及本轮排除

已有封存聚合表明LLaVA 1%下，Seq/OSFT/PAS的presence刚习得输出高度集中；PAS在2955题只输出同一评分token答案，仍为75.025381 F1。T12是遥感城乡分类，**不是医学**；不能借它声称跨域。T12的OSFT/PAS刚习得各100题同答案、44 F1，Seq为两种答案、64 F1，来自同一旧EVIDENCE；这是重新核查的历史事实，不是本轮新模型发现。回答集中不等于没有语义能力；同分也可能对应不同回答函数。原response_failure_profile的FINDINGS已提醒不追加同类统计，因此本轮停止扩大常答案比例表。

更关键的文献反证：[Chappuis等，The curse of language biases in remote sensing VQA](https://arxiv.org/html/2311.16782v1) §6.3 Table3已对同2955题presence报告75.03%的常答案先验；§6.2的visual-blind、换图等控制比单看常答案更有辨识力。该现象不能独自承担本项目端侧创新点，也不因此改正式数据、提示或评分。

[MC-SMoE，ICLR2024](https://proceedings.iclr.cc/paper_files/paper/2024/file/3d09a88c3372cdb79401fde592ca4db8-Paper-Conference.pdf)研究专家合并后的低维性并以分开的合并/压缩控制检验，不支持仅凭专家银行大就称其冗余。[FOSTER，ECCV2022](https://arxiv.org/pdf/2204.04662)已在非LoRA持续学习中用扩展学习、单骨干压缩；本项目不能把这一框架本身当新性质。

## 当前唯一待观测问题

**实际路由变化是否主要落在专家输出的低敏感方向？** 分别看A能量路由PAS和learned-token+question-anchor路由CL。记录真实路由、全部专家实际输出及联合矩，才能分开“router本来不动”“专家输出相近”“路由与专家差异有特殊耦合”。不以gate均值接近均匀、bank参数多或F1相近代替这些证据。

这回答部署结构是否承载了复杂条件功能的前置问题，尚不是训练动力学结论，不覆盖全部持续学习。最终少的是新增部署参数，训练可全参或临时扩大。普通LoRA/FOREVER、可物化OSFT和零新增PaRSP必须公平比较。

## 为什么这次观测有去留价值

- 原PAS校准只有能量加权gate一阶量，缺少二阶矩；即使常数相同，也可能对应完全不同的路由变化。新观测直接补能辨识的量，而非再拟合一个替换方案。
- 同80历史TRAIN、原S19模型、无TEST/生成/CE/F1/优化更新；CL四臂暂停保持。严格记录全部层，不看结果挑层或改配方。
- 若路由近乎不变，仅记录为有限事实，不能包装深刻普适性质。若两法耦合行为不同，否定共同机制，不靠追加臂救故事。
- 若路由明显变化、专家差异也非零，而真实联合作用远小于解耦参考，才支持此TRAIN范围的函数性质；局部残差小仍不证明端到端质量保持。
- 若均值gate残差大，只否定该均值参考，不否定其它静态表示。任何新压缩方法仍须独立质量/部署测量；本观测不替代它们。

本文件写在新模型观测之前；独立子agent已审查问题、反证条件与统计设计。模型hook/资产绑定尚须独立审查，不把数学sanity或脚本准备当研究成功。
