# 数据预算变化是否改变动态组合收益

在现有10% CL-MoE最终S19检查点上，比较原动态推理与固定有效权重组合。零训练，不改变专家、基座、路由器参数、历史统计、解码或评分器。两臂均评估原19任务完整21454题，报告五域宏token F1及逐域、逐题差异。原动态分支须逐题复现已有10%完整动态预测，否则不能形成正式对比结论。

固定参照沿用1%完整对照的统计定义：同一份预先选定的80道TRAIN题（每域16题，均属于1%且属于10%），使用正确答案teacher forcing，在全部答案及EOS的预测位置读取历史混合后的有效专家权重。题内词元均值、题间等权均值均以FP64计算，再转FP32，不重新归一化。每层一份8维常量，对所有TEST题保持不变。不是uniform，不使用TEST选择权重，不宣称最优固定组合。10%固定权重来自10%模型，不能直接复用1%模型的数值。

每臂先通过已有五道TRAIN的原生成/透传恒等控制。固定臂的均值读取仅在原forward的专家求和前插入一个返回原权重张量的观察回调；使用既有答案输入构造。记录全部168层系数。原训练、评估源码及检查点逐SHA绑定。末态检查模型参数、buffer、锚点及历史权重不变。两臂仅使用实际完全空闲GPU，不设硬运行超时，无自动重试，不重放任何已完成消费者。

预定解释：若10%收益仍小，说明“弱动态收益”至少不局限于现有1%检查点；若明显增大，则支持训练预算相关性。1%与10%同时改变样本数（1313→13105）和主训练更新数（93→828），因此本实验不能单独证明数据量的因果作用。需要出现预算相关信号后，再用等更新预算对照区分样本覆盖与优化不足。两个既有模型均为单种子，不据此声称普遍机制或原论文结论失效。
