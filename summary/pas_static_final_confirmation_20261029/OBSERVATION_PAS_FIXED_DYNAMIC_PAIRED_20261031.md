# 已完成观测：PAS固定部署表示的平均保分，不能等同于逐题不变

在LLaVA、1%训练、完整五域19任务的21454条TEST上，对同一已训练PAS的原动态表示与已冻结静态部署表示进行配对。只读取两套已完整核验的原逐题token_f1，不重新生成或评分；两边38份原输出SHA、ID、答案参照、次序、题数与生成上限闭合，各任务原生顺序求和与原19格精确一致。此处静态表示包含固定混合、专家折叠与FP16物化，因而比较的是整个部署配方，不是单独干预router的因果实验。

**事实一：整体多数题不变，同时存在双向改变。** 21454题中，19095题（89.004%）原token_f1相同；18723题（87.270%）原答案字符串完全相同。静态表示分数更高1104题，原动态表示更高1255题。F1相同不等于答案相同，字符串相同也不等于内部logits或功能完全相同。两方向变化的逐题F1点数分别为+22936.069186与−38062.545751，总和−15126.476565；这是按全部QA汇总的−0.705066pp，不是主指标五域宏。五域宏仍为46.331976585对46.619976395，静态减动态−0.287999811pp；无事后等效阈值、统计显著或多seed保证。

**事实二：平均接近的形成方式在域之间不同。** 自然、医学、遥感和金融分别有98.28%、95.22%、96.18%、98.93%的题F1相同；交通只有16.77%相同。交通域有1767/2123题（83.23%）F1改变，两个方向的题数882与885接近，正负F1点数+4224.703137与−3998.023254大幅抵消，最终静态仅高0.106773pp。因此，总样本多数不变和局部广泛变化后抵消这两种现象同时存在，不能把小宏净差写成动态选择对每题几乎没有作用。遥感的原动态优势为1.519392pp，其中静态更高115题、动态更高267题；平均保分没有保证各域保分。
