# 固定删图后的回答监督：普通回放还是教师软目标

本项检验一个有限问题：同一已学习函数删去同一批 FFN 后，在相同紧凑图、memory、学生训练预算下，教师回答分布是否比金答案 CE 更能保住最终回答功能。它是 post-stream 压缩组件的必要性对照，不是在线紧凑持续学习框架，不承诺成功。

## 问题与依据

已完成证据：完整 wide-q/v 父模型宏 F1 43.791987409；无恢复物理删除固定 8 个 FFN 后宏 F1 19.620168，所有域下降。37 FIT 的联合 NLL 损伤大于单删损伤和；该差额包含 NLL 非线性，不能唯一归因于隐藏轨迹相互作用。此前若干局部特征拟合降低误差却未保住全图 QA，不能据此断言回答蒸馏一定有效或所有低秩都无效。

借用已有预测层蒸馏工具：[TinyBERT](https://aclanthology.org/2020.findings-emnlp.372/)、[Distil-Whisper](https://arxiv.org/abs/2311.00430)。已有先例不作为创新；本项只判断在本受损函数和有限回放预算下是否保留教师软目标组件。

**旧关闭边界的明确窄修订**：旧 direct-delete / joint-effect 的无恢复结果继续作为终态，不续旧进程或 CP，不改旧源。这里确实对同一个受损函数增加恢复更新，不能因新目录或 fresh 进程称其不是恢复。当前人类重新授权有理由的研究，并要求子 agent 评判；两位评判均认可只有 CE 对照的教师信息必要性问题值得做。仅修订这一固定对照，不授权 rank、删层数、memory、步数、LR、温度或 λ 搜索，也不恢复其它关闭分支。规则 029 的精度研究禁令保持，未启动量化模型。

## 两臂与固定数据

- 父：原合法 S19 wide-q/v 完整静态 FP16 包；其 1213 FIT / 87 更新历史成本公开。固定删除 `[2,5,13,16,17,18,20,21]`；末图必须恰为 789080096 个完整权重系数 / 1578160192 权重 bytes。所有注意力、完整视觉、其余 16 个 FFN 保留。
- 从同一实际 pruned 静态包独立严格重载，核对原完整 digest / layout。相同初始化、顺序及 RNG；剩余 144 个语言 Linear（96 attention + 48 FFN）r8、alpha32、dropout0.1，共 3293184 FP32 坐标，B 全零。只训练适配器，最后合并并物理移除。
- 各域原 FIT 按 `SHA256('response-memory-20261025:'+id)` 取最小 32 个 QA，共 160；同域跨任务汇总、hash 平局按 id。此规则可在流中以每域 bottom-k 保留，不依赖 DEV、TEST、教师损伤或未来答案质量。本次从既有 FIT 按规则事后重建，不声称原父训练实际维护过该 memory。报告实际任务及图片组数，不把 160 QA 称独立图片数。
- memory 采用域顺序 natural、medical、geography、finance、traffic 的 round-robin；每域内部上述 hash 顺序。完全相同顺序遍历两遍，320 QA forward/backward，microbatch1、累计16，恰 20 次优化器更新。无额外数据、增强、伪答案或训练内 DEV。
- CE：每个 QA 的 gold 答案预测位置 CE，目标截断 512 tokens 后含 EOS；先 token 均值，再 QA 等权。
- KD：`(CE + KL(P_teacher || P_student))/2`，T1 / λ1。KL 对词表求和、答案 token 均值、QA 等权。归一化使总预测项系数同为 1；无需第三臂。teacher eval/no_dropout，相同 gold prefix、位置、目标及 EOS；缓存最终 norm 后真正送入原冻结 lm_head 的 hidden。
- GPU AdamW，lr1e-4、betas(0.9,0.999)、eps1e-8、weight_decay0.01、clip1，20 步 cosine，无 warmup；第 k 步使用 `1e-4*(1+cos(pi*k/20))/2`，k=0..19，均正。新恢复阶段无 stage reset；不称继承旧 CPU optimizer 的逐值算术。

## GPU 与计费

只用 OLD 真正空卡；NEW 不新增 GPU 作业，基线和他人进程保全。两臂学生串行使用同一 OLD GPU；KD 的冻结教师与缓存使用另一 OLD 空卡。不向已有 GPU 进程发信号。

教师 160 次 decoder prefix forward 一次捕获，hidden 真正 clone slice，不保留整前缀 storage；上界 160×513×896×2=147087360 bytes，不含模型及临时值，绝不称进程内存上限。KD 重放两遍需 320 次教师 head forward，逐 QA logits / 分布只临时存在。CE 无教师调用，故两臂学生更新相同、总计算不同。教师训练、925 次原删图选择 NLL、160 memory、额外恢复、缓存、教师 head、保存/重载、评价全部单列，不能叫同 87 步或免教师。

所有新模型前向、反向、优化器、合并和必要小图检查都用 GPU。CPU 只做文件/张量 I/O、哈希、解析、评分与统计。适配器参数 FP32、基座 FP16，沿用原 SeqLinear 与外层 CUDA autocast；不把 FP32 参数存储误称全 FP32 适配器计算。合并在 GPU FP32，显式禁 autocast、TF32，转回 FP16。此为两臂共同新算术，不能假称与历史 CPU 合并逐值一致。最终回答来自实际新合并图。

固定 phase 上限：CE train 1200 秒、KD train 1800 秒、各独立 eval 450 秒，总 3900 模型秒；从各自首次 STARTED 计，包括模型加载、数据准备、缓存、训练、合并、物理保存与必要摘要。必要的一次 GPU synthetic 算子检查单列成本，0 真实 QA。首次真实模型故障/超时/中断关闭本固定条件，不续 CP、加时间或自动版本；不读 partial 质量来选条件。

## 完整评价与行动出口

两臂各独立 fresh 严格重载最终物理包，100 个原已探索 DEV greedy 原 cap 生成，另 5 个原 hash-min 同输入、固定 32 新 token GPU 资源窗口，共 210 新生成 / 200 新 F1。无 TEST、额外 NLL 或训练内评估。只在两臂全部退出、完整证明通过后调用唯一原 token-F1 评分。父 / 未恢复各 100 条只按原 VERIFIED、实际模型 digest、逐 ID 输入和源绑定复制原标量，不重生成/评分。

每臂记录全图权重与普通 buffers、实际部署包 bytes、GPU allocated/reserved 峰、精确输入与生成长度。仅将固定 matched 推理窗口比较部署 GPU 内存；全流程峰、RSS、训练缓存、教师内存另列，不混作推理优势，不声称速度。

保留组件必须：完整性与物理减重通过、实际包更小、五个匹配推理峰低于父，且五域点 F1 均不低父。若 CE 达标，优先不保留教师组件；只有 KD 达标且比 CE 宏高才支持保留教师监督进入独立框架评审。两者都达标也优先 CE。两者都未达标则关闭该删图 / memory / 20 步条件；仅超过 19.62 的损坏起点不足以保留。跨 ID/单 seed/已探索 DEV 不称显著、非劣或唯一机制。

最多 11.704% 完整权重与约 193–200 MiB 历史推理显存空间，论文端侧竞争力有限；通过也不是总目标完成。负结果将否定这个有限恢复配方足够承接功能的假说，不否定所有蒸馏或不可恢复性，不追加补救 sweep。
