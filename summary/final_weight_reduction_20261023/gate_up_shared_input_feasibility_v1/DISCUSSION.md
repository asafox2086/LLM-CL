# 主agent与review_next_probe的设计讨论：gate/up共享输入坐标

## 本轮实际做了什么

人类要求主agent与子agent继续沟通，不能只把审阅当一次文件验收。双方就一个具体候选往返讨论：同层gate/up能否不用两套独立输入投影，如何承接原功能，是否值得作为小模型主线。主agent核对当前安装源码、配置默认值和完整权重账；review_next_probe定向读原论文，找直接先例并质疑功能和对照假设。没有模型/张量/谱/QA/新评分/CPU模型准入/GPU。

这次产出是**否决把普通共享投影当新主框架，留下范围更窄的参数必要性问题**；不是新算法或新质量成果。没有恢复旧先导、选择新rank或启动实验。

## 对话怎样改变判断

| 主agent提出/核对 | 子agent反驳或补充 | 双方形成的判断 |
| --- | --- | --- |
| 两分支接收同一个x，候选Wg=FgR、Wu=FuR | 同输入不证明投影冗余；精确保留两线性响应需共同rowspace | 不声称可以无损删一份输入投影，不由形状推实际秩 |
| 候选可能不同于跨层Basis Sharing | SkipCat原文§3.2与附录B已直接共享同层gate/up输入投影；Cat-only也有同压缩率对照，但未单独隔离gate/up | 表示和拼接分解已有直接先例，不能作为原创框架贡献；可作已知工具/未来对照 |
| 同rank比较共享省参数 | 同rank不是同预算；输出维m远大于输入n，共享只省一份k×n | 必须按完整权重比较，不能放大局部收益 |
| 共享R的梯度由门/值两项相加，可能限制新任务学习 | Fg/Fu仍可独立更新，固定R时两支并未被绑死；负梯度内积还依赖坐标与尺度 | 只保留“是否需要分别改变输入子空间”的问题，不把梯度相加当冲突/必要性发现 |
| 想同时做到同功能起点与同最终预算 | 零私有支路仍占参数；削共享秩腾空间可能损伤起点；共同低秩坏起点不是功能承接证据 | 拆开必要性干预与预算优势对照，不宣称两个条件天然同时满足 |

定向原文：[SkipCat §3.2](https://arxiv.org/html/2512.13494v1#S3.SS2)、[附录B](https://arxiv.org/html/2512.13494v1#A2)。论文已经包含同层gate/up共享输入投影，不能以此命名新方法；其语言模型离线校准条件不是本1%图文持续任务的质量保证。这里未把第三方实现当作者代码。

[Basis Sharing v1 §3.1–3.2](https://arxiv.org/html/2410.03765v1)主要分析跨层共享；它不是“同层方案没有先例”的依据。找到SkipCat后停止扩展泛读，不重复检索填时间。

## 真实计算图与功能边界

当前Qwen2MLP源码为h(x)=Wd[SiLU(Wg x)⊙(Wu x)]，三个线性层无bias。模型配置未显式写hidden_act，当前Qwen2Config默认silu；源码/config SHA见EVIDENCE。这里解析源码，没有实例化模型，也不倒称所有历史包已逐字节封存。

共享候选为h_s(x)=Wd[SiLU(Fg R x)⊙(Fu R x)]。

- 若要求两条线性分支对所有输入精确保留，堆叠[Wg;Wu]的行空间须包含于R的行空间。这不是实际矩阵秩的观测，也不是非线性整体功能的必要秩。
- 更弱的整体条件涉及h对ker(R)中方向的全局不变性。局部Jacobian低秩或个别输入误差小不保证所有回答功能保留；残差主干的x仍存在，不能把MLP分支限制误写为整个残差层失去x。
- 对共享R，两个输出因子Fg/Fu可以分别适应；共同约束落在可用输入子空间。不能把“共用一个R”描述成全部门/值学习被绑死。
- 写出R的两项梯度只是静态链式法则。没有真实冲突证据，也没有从局部内积到原Answer F1的因果证据；不能据此自动分配私有rank。

## 完整成本限制改变了候选定位

当前形状n=896、m=4864、24层；原完整模型893675552是既有锚，不重读权重头或张量计数。

共享每层P_s=k(2m+n)=10624k；两独立同秩P_i=2r(m+n)=11520r。相同预算可取k=90t、r=83t，不能同rank后把多出的容量当机制优势。

同rank共享相对两套因子仅少7.7778%的局部系数；它不是整模减重百分比。对于非冗余k≤n，单靠少存一份输入因子，24层最多相差19267584系数，约原整模2.156%；这是对两个因子化表示的差，不是对原稠密结构的净减重，满秩因子化可能更大。

gate/up全部原权重209190912，占整模23.4079%。即使将两支全部删除仍剩684484640、即原模型76.5921%；因此只动它们无法达到旧先导25%整模减重成本点。25%并非人类给定的新硬门槛，不能以这个边界否定所有较小收益；它说明这只能是局部组成，不能宣称已经闭合轻量主框架。实际rank、质量、内存和速度均未测。

## 保留的唯一问题与两个不同对照

未解决问题：**在物理压缩模型中，新任务是否确需让gate/up分别改变输入子空间，还是共享输入子空间加独立输出系数已足够？** 这是参数必要性问题，与离线拼接SVD不同，但“换到1%数据”本身不自动构成新颖性。

1. **必要性干预。** 给独立结构复制Rg=Ru=R，从相同Fg/Fu/R出发可保持初始有效分支矩阵相同，研究共享与独立输入子空间更新的区别。独立结构多保存一份R，必须如实计费；它能分辨参数必要性，却不能冒充同预算优越性。浮点执行路径是否等同仍需未来必要实现门槛，静态相等不保证实际逐值相同。
2. **规模—质量主张。** 若主张某结构在相同完整预算下更好，另需按总参数匹配的独立表示对照。不能假定各自SVD起点同功能。共同可表示父函数、预分配零输出列只是构造线索：零列计全部参数，初始Jacobian差异公开，共同坏起点不能证明预训练功能已承接。

两类目的不能混为一个“完全公平”的对照。当前没有合法且功能足够的共同父模型证据，也没有闭合共享+私有更新/容量分配规则；不把这些线索写成可执行算法。

## 决定与下一行动边界

- **关闭**“普通gate/up拼接共享投影就是新的轻量主框架”的设计主张，不实现、不进入GPU准入；不恢复r200先导或其他旧负条件。
- **保留但未准入**输入子空间更新必要性问题；若后续无法写出可构造的功能承接、与已有机制的区别、最少对照和足够完整成本价值，就否决该机制，不靠新增rank/LR/文档维持分支。
- 没有新参数组可记作“已证无用”；共享/私有参数是否需要仍未被实验回答。科学贡献可来自严谨的删除/替代发现，但不能由公式、先例或命名代替证据。
- 总科研目标仍未实现。本轮实际避免了把直接已有方案误当新框架、以及把局部因子省量误当整模优势；它不是新的轻量或F1成果。
