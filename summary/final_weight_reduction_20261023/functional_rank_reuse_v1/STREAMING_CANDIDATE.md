# 历史响应信息怎样有界维护：成对流式摘要候选

状态：对下一项具体缺口的可执行候选定义，无代码/模型/数值测试/新实验准入。不是已通过审阅的性能方法。Frequent Directions和功能正则本身均已有先例。

## 为什么不直接不断更新Q/Y

硬约束算子需要给定且相容的WQ=Y。若每阶段简单按当前W重写Y，已经遗忘的响应会被当作新目标；若保留不同时期的成对响应，它们可能互不相容，硬约束可能无解。将所有历史信息截成少数Q也会舍弃保护方向。因此不能把“用FD更新Q”一句话当完整机制。

这里另定义软响应拟合候选，改变的是优化目标；DERIVATION/GLOBAL_BUDGET的硬约束公式及其最优性不能直接挪过来。

## 数据流与目标时刻

在任务t的当前FIT训练结束后、压缩归并前，将此时临时候选模型冻结，以eval/no_grad进行一次仅本任务FIT的响应采集，避免把训练dropout的不同随机实现混为一个固定目标。每个被替换线性层，记录相同前向中的输入x与该线性层输出y=T_t x（进入SiLU/gating等后续算子之前）。只取原supervised answer token位置；不抽取/改写答案，不改变评价。是否这个局部范围足以约束多模态功能是待推翻假说。实际FP16因子运算的舍入不必等价于某个先稠密重构后相乘的结果，代数式只描述理想线性映射；不得用它声称采集值FP16严格重构相等。

这条采集定义只适用于有对应语言token位置的语言侧线性层，不适用于视觉塔patch位置。它没有选择实际被替换模块，也不自动授权压缩视觉；若要扩展视觉，必须另定义合法位置与计费，不能假设同一answer mask可直接覆盖。最终完整模型预算仍包括全部视觉权重。

这次采集是额外前向和数据曝光，必须计费，不称原87次更新就同计算预算。它没有额外正式teacher：临时候选本身仅见过截至t的FIT，没有DEV训练；不读取未来任务，不使用历史原QA/图像回放。采集后只保留规定摘要，不保留原样本。历史原始响应的采集时刻与定义不因后来W变化而静默重写，但FD保留的是合成行，对其联合二阶量仅作近似，不能说逐条旧目标数值仍被精确保存。

上述y=T_t x针对线性权重部分；若模块有保留不训练的偏置，采集时必须扣除该偏置。若偏置也要学习，需显式扩展输入常数维并计入参数/保护条件，不能将带偏置输出误称成该线性公式。本文尚未选择实际模块。

每个任务先建立一个本任务摘要，再按该任务有效位置数N_t的平方根缩放后并入累计摘要；得到各原生阶段均方损失的等权之和，而不是按token多的阶段支配。固定λ时，这个历史正则相对β会随阶段数量累积；若将来选阶段平均，必须显式除以已见阶段数t或令相应λ_t=λ_base/t，不能默默混用。这些口径都不是五域QA宏评价，也不证明语义重要性。N_t=0须作为未定义条件停止，不默默设成1。

## 联合输入—响应摘要

将每个成对观测写成行zᵀ=[xᵀ,yᵀ]，对列维数n+m的联合矩阵做有界行摘要S=[S_x,S_y]，而非只存输入协方差。容量1≤s<n+m事前固定，最多2s行缓冲；满时做薄SVD，取δ=σ_(s+1)²，保留前s个平方奇异值各减δ的非负根及其右奇异向量，累计收缩标量Δ。任务结束或摘要合并时，若实际缓冲行数大于s而未满2s，也执行同一收缩并将δ计账；至多s行则直接保留。退化不足s+1个非零值则δ=0。任务摘要的Δ也按1/N_t缩放后与历史Δ和合并时收缩相加。

输入与输出单位直接拼接会影响摘要优先级；归一化规则尚未选定，不能按DEV调整。理论部分只针对按明确缩放后的行矩阵A，不自动适用于其他归一化。

该收缩每次满足0≤AᵀA−SᵀS≤ΔI（精确算术，按更新累计/合并）。因此对任意线性W，记历史代理损失L_A(W)=||A_x Wᵀ−A_y||_F²，摘要损失L_S(W)=||S_x Wᵀ−S_y||_F²，则：

    0 ≤ L_A(W)−L_S(W) ≤ Δ (||W||_F²+m).

理由是对C=[Wᵀ;−I_m]，损失差为tr(Cᵀ(AᵀA−SᵀS)C)。这只是给定固定历史局部输入—响应记录的误差证据，可能很松；不是历史QA、F1、上游变化或FP16保证。不能直接把Δ||W||²加到训练目标并声称更好，过强收缩可能使有效映射被压向零。

固定摘要行数只保证记忆尺寸有界，不保证累计Δ或长期误差有界。当前候选不以冻结全部上游来解决漂移；若上游继续学习，它只能被称为旧坐标上的局部代理，不能称全网旧功能保护。当前任务的采集目标还可能已经包含此阶段发生的错误或遗忘，保留更早摘要不会自动修复这些损失。

摘要占用O(s(n+m))系数并含历史信息，必须作为训练记忆明确报告。不得称“无历史记忆”，不得把它藏成免费常量，也不得把它写入Git；即便不含原QA文本也仍是训练数据衍生张量。推理若不需要摘要可不保存到最终模型；若任何路由/检索依赖它，则须计入最终完整权重/辅助状态。

## 有明确解的软归并目标

给定新候选T、固定β>0及λ≥0，考察：

    min_rank(W)≤r β||W−T||_F² + λ||S_x Wᵀ−S_y||_F².

令H=βI+λS_xᵀS_x，J=βT+λS_yᵀS_x，K=J H^(−1/2)。一个最优解是：

    W* = H_r(K) H^(−1/2).

因为展开目标可配方成||WH^(1/2)−JH^(−1/2)||_F²加与W无关常数，H正定且右乘不改变秩。λ=0退回普通截断近似，若最优值随r比较，非r部分常数固定，边际收益为σ_j(K)²。对应全局等成本预算可按这些收益分配，不能继续使用硬约束Z及k的预算地板；软惩罚允许牺牲历史响应，必须报告这种牺牲。

S_x的薄SVD给出H偏离βI的低秩部分，所以H^(−1/2)可通过小基加标量恒等算子作用于因子。若T本来就是低秩加小残差，则J/K也可用薄因子表示。它说明不必在数学上持久保存dense原W，不代表已实现或已测便宜。SVD/统计/临时秩/采集成本、Adam状态如何处理仍须工程与协议准入，本文不做这些。

## 这仍不是已完成的新框架

它补出了历史目标的时刻、记忆更新、舍弃误差与一个明确归并目标，但流式最小二乘、FD、加权低秩近似、功能正则均已知。可能研究价值应由最终完整权重减少与同规模质量/成本比较支持，不能仅因原基座物理删除就宣称组合原创。

尚待判断：局部成对摘要在上游表示变化后是否提供足够有用的保护；首次压缩如何保留预训练能力；摘要容量s/归一化/βλ/全局预算B的固定依据；是否可在1%总探索成本内获益。未定这些不进入模型。当前硬/软两个局部工具不构成自动条件搜索，也不同时启动两个分支；后续应先根据具体功能假说选一个或都关闭。

直接先例：[Frequent Directions原论文](https://arxiv.org/abs/1501.01711)、[Sketched Structural Regularization](https://proceedings.mlr.press/v157/li21b.html)、[Functional Regularisation with Gaussian Processes](https://arxiv.org/abs/1901.11356)。它们分别支持摘要/功能记忆已有先例，不证明本局部压缩目标在多模态持续生成中有效。
