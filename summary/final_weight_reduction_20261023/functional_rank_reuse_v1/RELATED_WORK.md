# 与动态低秩和持续归并先例的边界

本轮定向检查“方向替换/固定秩归并”是否已被研究，服务于具体机制判断。只使用原论文，不将文献结果当本任务F1。

- [Friedland–Torokhti，Generalized Rank-Constrained Matrix Approximations](https://arxiv.org/html/math/0603674)，经典广义Frobenius秩约束近似。本文局部算子按输入/输出正交分解后归结到截断SVD，不作为新数学贡献；本文没有声称逐式等同于该论文某一定理。
- [GeoLoRA v1，2410.18720](https://arxiv.org/html/2410.18720v1)，利用动态低秩几何调整适配器空间，含增广/截断。方向动态变化与秩预算分配本身不新，其训练适配器参数少不能直接代替最终完整基座压缩。
- [CoSO v1，2505.11816](https://arxiv.org/html/2505.11816v1)，梯度驱动的连续子空间、历史方向正交约束与Frequent Directions。仅加入在线方向统计或换学习子空间不足以构成新框架；这些不是原基座权重可删的证明。
- [NSR v1，2606.30067](https://arxiv.org/html/2606.30067v1)，冻结ResNet-18、压缩/检索历史LoRA bank，分开分析bank和分配策略。不能把SVD归并/子空间记忆管理本身称新；其bank及原骨干成本应完整计入，与物理替换整个稠密矩阵不同。
- [ReCoLoRA v1，2607.07719](https://arxiv.org/html/2607.07719v1)，从已吸收历史的有效权重重新分解为冻结残差、慢主成分和新适配器。每阶段重分解/再开塑性空间已存在；保留稠密残差不满足本最终完整权重下降要求。
- [Geo-LoRA v1，2608.26960](https://arxiv.org/html/2608.26960v1)，共享和任务分支子空间演化约束，与上面的GeoLoRA是不同论文。几何轨迹、主/残余分解和投影保护也不能单独宣称新颖；其LoRA参数高效结论不是本小模型质量保证。

结论：具体候选算子现在比“共享+保护”口号更明确，但没有查重依据可宣称原创框架。它提供一个可分析的固定最终秩约束，并暴露旧功能保持与新方向需求的冲突；是否能成为有实际价值的框架核心仍待独立判断。
