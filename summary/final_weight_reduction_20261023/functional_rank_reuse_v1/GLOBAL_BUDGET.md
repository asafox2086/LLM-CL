# 从单矩阵算子到完整权重预算：跨层分配秩，而非共享稠密基

范围：继续补齐本次独立审阅指出的“局部解是否属于整个模型参数集合”缺口。只做符号分析，无模型实验、数值矩阵测试、实际参数重数或F1。它是待判断的候选规则，不是已证明原创/有效的框架。

## 表示选择必须明确

本候选分支明确采用独立物理低秩因子W_l=F_lG_lᵀ；不保留framework_design_v1中的跨层共享D_g约束。共享的是一份全局权重预算，不是同一权重张量。若将来恢复共享字典，必须重新解决耦合，不能沿用本文局部最优结论。

所有未替换的视觉/语言/连接器/偏置等完整权重合计记P_fixed；只计真正删除原稠密W后的F_l/G_l。最终模型约束是：

    P_total = P_fixed + Σ_l c_l r_l ≤ B,
    c_l = m_l+n_l.

B是全部最终模型权重上限，不是只给adapter的预算；本次不选B或矩阵位置，不由参数大就决定删。纯FFN替换无法缩减视觉塔等P_fixed，整个模型的可缩幅度也受它限制。

## 从旧响应要求得到硬可行性门槛

每个矩阵给定Q_l/Y_l，k_l=rank(Y_l)。必须r_l≥k_l。因此至少要求：

    B ≥ P_fixed + Σ_l c_l k_l.

若不满足，不可能同时精确保留这些局部旧响应与该最终规模。必须报告冲突；不暗中删Q、放宽保护、扩大B或把冻结高基移到buffer后漏算。对这里彼此独立的矩阵约束，此条件也足以保证代数可行（各矩阵取Y_l Q_lᵀ）；它不保证质量，不代表已经知道真实旧知识需要多少秩。

特别是，若各层历史Q足够丰富，使k_l等于当前r_l，而当前表示已用满B，则全部剩余输出秩为零，跨层分配没有可移动的输出秩。仍能在已有输出方向内改变输入映射，但本规则不能凭空生成额外输出方向。人为把Q设得很小会留下自由秩，同时弱化历史功能覆盖；不能将这个设计选择解释成已经证明旧知识只占少数方向。这是进入模型前必须正面解决的保护—塑性冲突。

## 一个完全明确的候选分配规则

对当前有限秩候选T_l，用DERIVATION.md算出：

    Z_l=(I−U_lU_lᵀ)T_l(I−Q_lQ_lᵀ).

可用额外输出秩q_l=r_l−k_l来保留Z_l的前q_l个奇异方向。给定正权重α_l，考虑代理目标：

    min Σ_l α_l [ ||Y_l−T_lQ_l||_F² + Σ_(j>q_l) σ_j(Z_l)² ]
    subject to 0≤q_l≤min(m_l,n_l)−k_l integer,
               Σ_l c_l(k_l+q_l) ≤ B−P_fixed.

这是对“在固定完整权重预算内，从哪里移出/移入一个方向”的明确回答：仅为条件残差中的新增输出方向竞争预算；可复用旧输出空间的输入映射按局部算子保留，不为它重复支付新增输出秩。

一次分配中的Q/Y/T/α必须固定；若它们随分配改变，下述最优性不再直接成立。若全部候选矩阵c_l相同（原语言gate/up/down的相同形状之和满足这一条件），扣除必需k_l后，可用slot数是剩余预算除以c的向下取整；在全体α_lσ_j(Z_l)²中按降序选择最多这些个正收益方向，预算可不用满。每层奇异值本来降序，故可保持每层前缀。并列须事先有保持前缀的确定次序。这恰好最优于上述代理目标；它不是原Answer F1最优。若c_l不同，按收益/成本贪心不保证最优，需处理有前缀约束的离散背包，不把简单排序伪称全局最优。

该规则实际放弃的是未选中方向，其代理损失已经在尾能量中显式计入。不是无损释放秩，也不是证明尾方向无用。α_l尚未设计，统一α_l=1仅有权重Frobenius意义，不能把不同层的原始谱相加就解释为整体功能价值。

## 这与主方法还有多远

候选核心变成“受旧响应约束的方向复用＋完整权重预算内的跨层输出秩竞争”，而不是给OSFT冻结若干参数。原稠密基座被物理替换是必要条件，普通保留W_0的LoRA重分配不满足它。方向增广、谱分配、约束近似都有先例；这一组合是否超出已有方法，需要针对这个准确规则继续审查，当前不称原创。

三个决定性缺口仍阻止模型准入：

1. Q_l/Y_l必须从已到达FIT构造并有界保留，但怎样覆盖多模态旧功能、应否随上游表示漂移更新，尚未解决。新Q覆盖旧Q不足也会遗忘。
2. T_l和α_l必须来自明确、成本可控的优化/功能标准；当前算子只近似T_l，不保证其候选是好学习方向，更不保证QA下降。额外回调、SVD、统计和临时秩全部计费。
3. 初始紧凑表示能否在原1%预算恢复已有能力，没有证据。全局分配公式也不能保证恢复；不能重用见过DEV的正式teacher或未来FIT校准。

## 必要对照的条件化定义

如果这条规则后续通过用途与新颖性判断，最少应区分旧响应约束和跨层分配：相同物理因子初始化/最终预算/候选步规则下，约束开关×跨层分配开关的2×2；先说明如何让关闭条件仍满足相同完整预算，再冻结。额外总代价要可比或完整披露。普通压缩加连续适应是无二者条件；未压缩合法参照提供规模—质量取舍。现在不运行四组，也不沿DEV搜索B/秩/α。

## 行动出口

若该规则只是经典局部算子加已有分配，不能作为新贡献；若无法提出便宜且有功能依据的Q/α，则关闭它作为主框架机制。只有在这些问题得到明确解答、且最少对照能改变研究选择后，才另立实验协议/成本出口。本文不授权GPU、原因子pilot激活、旧PAS/ShortFixed恢复或完整1313/21454。
