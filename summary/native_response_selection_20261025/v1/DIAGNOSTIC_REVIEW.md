# S1响应尺度诊断：必要性与解释边界

结论：接受这一次固定GPU前置诊断的必要性，只接受“检查拟用信号是否退化、固定后续静态尺度”的用途。不据此准入训练，不把非零gate、源码通过或统计完成记成回答功能收益。本文不授权恢复旧单臂能量beta点。

当前拟比较复用原FFN响应的动态调制与同尺度静态调制。先确认原真实图上存在所需信号，比写完两条训练流后才发现信号恒定更合理；本次观测可以事前终止退化的固定设计。偶/奇分组本身没有专业语义证明，非零和非恒定也很容易由一般通道差异产生，所以该诊断仅排除实施退化，不证明选择了有效知识。

固定fresh未适应OneVision、原384图像policy、32个仅S1合法FIT组的固定哈希代表。每QA只在原answer_loss真实答案预测位置[prompt_len−1,total_len−2]均匀取至多64点，避免大量图像前缀位置支配尺度。每QA调用原answer_loss一次，完整decoder实际前向：合计32次语言NLL请求，0生成、0反向、0更新、0DEV/TEST。不能写成“0decoder”或“只读权重统计”。加载、原图处理、全部视觉/语言计算、hooks、摘要和退出计入首次STARTED后的600秒；未完成与失败仍保留成本。

Gx及phi、h、h_diff的实际dtype、采样位置/数量、输入SHA、组和QA绑定必须保留；不能从参数FP16或autocast设置推断输出dtype。统计显式GPUFP32，hook只旁路读取，不返回替换张量、不改变原前向，不能为取得信号而轮流改变分组、位置、epsilon或dtype。完整预训练state和全部buffers开始/结束一致是有效性要求，而不是科研结论。

接受额外在选中phi上计算h_diff=D(sign⊙phi)，以及d*h_diff相对原h的QA等权二阶量。这可以排除“gate非恒定但实际拟用输出修正为零”的退化，比只读gate方差更有意义。它仍是额外GPU矩阵计算：应披露相应Down调用/位置数量并计入600秒，不能称免费或0额外计算。Down hook内不能再次调用同一hooked模块而引起递归；可读取同一冻结权重作functional linear，并核原down bias条件。原回答路径仍使用未改h，不能把旁路修正加入原前向。

设第q个QA在第l层采样n_q个位置，d_qp=(s0-s1)/(s0+s1+1e-8)。应先对该QA位置求均值，再对32个QA等权：

- m_l = mean_q(mean_p(d_qp))。
- r2_l = mean_q(mean_p(d_qp²))，c_l = sqrt(r2_l)。
- v_l = r2_l - m_l²；固定精度下的微小负舍入处理须公开，不能据它调整设计。

不能将不同长度QA的所有位置直接汇总而多给长QA权重。“完全常数”应针对每层全部被采样QA×位置的d，不只是32个QA平均值相同。当前源码直接合并同批d的min/max判断是否有实际范围，避免把FP32二阶矩相减的微正方差当成非恒定证据。有限32组仅描述这次采样支持，不证明以后输入也恒定或永远变化。

预定关闭规则可以保守执行，但要准确命名：某层RMS为0只证明该层的拟用尺度退化，不数学证明其它层的动态信号不可识别；关闭整个24层固定方案是设计上的保守退出。若每一层在全部采样位置均为常数，则本支持上没有可由输入变化识别的动态成分。若常数为负，而静态c取正，二者仍会因符号不同而异；不能把这种差异称为动态性。

RMS匹配的不足必须保留到后续成对协议：

1. c_l²只匹配E[d²]，不匹配E[d]、符号、方差、稀有幅度或与隐藏输入/梯度的相关性。动态d对正的常数c的比较是整个调制包的净作用，不单独识别“输入相关选择”。
2. 该尺度来自S1的teacher-forced轨迹和所选位置。未来域、参数更新后以及自由生成轨迹的幅度没有被匹配；不能叫全程等尺度或等有效学习率。
3. 新增响应二阶量可以核对输出修正是否非零，当前判据已要求每层E[(d*h_diff)²]>0，而不只分别要求d和h_diff非零。但d的变化仍可能发生在h_diff为零的位置，所以不能据此认定动态与静态的实际修正之差一定非零，更不能证明方向改善loss、beta梯度非零或有限预算可学。RMS(d)与实际修正RMS并不相同：d与h_diff可相关；记录两种响应量正是暴露这个剩余不匹配，不能悄称已匹配修正/梯度规模。后续形式h+beta*d*h_diff、beta参数化/初值和静态控制定义须在结果前固定，不能看32组后选择更有利的形式。
4. 若后续只有动态臂比静态臂稍好，仍须分别公开全部域、完整权重和实际GPU峰；不能由这项诊断推出可以避免有效专家。完整base保留也意味着相对公平fold的OSFT没有自动完整权重优势；是否能替代动态专家须靠后续质量—成本实证。

5. 后续静态分支若折叠、动态分支若显式运行，FP16舍入和算术路径也会不同。主功能对照可让两者同显式形式，或如实解释为整包净比较；不由本诊断自动新增第三训练臂。

本诊断只可决定退化关闭或保留一个已固定的成对功能问题。通过不保证保质、不允许自动搜分组/尺度/位置/数据或扩充训练；失败也不否定所有原生响应复用。当前审阅仅文档与静态推理，没有运行模型、Torch、QA、评分、远程或新门。
