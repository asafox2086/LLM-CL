# 任务方向对照在Adam下检验什么

这是一条按实际优化器写出的代数说明，不是新理论、实验观测或已找到失败根因。原局部协议的“A方向信息”保持，不修改已冻结源、指标门或实验条件。

本配方新分支为sBA，B初始为0，A的行正交且AAᵀ=κ²I，s=4、κ=1/√3。原AdamW每阶段新建、weight_decay=0。首步A梯度为0，A不变。设H代表实际当前训练批次、实际dropout输入和原归约规则对应的梯度矩阵，则g_B=sHAᵀ；H不能直接替换为eval模式校准得到的G。

设η为该步学习率，c为该臂该步对整个参数梯度统一应用的clip系数（不要求两臂c数值相同）。在理想实数算术、新鲜Adam moment和bias correction下，逐元素有

`B₁ = −η · c g_B / (c |g_B| + ε)`，`ΔW = s B₁ A`。

这不是SGD得到的简单梯度投影。令K=HAᵀ，则

`〈H, ΔW〉 = −sη Σᵢⱼ [c s Kᵢⱼ² / (c s |Kᵢⱼ| + ε)] ≤ 0`。

当clip后的非零梯度远大于ε，内积近似`−sη ||HAᵀ||₁`，并非校准G的Frobenius投影能量。校准/实际训练输入和dropout还不同，因此SVD选到高能量方向既不保证该Adam步更优，也不保证回答F1更高。

由AAᵀ=κ²I可精确得到`||ΔW||F = sκ ||B₁||F`。只有所有out×r个B梯度都非零且clip后远大于ε时，才近似`sηκ√(out·r)`。正交A与相同κ控制了这一区域内的步量；不能据此声称实际两臂更新范数必然完全相同。有限精度、autocast和最终FP16合并还有数值偏离；矩阵范数也不等于实际dropout输入上的输出扰动。

同一子空间内的基旋转也能改变Adam更新。取H=[2,1]，A₁=κI，A₂=κ/√2·[[1,1],[-1,1]]；两者AᵀA相同、span相同。忽略ε时，`sign(HA₁ᵀ)A₁=κ[1,1]`，而`sign(HA₂ᵀ)A₂=κ[√2,0]`。范数相同，方向仍不同。因此当前比较检验任务相关低秩初始化方向/坐标策略的功能价值，不能单独归因于纯投影子空间。

research_review独立复核首步Adam、clip/ε条件、L1内积、范数条件及上述反例，代数接受；明确这些是标准优化器性质，只作方法解释，不能升格为核心发现。核心证据仍须来自同起点、同预算的真实回答前后变化。
