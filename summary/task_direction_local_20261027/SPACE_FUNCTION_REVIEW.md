# 小学习空间与强方法成本：先证功能，再谈替代

可证伪的论文问题是：**固定少量更新时，任务相关的低秩初始化方向／坐标策略，能否用小活动空间取得有竞争力的新习得，并保留单一小部署图？** 不能预设强方法只是用参数弥补适配不足，也不能把更多数据或坐标通常有帮助当核心发现。

## 已有证据包含真正的收益与反例

- 正式1% LLaVA的PAS刚习得五域宏为48.349，Seq为42.026；19任务15高4低，自然反低1.779pp。T18／19的PAS终点更高，但阶段增量更小，说明继承起点与当前学习不能混同。[原全19任务及五域证据](../conditional_shared_budget_20261026/PAS_ACQUISITION_FINDINGS.md)
- OSFT刚习得19任务均分为47.887821，Seq为38.604705；这里不是原主表的最终AP19。实际训练坐标113,766,144对540,672，约210.416倍，同时位置、LR、参数化与保护规则不同。这是值得承接的习得功能，不能把坐标倍数当独立函数维数或收益原因。[原习得审计](../onevision_diagnostics_20261016/osft_acquisition_20261018/RESEARCH_FINDINGS.md)
- 大成本不保证同一种答题功能。相同546道多选，OSFT刚习得F1仍为0，PAS为13.736；单选却是OSFT37.720高于PAS32.823。三法数值题当前阶段均下降。故“更强方法普遍学会更多同类功能”已有反例，不能拿总分代替功能证据。[同题型原分数](../train_answer_prior_20261025/FINANCE_STRONG_ACQUISITION_FINDINGS_20261027.md)
- PAS的多选收益也不等于精准组合：输出长度无3字母，而合法参考有162道3字母；原串匹配75题之外，有176题仅多成员。这不证明其先验或路由导致错误，却反驳“增加专家已普遍解决答案组合”。[全部字面分解与未知](../train_answer_prior_20261025/FINANCE_MULTICHOICE_LITERAL_FINDINGS_20261027.md)

这些是非平凡的功能取舍，支持研究更有效的适配，但没有证明小r8容量充分或大空间冗余。另一个必须保留的反例是七位置LoRA_all正式宏44.894423，仍低于PAS46.619976／OSFT45.937438：简单开放更多位置未完整复制强方法收益；该关闭点不重启。[完整确认](../edge_deployment_20261019/osft_increment_confirmation_20261022/v1/FINDINGS.md)

## “空间”和“内存”须分三本账

活动训练坐标、最终常驻状态、实际GPU峰并不等价。PAS保存态含1,034,446,880个神经权重及336个mask标量；约2.350GB权重／mask字节中还含FP32专家的dtype成本。原同卡五窗峰2490–2959MiB，是实际原实现锚；既有小图约1857–2166MiB的比较不是尚未运行local的测量结果，也不是同dtype最优部署证明。[保存态分解](../conditional_shared_budget_20261026/PAPER_CLAIM_REVIEW_20261026.md) · [PAS原图五窗](../strong_pas_resource_20261025/v1/FINDINGS.md)

OSFT的2757.984MiB保存态不能直接充当不可避免的部署成本：已有常规静态fold证据，普通LoRA与OSFT均可回原稠密形状。不能以普通合并冒称本方法独占结构减重。[已有导出证据的复核](../research_takeover_20261025/TAKEOVER_REVIEW.md)

**540,672只指主optimizer更新坐标，不能说全程始终仅此活动空间。** 校准临时冻结A/B、解冻22,020,096个dense q/v坐标，估计FP32 G共88,080,384 bytes（84MiB），没有optimizer更新。权重临时FP32提升、梯度及clone、SVD还有额外暂存；84MiB只是G载荷，不能当校准总峰。完成后恢复原状态，部署不永久保留G。

| 必须分列的账 | 当前local定义／证据边界 |
| --- | --- |
| 主optimizer空间 | q/v-r8，540,672坐标 |
| 校准暂时反传空间／载荷 | dense q/v 22,020,096坐标；G为84MiB；两臂额外费用匹配 |
| 最终永久权重 | 单dense图893,675,552系数；无常驻A/B、G或SVD分解 |
| GPU实测 | 校准／主训练峰、最终五窗分别报告；不由参数或G字节推算 |

额外反传、加载时间及训练峰也必须计入。前一全课程超时已说明小主更新坐标不等于执行便宜，不能隐去这项成本失败。[固定预算缺测审阅](../task_direction_reuse_20261027/COST_FAILURE_REVIEW.md)

## 当前local对照能搭到哪一段桥

同一真实shared S15经共同fold得到相同W15、相同before回答，再用相同69 FIT／5更新／16校准，只改变任务相关A方向与随机正交A。若aligned改善原20题新习得，支持**该前态、该预算下方向／坐标信息有功能用途**；无收益则不保留该局部点。它不比较强方法、不识别纯span作用，也不能外推五域优势。单题贡献、负贡献与小样本限制必须保留，SVD能量最大不是额外功能证据。[固定局部设计](DESIGN_REVIEW.md)

若未来要支持论文的实际取舍，应在不据TEST调参的完整固定条件中，报告候选自己的五域质量、习得与完整模型／GPU成本，对照同骨干完整PAS、OSFT、Seq结果；用户允许合理质量取舍，不应恢复旧“必须各域胜出”门槛。只复用历史强方法质量可作基准参照，不能消除跨轨迹差异；资源需同卡、同输入窗口，并区分PAS持久银行与OSFT可fold表示。跨骨干全体最强结果也不能隐去。

若坚持更强的因果表述“大空间只是在代替任务适配”，则逻辑上还缺**同前态、同位置／优化规则下，参数预算与方向策略的匹配交叉**：仅比较small-aligned与原PAS，会同时改变位置、LR和专家机制。此交叉即使成立，也只识别该受控参数化内预算与方向的关系，不是所有强方法的根因。它不是当前local的新增臂、准入条件或自动排队建议；不主张这一因果结论时，无须先无限扩基线。

本次只读现有封存报告与固定设计，没有读取新QA、模型、参数载荷或重新评分，没有新增训练。当前最强可守住的故事是“任务适配策略可能改变小空间的功能—成本取舍”，不是“大空间无用”或“已用小空间替代专家”。
