# 首个跨域对照：有完整旧锚差距，尚不能直接归为遗忘

- **探究的问题：** 当任务数、更新数、旧锚直接训练量相同时，替换后续任务为其他领域是否影响旧任务？
- **做的实验：** Organ共同stage1真实A/B和32题输出/NLL精确相同。后续4阶段分别学习同医学Modality/Position/Shape/KG，或自然/遥感/遥感/金融原生任务。两组均5阶段、20更新、40目标QA曝光、旧Organ直接曝光8次；SeqFT无回放/正则/扩容。最终两组均测完整Organ 507题，按158图像配对。
- **结果：** 同域最终F1=34.168，跨四域18.626；跨域−同域为−15.542pp，95%图像区间[−19.429,−11.950]。126题质量下降、24题上升、357不变。辅助NLL差+3.6871，区间[3.4619,3.9082]。
- **证明了什么：** 对本固定序列和已训练模型，后续任务内容/领域组合的替换造成明确旧锚输出质量差距；不能仅用名义任务数或更新次数解释，因为它们保持相同。**尚未证明跨域真正遗忘了共同首阶段能力：完整507题共同S1未测，差距也可能包含同域正迁移缺失。** 专业知识、输出适配、参数干扰的贡献仍未独立分离。
- **改进的方法：** 继续原五域序列/第二锚/全部机制；准备共同S1的507+228题推理参照，参数/输入/评分不改，先要求32题精确重载。跨四域/五域再核验共同前三阶段状态，不只检查S1。新增推理已通过CPU清单/调度检查并进入新队列，尚未执行实际GPU重载/完整评测。
- **改进的效果：** 获得了第一条完整旧锚的显著条件差距，明确补测缺口；未宣布新方法提升或唯一成因。
