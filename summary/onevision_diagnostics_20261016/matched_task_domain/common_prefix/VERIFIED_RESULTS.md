# 共同三阶段后，四域与五域后续序列的完整旧锚对照

2026-10-18新GPU case18正常完成，原独立恢复run完整证明已接受；严格对照13/48，尚未全做完。当前GPU1被其他用户实际进程占用，新固定池试验仍按队列等待，不抢占、不重复启动。前一目标回合属于**进展**：完成并推送学习复用结果/新对照准入，核验恢复基线；本回合进一步接受新case18与首次共同三阶段配对证据，不重复旧CPU统计充数。

## 1. 探究的问题

此前跨域相比同域的差距，是否简单由“更多领域”解释？在已有共同学习历史后，四域序列换成五域序列，旧医学任务是否明显更差？F1不变是否意味着功能不变？

## 2. 做的实验

使用已预先固定的两条SeqFT序列：

- 四域：`[T04医学, T01自然, T13遥感, T15遥感, T16金融]`。
- 五域：`[T04医学, T01自然, T13遥感, T16金融, T18交通]`。

均5阶段、每阶段8条原TRAIN/4次正LR更新，总40次QA曝光/20更新。旧医学锚仅首次8条直接曝光。新CPU核验实际前3阶段全部48层A/B、各阶段首批原始梯度、训练ID精确相同；S1/S3的32题原预测/NLL/评分也精确相同。这是同历史下替换最后两个任务，**仍同时改变任务内容和顺序，不是纯领域数干预**。没有修改任何GPU源码、QA、参数或选择规则。

全部原Organ507题、158图像簇，原Answer F1重算；图像簇2000次bootstrap/seed42。按作者英文253题/中文254题全部报告，不挑显著子组；非独立seed/顺序复现。

## 4. 证明了什么／未证明什么

- 已核实后续分叉前的学习历史精确相同，排除本配对前3阶段随机权重/首批梯度差异。
- 当前没有建立“五域比四域准确率显著更低”；区间含0**也不证明无效或等价**，不能给一个额外领域分配因果损失百分比。
- 在本完整旧锚，NLL明显变差与生成F1差不确定并存；接近0分的中文大量题不能继续体现小差别。loss只作辅助机制证据，不能替换主Acc或称无遗忘。
- 同域相比跨域的较大差距包含后续正迁移不同，不能全记为已丢知识。此处任务内容/顺序/语言仍混杂；两任务锚的原48组继续，未完成归因。
