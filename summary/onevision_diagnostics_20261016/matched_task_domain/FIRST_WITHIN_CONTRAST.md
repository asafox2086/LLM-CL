# 首个严格同域对照：还不能把缺陷归因于任务数

快照：严格48组已有7组完成。本页只解释Organ锚的SeqFT重复任务/同医学新任务两个完整轨迹；跨域与第二锚尚未完成，不据此提前选方法或调整设置。

- **探究的问题：** 不切换领域，只连续学习其他医学任务，是否就明显损害旧任务？
- **做的实验：** 相同基座、初始状态、seed、优化器、每阶段8条原TRAIN/4更新，共5阶段。重复组为Organ×5；同域组为Organ→Modality→Position→Shape→KG。共同首阶段参数及32题输出/NLL精确一致。最终两个SeqFT都测完整Organ 507题，并按158张图像做配对区间。
- **结果：** 见下表。全507题同域组比重复组低0.934pp，但95%区间包含0，未建立显著F1差异。辅助NLL差为+0.09457，区间[0.06498,0.12351]。32题诊断F1差为−5.208pp，不能替代完整507题差异。
- **证明了什么：** 在这两条固定轨迹中，同域新任务与重复旧任务的拟合结果不同，但主指标尚不能支持“多任务本身导致明确性能缺陷”。两组独特训练内容不同，旧锚直接曝光为40次与8次，不能把结果纯化成任务数量效应。两组在32题上的最终NLL都远低于共同首阶段，不能将相对重复组的差距直接称为相对刚学完的遗忘。
- **改进的方法：** 按原冻结计划继续跨域、第二锚和所有机制；保留完整507题核验及当前任务学习，不只用32题小诊断或只挑显著NLL。未提出或启用新算法。
- **改进的效果：** 明确了当前证据边界，尚无方法性能提升，也尚不能判定领域干扰是主因。
