# 两模块完整持续学习试验：已实现/排队，尚无GPU效果

本次用户授权从问题设计两个模块，并将GPU1方案交由研究者决定。旧“暂停设计”要求已被覆盖；固定数据、禁止测试调参、逐项证明干预有效、基线后台运行等要求不变。

## 1. 从哪两个问题出发

| 问题与已完成证据 | 待检验模块 | 不能先声称的结论 |
|---|---|---|
| 旧A基底和完整旧AB函数对医学/遥感效果不同；零B初始化的一步训练只更新B | A：分离优化基底与旧功能 | 保留A，只用当前TRAIN探针选择B强度1/0.5/0；不预先指定某域应重置，不是自适应最优模块数 |

## 2. 四组完整对照

control / 仅A / 仅B / A+B，固定19原生阶段、1%共1313条TRAIN，seed42、每阶段fresh AdamW、1epoch、有效batch16、lr1e-4、floor warmup、clip1。QA、图像和原生顺序不改；各组训练顺序完全相同，无验证集。

本研究保持原生AnyRes输入，与正式V2基线公共缩放协议分别报告，不能直接混成同设置方法排名。control每个阶段的A/B必须与已完成确定性原19阶段轨迹逐元素一致，其他三组的首阶段也必须精确一致；失败不放宽容差。六个官方GPU前向门槛含FinMME:5082已知token问题。所有这些真实GPU门槛仍待运行。

当前探针每个原生任务最多8条TRAIN；旧记忆每个已学原生任务2条TRAIN，按固定ID哈希选取，最大36条旧QA。全部来自同一冻结1313池，不新增标签。完整阶段的B参考是每个旧任务**刚学完时自身记忆NLL**，允许预算固定+0.02nats，不随每次更新滚动放宽。A的平分规则保留更多旧功能；所有候选/步长只读TRAIN，不读TEST。

共93次目标优化器更新，所有组1313次目标QA训练曝光相同。A额外TRAIN前向上限1359题次，B上限11430题次，采集自身参考另76题次；实际值另报，TEST评测另计。候选计算并非免费，若效果无明显收益或成本过高，就不能宣称轻量优势。这些只是题次预算，不是GPU耗时测量。

## 4. 保存、恢复与成本

每次更新保存原始preclip完整梯度、参数布局、实际起点/提议/接受A/B、loss、真实使用LR、门控候选及拒绝原因。每阶段保存A/B、固定基座revision/源哈希、优化器/RNG和SHA侧文件，`latest_stage.json`指向最新可信阶段。当前原型四组都留19阶段，便于完整稀疏评测；这些为独立研究快照，不改正式基线保存策略。

仅恢复同源/同数据/同权重；阶段训练中断归档该未完成阶段并从上一可信边界重训；同权重评测允许原ID前缀续接。SHA损坏停下，缺失原子侧文件视为未证实，禁止拼接不同权重预测。固定基座单独按SHA/revision引用，不能声称每个小adapter文件含完整模型。

每阶段同PID训练前后记录CPU RSS/PSS/USS、GPU allocated/reserved/NVML、增长字节和训练窗口峰值；临时候选与CPU优化器副本计费。CPU/NVML每5秒采样可能漏瞬时峰，CUDA另有allocator峰；TEST和跨PID恢复总体峰单列，禁止把两个PID占用相减当内存增长。
