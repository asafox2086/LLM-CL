# 从多领域论文到小模型／小数据：质量校准与软聚合

2026-10-18用户授权：从已有多领域方法出发，检验在0.5B、1%少数据背景中是否能取得明显收益，再轻量改造，同时考察性能。不能预先保证结果。本试验是机制借鉴后的独立改造，**不是原论文复现，也不作为原方法基线成绩**。

已接入原nohup服务新CPU340143、只读结果观察器340149；继承原归因GPU338128自然完成并校验，旧CPU336769仅计划退役。15机制、10策略、3继承安全CPU检查通过；无新GPU效果。[激活与受保护进程](../functional_router_queue/ACTIVATION.json)、[实时状态](../functional_router_queue/queue_state.json)。冻结源码后不热改，原全部任务和基线保留。

## 1. 探究的问题

输入“像不像见过的任务”与某个专家“能不能回答”是否不同？少量TRAIN向量估计的拒绝阈值，会否让模型不必要地退回较弱的无LoRA基座？保持原专家权重不变，检验调用/融合是否构成性能瓶颈，避免先靠扩容解释一切。

已完成的同155题/19任务诊断：固定相似度AP22.391，可学习相似度31.025，顺序LoRA43.363；后者为同原生研究协议，不是V2正式成绩。学习相似度相对固定版本+8.634pp，相对顺序LoRA−12.338pp，尚未成功。两组都在阶段1/2/3占满3个模块。学习版本在固定500NLL诊断题上退回基座的比例为自然22%、医学61%、遥感3%、金融51%、交通0%；这些计数只证明动作发生，**未证明这些动作错误，或是掉分的全部原因**。

## 2. 别人提供的角度与本背景的取舍

| 论文与正式来源 | 作者机制 | 在本背景里的限制 | 本次借鉴／保留的控制 |
|---|---|---|---|
| [D-MoLE，ICML2025作者全文](https://arxiv.org/html/2506.11672)，§4.1/4.2 | 逐任务自编码器识别输入、阈值选专家，预算内分层扩容，视觉/语言分配更新 | 原文会对视觉模块分配LoRA；直接复制会改变我们冻结视觉的实验。小量QA上输入分布阈值是否可靠未被作者证明 | 不增加自编码器/视觉LoRA；用已有相似度，但以TRAIN真实NLL监督极小校准器 |
| [MVP，ICCV2025作者全文](https://arxiv.org/html/2508.00260)，§3.3/4.3 | 根据相关性聚合预训练投影和已学专家，剪枝抑制无关复用 | 原方法针对视觉投影器；我们现有投影冻结，不能声称有同样的投影器漂移。多个完整投影器成本不合适 | 只借鉴连续聚合原则；在既有一个活动LoRA上缩放残差，不新增视觉投影器或专家 |
| [ProgLoRA，Findings ACL2025](https://aclanthology.org/2025.findings-acl.143/)，§4/Table3 | 相关旧LoRA参与知识迁移，task recall保持动态分配 | 原方案按任务增加块；静态版测试使用任务信息，不能直接当未知任务路由；数量增长与我们轻量目标不同 | 保留“不只保护，也要调用旧技能”的视角；本轮先固定池区分路由与专家能力，不直接扩为19块 |
| [DGG，CVPR2026作者全文](https://arxiv.org/html/2511.15164)，§5.3 | 不扩模型，结合参数方向代理与小量真实回放梯度 | 作者异质流更依赖回放；其几百题/任务预算不等于我们1%少更新。保护不一定解决弱习得 | 保留严格机制对照；本轮不先叠加强正则，也不把公式上的零梯度直接认定性能原因 |

这些论文证明的是各自设置的效果，不能推导在本模型里有“大幅提升”。本次新增通读/定位为D-MoLE方法/分层预算/路由回退、MVP聚合/消融、ProgLoRA分配/recall及DGG异质流消融；不转录其总分作为我们的成绩。

## 3. 做的实验：两个轻量模块、四个视图

固定已完成`learned_cosine_K3`的stage19专家池、原向量投影、全部原QA/图像/提示词/Answer F1。**没有新的LoRA训练，没有新增LoRA。** 不是重新训练五个领域的方法效果，而是训练完成后的固定权重归因与轻量校准；全持续学习收益需另做完整训练对照才能成立。

**模块A：TRAIN质量校准。** 使用原池实际保存43条TRAIN输入向量（e0/e1/e2为16/11/16），原始数据及ID不变；每条分别测无LoRA和3个专家的NLL，共172次前向。标签为`softmax(-NLL)`，不需要领域名、测试标签或额外知识。已有3个余弦分数加常数项，线性映射为4个质量logit，共**16个FP32参数**。CPU AdamW400步、lr0.03、weight_decay0.001；原1792→32投影固定，不再优化。单次几何相似高不被直接等同于已掌握。

**模块B：连续残差聚合。** 基座始终为原模型；每题只装载一个LoRA。用`W_base + gain×ΔW_expert`，替代阈值一过就整块关闭。质量版`gain=1−p(base)`、专家为最高质量概率的非base专家；几何版`gain=clip((1+max_cos)/2,0,1)`，这是预先固定的零参数连续对照。它是对MVP聚合原则的语言LoRA改造，不是其视觉投影公式的原样复现。

| 视图 | 校准A | 软聚合B | 作用 |
|---|---|---|---|
| original_hard | 无 | 无 | 原始硬阈值复现门槛，不拿新分数替换旧成绩 |
| quality_hard | 有 | 无 | 质量概率最高者，在base与专家中选一个 |
| geometry_soft | 无 | 有 | 最近专家＋预先固定的连续相似度增益 |
| quality_soft | 有 | 有 | 质量校准＋连续残差聚合 |

所有视图全部报告；不按测试选最好视图。模块校准只读TRAIN答案；推理只读图像和问题，原评分没有翻译、选项映射、前缀剥离或答案修正。用户要求的测试答案不能挑路由/事实/容量/超参仍生效。

## 4. 结果与因果边界

目前只有CPU实现检查，GPU结果待测。首先必须在gain=1路径上逐题**精确重载原500NLL/155生成/参考/评分/路由**，否则停止。15项CPU机制/实际包装层检查不代表本模型效果。CPU预检原误假定每专家都存满16条，已保留失败证据，改为读取实际43条，不补样、不改变采样。

四视图诊断只测原500题NLL/155题生成。预先固定`quality_hard`与`quality_soft`两个完整确认候选，**无论诊断哪组好，都各测完整21454QA**；新进程先精确重载本试验500/155，再完整生成，不拼旧预测。其余20954与既看500分开。几何软视图是机制辅助对照，不宣称完整主表方法。

增益只能支持“在固定专家池上，调用/融合贡献了一部分差异”，不能证明专业知识已充分、路由错误解释全部损失，或此后任意训练都能无遗忘。模块未实际改变选择/增益时，不把无收益写成有效干预失败；逐题、路由、增益和拟合梯度一起报告。最终单点评测不填完整FWT/BWT。
