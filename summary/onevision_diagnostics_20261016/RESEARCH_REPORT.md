# 痛点探究报告：问题—实验—结果—证明—改进—效果

当前唯一主指标为 **Answer F1（原始Token F1，0–100）**，不做选项映射或额外答案解析。[评分冻结规则](../../rules/020_answer_f1_primary_20261017.md)。旧版报告与精确正确数移至[历史快照](../ago/metric_revision_20261017/RESEARCH_REPORT_before_primary_F1_rewrite.md)，不再作为并列主成绩。

研究对象LLaVA-OneVision-Qwen2-0.5B-OV，完整模型约0.9B。共享冻结1%训练1313QA；500题NLL／155题原生任务生成是诊断，不是完整21454测试。重复训练、知识事实和固定8题机制实验各自另计预算。正式双骨干V2原图共同缩放与本研究nativeAnyRes协议不同，不混排。

**已证明的局部问题：** 同一任务多训也会退化；输出全部相同时仍可保留视觉条件信号；最新中心EWC首步保护项为零；极小知识记忆成功并不保证目标问答提高。**核心未完成：** 不能认定“主要因为多域”或“主要因为任务少”，严格双锚六机制GPU对照尚待运行。两模块候选已有CPU原型并排队，尚无GPU提升结论。

## 1. 模型所有图片都回答urban：没看图，还是输出偏了？

- **探究的问题：** 恒定答案是否说明视觉输入完全失效？
- **做的实验：** 相同旧自然LoRA起点，原遥感TRAIN6/TEST100，1步/4步；5个固定权重测原图、确定性错图、纯文字，共30格。原图400条生成和NLL逐题复现。
- **结果：** 完整旧AB的1步原图F1=76，4步F1=44且全部urban。4步时原图相对错图仍降低gold NLL约0.054，配对区间[0.033,0.074]；urban相对rural概率整体偏移。
- **证明了什么：** 排除“该组权重完全不受图像影响”；输出决策偏移可掩盖保留的视觉条件信号。未证明视觉表征不变或唯一成因。
- **改进的方法：** 实际测试同数据/起点/4步的类别平衡损失，并把同一权重集合反向分配给urban作为负对照，不按测试选权重。
- **改进的效果：** 均匀F1=44、平衡=50、偏urban=44；平衡+6pp，图像配对区间[2,11]。仍94/100输出urban，低于平衡组自身1步F1=75，只是局部缓解。

证据：[视觉对照](RURAL_COLLAPSE_EVIDENCE.md)、[损失权重](RURAL_WEIGHT_EVIDENCE.md)、[统一F1重审](PRIMARY_F1_REASSESSMENT.md)。

## 2. 样本少就重复训练，能否解决？

- **探究的问题：** 低分是否只是更新次数不足？
- **做的实验：** Modality TRAIN11/TEST228、KG12/267、遥感6/100；三种起点各自比较同轨迹1/4次更新，共9轨迹18终点。完整重复当前任务4遍，不是历史回放，也没有“两遍”的实验。
- **结果：** 完整旧AB起点的Answer F1如下。

| 原任务 | 1步F1 | 4步F1 |
| --- | ---: | ---: |
| 医学Modality | 29.263 | 51.956 |
| 医学KG | 7.240 | 17.918 |
| 遥感rural | 76.000 | 44.000 |

- **证明了什么：** “增加预算普遍有利”被否定；即使不增加新任务，继续训练当前任务也能退化。遥感同权重端点TRAIN NLL0.334→0.240、TEST0.296→0.374，但TRAIN仅6题且差值区间含0，不能直接下普遍过拟合结论。
- **改进的方法：** 已扩大同一数据更新预算，并做第1项权重控制；不按测试选择最佳步数。
- **改进的效果：** 医学获益、遥感反向；预算有任务依赖，不能把多训练当通用解决方案。

证据：[全部18终点](COMPLETED_CONTROLS.md)。

## 3. 极小知识LoRA足够吗？先检查写入，再看迁移

- **探究的问题：** 专业知识没写入，还是写入后不能迁移到图文任务？
- **做的实验：** 固定作者16条解剖事实，rank1/8×正确/错配共4轨迹，0/8/64步，同预算负对照；64步512次辅助曝光。rank1增加67584参数；rank8继续训练540672参数。原事实与固定改写是干预有效性检查；目标性能只用Answer F1。
- **结果：** 原8步未验证事实回忆；64步rank8可逐条复现全部16事实、改写12条。目标问答F1如下。

| 64步条件 | 医学100题：共同起点→64步F1 | 原生KG267题：共同起点→64步F1 |
| --- | ---: | ---: |
| rank1_correct | 20.022→25.456 | 8.978→6.494 |
| rank1_permuted | 20.022→20.854 | 8.978→3.581 |
| rank8_correct | 20.022→22.133 | 8.978→6.523 |
| rank8_permuted | 20.022→21.945 | 8.978→4.779 |

- **证明了什么：** 64步已排除“完全没记住事实”；但成功记忆不等于目标迁移足够。正确知识与错配的医学生成F1差：rank1约+4.602pp、区间[-1.046,10.402]，rank8约+0.188、区间[-6.283,6.100]，均包含0。KG正确相对错配有局部信号，但两种正确知识KG F1都低于未加辅助训练的共同起点，不能把“比错误知识少损害”说成普遍提升。新增审计确认四组起点在医学100/KG267的预测、F1、NLL全部逐题相同；即使31条同关系/固定tail字面匹配题，F1起点15.054→rank1正确11.885/rank8正确12.903，差值区间分别[-17.497,12.423]/[-14.444,10.753]，均含0。不能将“只是没覆盖到题”当作已证原因；该31题也不是语义/图像实体覆盖的证明。
- **改进的方法：** 已增加写入预算并补同rank/同预算错配控制；未扩事实池、用测试选事实或选rank。
- **改进的效果：** 修复“干预尚未学入”的有效性缺口，未证明极小知识库就足够解决目标问答。事实池覆盖、关系/视觉实体绑定和输出行为仍可能限制迁移。

医学100与KG267重叠12题，不合成367独立QA。证据：[F1配对区间及源SHA](PRIMARY_F1_REASSESSMENT.json)、[写入检查](KNOWLEDGE_FIT_EVIDENCE.json)、[知识覆盖](KNOWLEDGE_MECHANISM_AUDIT.md)、[起点精确复核及全部字面分组](KNOWLEDGE_LOCALITY_EVIDENCE.md)。

## 4. 极少更新时，EWC保护真的启动了吗？

- **探究的问题：** 仅有很少更新时，正则化是否提供了预期旧任务保护？
- **做的实验：** 实际8个EWC条件、32个后续阶段首批，读取各自保存中心/Fisher/参数；相同起点和目标梯度做CPU fresh AdamW λ0/1/100反事实。
- **结果：** 最新旧任务中心等于阶段起点，32/32最新项首步梯度0；stage2仅一个中心，8/8整个EWC梯度0。同状态CPU首步更新完全一致。更早中心与阶段内后续更新仍可生效。
- **证明了什么：** 这是原EWC二次项性质及本设置的实测启用限制，不是新数学发现；不能称EWC全程失活。另8个实际stage2首批新旧梯度正相关，不支持“首步无保护必然有害”的因果叙述。
- **改进的方法：** 已测试λ1/100并核验梯度；不自创新正则化。补查完整日志中的冲突时间位置。
- **改进的效果：** 调大λ不能改变最新中心首步零梯度。128次noop/projection更新有31次负点积，只有5次在首批、26次在同阶段后续；原始向量只保存并重算了32个首批，其余是当时日志。未证明这一启用限制导致最终F1下降。

证据：[EWC启用](EWC_ACTIVATION_AUDIT.md)、[首步因果边界](FIRST_STEP_CAUSALITY_AUDIT.md)、[冲突时间核查](GRADIENT_TIMING_EVIDENCE.md)。

## 5. 复用旧LoRA，是旧A基底有用，还是完整旧功能有用？

- **探究的问题：** 一步任务是否学到了A/B全部因子；复用整套LoRA是否总好？
- **做的实验：** 9个独立单更新任务核查实际正LR/参数；比较随机A零B、旧自然A零B、旧完整AB三个起点，当前QA/更新预算固定。
- **结果：** 独立单步9/9的A不变而B更新，符合B零初始化的链式梯度。4步F1对比如下。

| 起点 | Modality228题F1 | 遥感100题F1 |
| --- | ---: | ---: |
| 随机A零B | 24.825 | 62.000 |
| 旧A零B | 23.127 | 69.000 |
| 完整旧AB | 51.956 | 44.000 |

- **证明了什么：** 排除“LoRA完全没更新”；旧优化基底与旧功能是不同干预，方向依任务。不能由A/B相似称语义冗余，也不能说一种固定复用跨域通吃。
- **改进的方法：** 已实际对照只复用A、重置B，与完整AB复用；这是机制实验，不是新算法。
- **改进的效果：** 遥感旧A零B点估计69优于完整AB44，医学却明显依赖完整旧功能；历史自然347条TRAIN成本另计。没有测试选专家或新增路由。

证据：[因子更新](FACTOR_UPDATE_EVIDENCE.md)、[全终点](COMPLETED_CONTROLS.md)。

## 6. 评分差异会不会冒充能力变化？

- **探究的问题：** 不同域有短答案、选项、长回答，是否不应只因表述不同整体判零？
- **做的实验：** 按用户决定改用已有Answer F1作为唯一主指标，不增加选项映射或额外答案抽取。72份实际预测/1365条生成逐值复算，与原存token_f1完全一致；全部历史预测保留，不重训。
- **结果：** F1给内容部分重合提供连续分数。交通30题F1=30.465，500题诊断答案NLL截断0；完整TEST仅3条交通参考超过512，其NLL单列为前512+EOS，生成评分仍对原完整参考。
- **证明了什么：** 指标口径改变能更连续地描述输出，但F1不是完整语义正确率，仍受同义词、数字/单位及字母/内容差异影响；不能把F1增加直接解释为专家知识提升。
- **改进的方法：** 统一评分与AP/FWT/BWT聚合规则；取消拟议选项映射，不按哪种指标让方法胜出而选指标。
- **改进的效果：** 改善比较与报告口径，没有任何新训练性能提升声明。后续不再将EM/ROUGE并列主成绩，必要loss/梯度机制诊断保留。

证据：[评分定义与书面表述](../../rules/020_answer_f1_primary_20261017.md)、[F1重审](PRIMARY_F1_REASSESSMENT.md)。

## 7. 多领域干扰，还是任务少/预算少？现在证明到哪一步？

- **探究的问题：** 同任务重复、同域新任务和跨域新任务，在相同任务数/更新数下是否产生不同质量变化？
- **做的实验：** 旧医学锚23题、4序列×6机制24组合已完成；存在相同首阶段权重不一致。确定性新设计2锚×4序列×6机制48轨迹已冻结8TRAIN/32锚TEST/8当前任务TEST，每条stage1必须参数和输出精确一致；尚待GPU。
- **结果：** 确定性原19任务轨迹中，医学F1由刚学完累计35.327升到最终46.058，遥感59.375降到46.875，自然60.714降到57.381，金融30不变，交通31.254降到30.465。19任务宏平均变化+1.425pp，但五域等权变化−1.178pp；同一155输出，3/5域下降。医学在任务宏平均占10/19，而域宏平均占1/5。
- **证明了什么：** 正BWT不表示所有域都获益；不同聚合权重可掩盖域内异质性。医学诊断NLL同域段改善0.367、后续跨域段退化0.319，是待复核线索，不是纯域数因果：任务内容、曝光、先后顺序和初始能力仍混杂。
- **改进的方法：** 严格双锚原机制对照已排队；F1报告观察器CPU验证能拒绝旧23组首阶段输出不一致。48轨迹实际GPU门禁及结果仍待产生，不用CPU验证代替。
- **改进的效果：** 目前改进了实验控制与诊断可见性，**核心域数/任务数归因尚未完成**。原始局部TRAIN梯度中重复锚无负点积、跨域更多，但不能当作领域独立因果或有限Adam步骤必掉分证明。

证据：[唯一F1逐域与聚合](PRIMARY_F1_REASSESSMENT.md)、[同域/跨域时间段](DOMAIN_BOUNDARY_AUDIT.md)、[严格双锚协议](../../analysis/ONEVISION_MATCHED_TASK_DOMAIN_PROTOCOL.md)、[新实验结果入口](matched_task_domain/VERIFIED_RESULTS.md)。

准入预检补充：[固定879条QA的图像结构核验](matched_task_domain/INPUT_GEOMETRY_AUDIT.md)全部兼容；80 TRAIN/799 TEST原ID不变。原失败FinMME:5082作为队列外检查能复现2052/2106不匹配，说明检查能识别该故障。这只排除本固定队列的已知结构风险，不能代替实际GPU前向/更新/首阶段精确门槛。

## 8. 总体F1上升就没有旧题退化吗？

- **探究的问题：** 新题质量收益能否抵消已有题的下降，使总分掩盖退化？
- **做的实验：** 确定性19阶段、155个固定原生覆盖生成ID，逐题比较各自刚学完与最终的原F1；不阈值化成正确/错误。
- **结果：** 155题平均F1=40.798→42.903，+2.105pp，图像配对区间[-3.308,7.718]。22题上升、18题下降、115题不变；正变化累计1160.454题分，负变化累计−834.117题分。刚学完值跨多个模型时点，非单快照。
- **证明了什么：** 总体方向不能代表所有题，质量损失会与新增收益相抵；整体差值区间含0，不能宣称确定提升或普遍遗忘。F1逐题下降也不等价于语义知识已删除。
- **改进的方法：** 同时报统一F1、逐题质量变化、原生任务/领域结果，保留loss/参数证据；不靠换阈值制造发现。
- **改进的效果：** 提高报告可诊断性，没有新增模型性能。诊断AP=43.363、FWT=15.301、BWT=+1.504，仅限155题，不能填入完整21454主表。

证据：[逐题F1重算与SHA](PRIMARY_F1_REASSESSMENT.json)。

## 9. 基座的图像收益弱，是否说明训练后仍不会看图？

- **探究的问题：** 早期基座的医学图像收益不足，能否解释训练后的低分？需要分别核实各组实际权重。
- **做的实验：** 只读已完成的4权重×3域×3视图36个预测文件，3个实际adapter SHA一致；每权重每视图医学100题生成，自然/遥感各10题生成，各域100题NLL。原图、固定循环错图、无图ID与原金标逐题对齐，Answer F1不加解析；同时核验图像解码像素、错图模态、视觉token数。
- **结果：** 最终顺序权重医学F1原图43.022、错图30.889、无图24.310。原图相对错图+12.133pp，收图端图像聚类区间[6.950,17.941]；相对无图+18.713，[9.376,28.614]。基座原图相对错图仅+2.777，区间[-0.016,5.568]。全部300个错图对照均不是相同文件字节或相同解码RGB。
- **证明了什么：** 排除“基座收益弱，因此最终权重也完全不依赖图像输入”的推广。该最终权重的图像输入干预会改变输出质量；不证明视觉能力已经足够，也不证明顺序学习本身导致提升。医学错图61/100改变视觉token数，同token的39题差+6.239、区间[-0.360,14.474]含0；分辨率/裁剪与语义作用尚未独立分离。
- **改进的方法：** 补齐训练后固定权重视觉对照的逐题F1、配对区间和负对照有效性审计；原生题型与相同/不同token两组全报，不挑显著组，不新增算法或改图像。
- **改进的效果：** 收紧“不会看图”的归因，避免由早期负结果否定训练后视觉作用；没有新增模型性能或方法提升。跨权重训练预算/dropout不同，不能把43.022与其他轨迹46.058混算；仍需严格48组控制回答多域/少任务问题。

区间固定拟合权重、单seed、未校正多重比较，且未建模共用错图来源依赖；医学100题不是完整2094题。证据：[训练后视觉F1审计](TRAINED_VISION_F1_EVIDENCE.md)、[全部配对/题型/像素SHA](TRAINED_VISION_F1_EVIDENCE.json)。

## 10. 把机制发现变成两个模块，是否能明显提高性能？

- **探究的问题：** 旧LoRA基底与旧函数的作用不同；首步正则项/原始梯度约束又不等于实际更新保护，能否分开改进？
