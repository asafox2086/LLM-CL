# 原因判定与尚缺的证据

这里区分“排除一种解释”和“确认唯一原因”。持续学习总目标仍未完成，不能用一个遥感任务的结果代替全部领域／方法。

| 问题 | 当前证据允许的判断 | 尚缺什么 |
| --- | --- | --- |
| 实际有没有训练？ | OneVision存在真实正LR、非零梯度和参数更新；知识rank1本次前8步A/B及实际ΔW均变化。不能把它解释为旧Qwen的零LR故障。 | 更新不等于知识写入或功能提高；知识64步完整病例和错配对照待完成。 |
| 是否一定因为新增任务多才退化？ | 同一旧自然LoRA、同一个遥感任务、同6条TRAIN，1→4步就能76→44/100。**这种退化不需要继续添加新任务即可发生。** | 这不是所有CL退化的解释；旧自然→遥感仍包含域切换。多域数量的严格效应仍待匹配数值、内容及多锚验证。 |
| 是否因为图像完全没用？ | 4步全答urban时，原图相对错图仍改善gold NLL和目标方向概率；至少这组权重／任务不能归因为图像完全不起作用。 | 不能证明视觉表征未变化、语义视觉能力完好，或其他域没有视觉瓶颈。 |
| 输出偏移是不是直接现象？ | 裸候选概率优势整体向urban移动约1.95，跨图排序相关0.918；两类均值均越到urban侧，与全部输出urban一致。 | 训练类别权重、优化器和旧函数各占多少因果贡献？固定三组损失权重干预已排队；未按测试调阈值。 |
| 正则化是否每一步都有保护？ | 最新旧任务中心等于当前起点时，EWC该项首步梯度为0；32个真实首批检查通过。 | 较早中心、后续步仍可保护；尚未证明该零梯度导致最终准确率下降。 |
| 加极小知识LoRA就足够吗？ | 当前不能支持。原16事实严格回忆未验证成功，且正确／低相关／错配内容的收益不具清晰特异性。 | 同预算正确／错配的rank1与rank8、固定8／64步操作核验仍在运行；先证明事实被写入，再分析目标任务。 |
| 多域比少任务更致命吗？ | 默认后端4×6对照提供线索；同域／跨域表现不同，但首阶段已有数值差异，格式辅助下部分区间含0。 | 同起点确定性复核、多锚／顺序和内容／token预算控制；不得先宣布域数量是唯一原因。 |
| 能否解释所有方法／完整测试？ | 不能。OneVision诊断与Qwen基线分别报告；小样本机制结果不当作完整测试排名。 | 完整21454确认、不同CL机制的严格对照与资源汇总仍未齐备。 |
