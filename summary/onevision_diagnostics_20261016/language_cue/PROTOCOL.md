# 固定权重的语言/简答指令干预

冻结时间：2026-10-18，任何本干预GPU结果产生前。属于观察语言混杂后的**事后机制假设检验**，不是未经查看的独立测试，不改变正式双骨干基线。

## 问题与可证伪解释

严格共同起点T04 SeqFT的最终507题中，跨域−同域英文F1为−9.960pp、中文−21.102pp；中文预测含汉字251→25/254。后续同医学32目标曝光中17题含中文，而跨域32题无汉字。任务内容、领域、语言共同变化，尚不能把差距全归因知识丢失。

若相同权重仅添加既有语言指令就恢复部分成绩，说明该部分可由输出引导获得，无需此次再写入知识；这不证明知识完全保留。若没有恢复，只否定这四种固定视图的简单修复，不能否定所有对齐解释。简答指令单独作为对照，以免把任意额外指令作用全算成语言作用。提示长度/语义、题目语言组内容仍有局限。

## 冻结设计

- 权重：原严格研究的T04 `within_medical`与`cross_short` SeqFT S5，保留父完成证明、源/检查点SHA。不是按本干预效果选择权重。
- 四视图复用早已存在的`onevision_knowledge_intervention.PROMPTS`：`original`、`answer_only`、`question_language`、`both`。同一指令对每个问题统一应用，作者语言/答案不参与选择。只附加指令，不改存储问题、图片、答案或上下文。
- 两个范围分开：原32题probe（2权重×4视图=256次条件观测）；原完整Organ507题（8格、4056次条件观测）。probe属于507子集，不当独立重复，不能相加为539题。
- 4个独立进程依次为同域probe、跨域probe、同域full、跨域full。**无论probe结果如何，完整8格全部执行**；禁止按TEST挑提示词、事实、容量或调参。
- 不创建优化器，0次参数更新；不加事实、LoRA或专家。原生AnyRes/BF16、确定性后端、生成预算沿用原研究，不混入V2图像协议的主表。
- 原始Answer F1唯一成绩，不做翻译、选项映射、前缀剥离或语义重打分；按作者英文/中文、开放/闭合题型完整报告。汉字出现次数仅为文字统计，不是语言遵循准确率。

## 必须通过的实际门槛

1. CPU实际processor检查8条原TRAIN×4视图：输入token确实变化，原图像像素/image_sizes保持精确一致，SHA冻结。CPU通过不冒充GPU通过。
2. GPU每视图重新核对8TRAIN输入token、BF16像素、image_sizes与CPU计划精确相同。
3. `original`视图32或507题的ID、references、prediction、scores、NLL必须逐项精确等于各自父轨迹，不放宽容差。
4. 每视图推理后所有A/B逐元素精确等于原S5；保留原始逐题输出、input/parameter gate、CPU/GPU推理前后与峰值。这里无训练内存窗口。
5. 源/数据/权重校验失败即保留证据、停止等待处理；中断重新建可追溯attempt，不拼接不同运行预测，不修改父权重。

## 预定报告与调度

全部条件成绩、同权重cue−original配对效应、跨域与同域的cue效应差都报告，英文/中文分别列出。固定图像聚类bootstrap2000、seed42，区间未多重校正，只反映固定权重下题目差异，不是跨训练seed因果置信度。

先补可用共同S1，再执行本4个固定推理进程，之后继续原48（全部保留，SeqFT优先）及完整方法/确认队列。只在GPU1真正空闲时启动；尊重其他用户进程，保留GPU0/2/3与两机基线。
