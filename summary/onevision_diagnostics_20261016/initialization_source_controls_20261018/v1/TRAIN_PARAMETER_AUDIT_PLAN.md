# 来源对照的TRAIN参数审计

独立只读CPU工具：`analysis/onevision_initialization_source_geometry.py`。不修改已冻结训练／调度／原报告源码，不新建GPU或轮询服务；只有新封存证明出现后运行一次。当前未获得五格完成证据，不预填结论。

1. 验证完成证明、全部绑定SHA及原源文件；拒绝活动／未封存参数。
2. 报同域／跨域源A实际变化幅度及48层行空间主角余弦、归一化投影距离。因子换坐标或缩放不应被当作子空间变化；“A非零变化”不自动说明干预足够强。
3. 报每格目标训练前后A／B位移及实际缩放后的deltaW位移；以低秩Gram恒等式计算，避免临时生成48个稠密deltaW矩阵。
4. 分别读目标两步已保存的原始preclip梯度，报告48层A／B梯度范数、非零层数和真实TRAIN IDs。原文件对None也记录零向量，所以本工具不把零向量重新解释为必然None。
5. 本工具只解释参数／优化干预是否实现，不解析TEST答案或预测，不给语义冗余、知识充分、Answer F1因果或内存优势结论。验证全部封存SHA可能读取绑定TEST文件的原始字节，绝不据其选择条件。性能只由原五格报告的完整507题原始Answer F1判断。

CPU合成控制覆盖：因子可逆换坐标保持行空间、真实子空间改变、低秩／稠密乘积范数一致、零B乘积为零、两状态deltaW差与稠密真值一致。它们验证计算实现，不是模型实验成效。
