以下来自官方真实配置上的meta参数布局，CPU不加载权重、不前向；是参数字节量，不是实际部署文件或RAM／VRAM，也未含运行cache／状态。FP16／BF16基座＋FP32适配器按当前原端口计，重复注册的作者别名只算一次。
