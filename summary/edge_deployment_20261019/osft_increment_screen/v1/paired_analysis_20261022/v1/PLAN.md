# 四组完整后的一次配对补充分析

2026-10-22。该分析在LoRA_qv的完整结果已经可见、尚未读取另三组结果时新增，**不称原预注册分析**。准备期间后来观察到OSFT_all的COMPLETE已出现，仍未据其分数调整分析。原四组的科学源、READY、SPLIT、DEV点估计候选门槛不改；不新增训练/生成/TEST，不成为新的队列所有者。

## 问题与已有数据

100个固定DEV QA对应89个已知图像/场景分组：自然20组、医学18组、遥感11组、金融20组、交通20组。遥感20题的组大小为1×5、2×4、3×1、4×1。按题目完全独立重采，会拆开原本已知同组的题目。89组只是已知分组数，不保证组间独立；近重复和未知关联仍可能存在。

问题是：四组完整后，宏均分差来自多少配对题目的增减，按已知组重采时差值如何波动？这为结果表述增加约束，不用于挽救未通过的候选，也不把小测变成显著性或等效性证明。

## 执行与固定口径

- 仅原`SCREEN_COMPLETE.json`存在且四份COMPLETE通过原冻结`dispatch.verify`后，一次读取四组全部100DEV预测；核对所有ID、全部原参考、原评分AST及文件/权重SHA，不读取partial预测。缺少结束标记就返回pending；失败保留，不自动训练或重试。
- 全部六个方法对都公开固定100QA的原配对差、逐域差、五域宏均分差，以及QA和已知组的高/低/平计数。主点估计始终是原QA等权域均分，再五域等权；组计数不替换这个估计量。
- 各域独立从该域完整已知组中等概率、有放回抽取相同数量的组。同一组的全部QA一起纳入；同一份抽样同时用于四模型，保持配对。
- 每个重采域用该次抽到的全部QA分数总和除以QA数，然后五域等权。**不计算各组F1的等权平均**。组大小不等会使分母随机，这种比率统计量存在有限重采样偏差，不声称无偏。
- 固定10,000次、seed20261022，报告差值分布的2.5%与97.5%线性插值百分位，名称为“探索性组重采样百分位区间”。记录Python版本和配对抽样摘要SHA，不追加seed/次数/区间变体追结果。

聚类重采样的来源参见[Field与Welsh，JRSSB2007，§1](https://doi.org/10.1111/j.1467-9868.2007.00593.x)：整组抽取用于保留组内关联，其性质依赖数据模型。该文不是本11组遥感小样本区间覆盖率的证明。

## 解释和行动边界

原四组点估计筛选照常：LoRA_all/extra严格高于max(qv,OSFT)才列可能完整重训候选。本补充的区间是否跨0均不改变这个名单、不判显著或等效；六对分析未校正选择与多重比较。仅11个遥感组、固定单训练seed及未知组间相关限制解释，不代表跨seed不确定性、全部19任务或正式TEST表现。

即使候选通过点估计，完整1313重训及独立正式确认仍必需；不能把区间窄、配对赢题多或所选小测第一名当最终收益。若差值很不稳定，报告这一局限，停止使用“稳定/显著领先”的表述；不据此再挑题、调方案或延长训练。正负完整公开。

投入为一次CPU只读核验与10,000次标量重采，0模型请求/反向/优化器步；原CP SHA核对有磁盘读取成本，一并计时。结果输出到独立RESULTS.json，不改原SCREEN_COMPLETE或正式主表。脚本准备和分组计数不是新方法性能进展。
