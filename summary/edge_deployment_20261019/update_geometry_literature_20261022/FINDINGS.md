# 参数数相同，不等于从预训练点出发的更新空间相同

2026-10-22。本轮是论文、冻结端口与数学表达核对，未运行模型、反向、优化器或GPU，未创建实验READY或修改原四组。按rules032，端侧只作研究背景。下面区分已有实测、论文事实和自行推导，不把文献结果当本实验收益。

## 问题和已有证据

正式OneVision OSFT相对Seq的AP19提高6.071分，刚习得均分提高9.283，BWT反而更低；当前PASs最高点估计46.406仅比OSFT高0.049。来源为已封存[四基线分析](../sealed_baseline_tradeoffs_20261021/FINDINGS.md)。这些是结果分解，不能把习得差直接归因于容量、位置或投影。

原四组FIT/DEV同时保留LoRA_qv、OSFT_all、LoRA_all、LoRA_extra。其中三LoRA的rank相同、位置和总坐标数不同；跨OSFT另有LR、分解和投影差异。它们能检查简单LoRA扩展位置的收益，不能单独分清所有机制。以下分析没有新增条件或改冻结primary。

## 论文与实际端口的关键区别

- [MiLoRA，NAACL2025，固定论文v3](https://arxiv.org/html/2406.09044v3) §3用尾部奇异分量初始化A/B，并明确只用初始化引导，未在训练中强制正交。附表11的视觉设置为rank128，LoRA/MiLoRA的alpha分别256/128，dropout均0.05；不能把论文比较概括为其余条件全同的纯方向消融。该视觉指令微调也不是本1%多域持续学习证据。
- 本项目冻结[OSFT端口](../../../../exp/two_backbone_native_cl_20261017_v2/osft_adapter.py)除尾部25%分解外，每步调用梯度投影和参数投影，后续阶段重新分解。不是仅把普通LoRA换一个SVD初始化；不能把MiLoRA的结果拿来证明这些投影必要或多余。
- [LoRA-GA，NeurIPS2024](https://proceedings.neurips.cc/paper_files/paper/2024/file/62c4718cc334f6a0a62fb81c4a2095a1-Paper-Conference.pdf) §3从样本梯度构造初始化，同时处理缩放。Algorithm1含额外反向与梯度SVD，不能称免费初始化；初始化数据只能来自FIT，成本另计。其首步梯度近似不保证本项目AdamW全轨迹、F1或遗忘性质。

## 自行推导：要分开记录坐标、局部方向和相对基座的有限更新

设线性权重W0为m×n，B为m×r，A为r×n，s非零且固定，r≤min(m,n)。本节只讨论无dropout的线性映射和精确算术；未对实际checkpoint测量。

**普通零B LoRA：** W=W0+sBA，增量ΔW=sBA，所以rank(ΔW)≤r。可训练坐标为r(m+n)。初始B0=0时微分dW=s(dB)A0，dA项为零；A0满行秩时，该参数雅可比的像维数为mr。这是初始化处局部线性化，不是整个训练过程只能走这mr个方向。

**非零A/B并补偿基座：** Wfrozen=W0−sB0A0，W=Wfrozen+sBA；因此相对原W0的变化是ΔW=s(BA−B0A0)，rank(ΔW)≤min(2r,m,n)。这是上界，不能说实际达到2r或自由度翻倍。可训练坐标仍是r(m+n)；BA满秩r点的参数→线性权重雅可比秩为r(m+n−r)。补偿只平移rank≤r矩阵集合，不包含全部rank≤2r矩阵，也不能称普通LoRA增量集合的严格超集。相同rank、相同参数个数并不保证两种参数化相对W0的可达增量集合相同。

因此，直接比较零B随机初始化与非零SVD初始化，即使r一样，也不能把F1差全叫“找到了更好的方向”：初始雅可比、平移后的可达集合和更新尺度都可能改变。它们需要分别解释，不等于已经定位本实验失败原因。固定基U C Vᵀ、只训练r×r系数又是另一种受限集合；其失败不能否定可转动A/B的全部低秩方法。

普通LoRA进入BA满秩r的一般点后，雅可比秩同样为r(m+n−r)；mr只是零B初始化处的性质。上述雅可比秩不是某个loss或AdamW实际走过的方向数。原连续LoRA跨stage不重置A/B，重建优化器也不会把B归零，所以零B性质只描述全程最初初始化。原四组87次更新是尚待运行的FIT预算，不存在该四组“87步低秩失败”的结果；旧固定系数负结果和正式Seq的93步结果不能混用。

**训练态还有dropout区别：** 若沿本项目[SeqLinear](../../../../exp/two_backbone_native_cl_20261017_v2/methods.py)把dropout D放在A之前，残差基座无dropout，则上述非零初始化的初始输出为W0x+sB0A0(D(x)−x)。即使eval代数补偿成立，train逐样本输出也不必与原W0x一致。这里只是条件代数推导，未声称作者所有实现都有相同dropout位置，也不要求改精度或额外工程实验。

## 当前研究决定

1. 不启动拟议的“固定正式OSFT撤回q/v或额外位置”的15次CPU生成。它只有5个teacher已见TRAIN探针，且参考仅3题非零；正结果不足以改变筛选，负结果又可能来自末态共同适应，不能代替从头训练位置消融。按规则028，当前增量不足；没有据此生成预测或挑方案。
2. 原四组仍是当前最直接的问题：在既定预算下，普通小LoRA扩展更新位置能否超过两个参照。没有四组证据前，不加MiLoRA/GA变体、调rank/LR或修改队列。
3. 若四组证据留下“位置扩展不足以解释差距”的具体未解，后续独立协议才考虑拆分初始化/参数化与逐步投影，记录相同目标位置、坐标预算、相对W0的有限更新约束、scale/dropout、额外FIT曝光及分解成本。不能只写“同rank”；也不能把改变有限更新集合的收益说成纯优化收益。
4. 若要区分容量和优化，需使可达更新集合一致后改变初始化/训练路径，或明确承认这一点仍混杂；若主张1%特有原因，还缺数据量对照。任何方法选择都需FIT训练与独立DEV，正式teacher见过原DEV不能用于该筛选，TEST不选方案。

新结论是比较口径与竞争解释得到收窄，不是低秩已成功、投影已可删或取得新方法F1收益。基线、原四组科学源和数据不变。
