## 集合的双向证明

权重为m×n，h=floor(0.75 min(m,n))，k=min(m,n)−h。两侧完整正交补基分别为QL（m×p）、QR（n×q），p=m−h，q=n−h，故min(p,q)=k。

投影约束给出UL=QL A、VL=B QRᵀ。因此

`W = Whigh + UL diag(S) VL = Whigh + QL [A diag(S) B] QRᵀ`。

反过来，任意p×q矩阵C的秩不超过k，都能分解成A diag(S) B。因此原USV因子化的允许权重集合，恰是仿射保护块

`Whigh + { QL C QRᵀ : C为任意p×q矩阵 }`。

这是表示集合的等式，不是优化轨迹的等式。它既不证明因子化对学习无用，也不提供无损删神经元的依据。

## 为什么冻结原尾部基不是一般的同空间对照

方阵中p=q=k，初始SVD尾部两侧都张成完整补空间。但矩形层只有一侧如此。例：本模型k/v为128×896、h96、k32，完整核心形状为32×800；直接冻结原薄SVD尾部，只训练32×32系数，只能覆盖其中一个较小块。4864×896的FFN同样需要4192×224核心，而不是224×224。

所以旧极小固定系数试验失败，不能用来否定“OSFT同一保护块内换更简洁坐标”的想法；完整补空间与任意截小rank是不同干预。上述形状来自既有168矩阵metadata，未根据DEV/TEST选择。

## 坐标记账：何处是约束，何处是因子冗余

每矩阵原坐标为k(m+n+1)。两侧正交约束消去2hk个法向坐标，留下k(p+q+1)个约束内因子坐标。仿射保护块的维数为pq，差k²+k是一般满秩、非退化点的因子化冗余维数；不把该说法外推所有奇异点。

## 有区分力的研究问题与边界

从同一阶段起点、共用同一高子空间，原USV因子化与完整核心坐标可形成同表示集合的对照，检验有限更新预算下的坐标化/因子化/优化动力学。AdamW、裁剪、正则与浮点行为不保证相同；核心的基选择也须事先固定，不能事后调基追分。

不同轨迹到了下一阶段各自重SVD，高子空间可能已不同。因此19阶段比较只能叫同一重分解规则下的不同坐标优化，不能称全程同一保护块。严格的同块机制识别应限定共同起点的阶段局部对照。

这是原四组完成后再判断优先级的条件问题。目前不启动：若原四组已回答普通LoRA替代是否值得，就先按真实DEV证据推进；若确有未解，再独立写必要最小对照。阳性不自动证明等效/新算法，阴性只否定所试配置，不证明额外坐标必要。已有[GaLore](https://proceedings.mlr.press/v235/zhao24s.html)等子空间优化工作存在，不能把核心坐标或低维优化的通用思想称原创。

为说明“同表示集合”仍留下什么竞争解释，以下是**自行推导的理想SGD局部公式**，不是实际AdamW日志的拟合。令低分量为`U S V`，`S=diag(s)`，`V`为k×n，`G=∇Wℓ`。固定高子空间，在因子已满足正交约束时，三因子同时用相同η、两侧梯度投影、无动量/衰减/裁剪的SGD，得到

`ΔW = −η [ PL G Vᵀ S² V + U diag(diag(Uᵀ G Vᵀ)) V + U S² Uᵀ G PR ] + O(η²)`。

这里PL/PR是两侧完整高子空间补投影。第一项来自更新U，中间项来自更新奇异值向量s，第三项来自更新V。投影后的因子SGD一步在权重空间中的作用，通常不等于核心坐标直接SGD的`−η PL G PR`。

进一步，仅在方阵、阶段初始精确SVD时，取QL=U、QR=Vᵀ，定义`G̃=QLᵀ G QR`，则

`ΔCij = −η [(si²+sj²) G̃ij + δij G̃ii] + O(η²)`。

尾奇异值全部非零时，这个一阶线性算子可逆，覆盖整个核心的局部一阶方向，但施加非均匀缩放；它不是有限步轨迹等式。矩形层保留上面的一般式，不能把这个方形逐元素公式套到整个矩形补空间。非均匀权重不自动意味着有益，也没有证明当前OSFT优势来自该项。

实际四组采用AdamW和clip1，OSFT还含每步参数投影及后续阶段重SVD；本公式不替代这些过程，更不解释现有F1。[LoRA-RITE，ICLR2025，§2与§3.1](https://proceedings.iclr.cc/paper_files/paper/2025/file/bcbc0f660d2dde42f9d1d0ecb14a6f9a-Paper-Conference.pdf)研究两因子参数化下优化器的变换不变性，说明Adam的坐标依赖已有文献讨论；不是本三因子公式或本多领域结果的直接证明。本文不提出新优化器。

这项补充只收窄未来对照的解释：如果四组留下“位置扩展仍不足”的未解，同一阶段/同一保护块的因子与核心比较，也只能识别坐标化和优化动力学的组合；相同数值LR、原始梯度范数或坐标数都不足以证明相同实际权重步长。即使空间相同的替代胜出，仍不能将投影、容量或大参数量单独判为无用。现阶段不插实验、不调LR、不改筛选规则；新增成本仅为读取已封存日志及源码，0新模型请求/反向/优化器步。
