# 固定方向、更新秩和可训练坐标不是同一件事

2026-10-22。这个核对回答：旧固定方向系数负结果能否排除“固定基但高秩更新”的替代？只读原冻结源码与RandLoRA论文；0新模型/更新/GPU/TEST，没有新实验READY、实现或排队。当前唯一LoRA_all完整确认不改；不以文献代替本五域Answer F1。

原[DirectionalLinear](../../../analysis/onevision_directional_coeff_core.py)固定left/right，只训练零初始化16×16 coeff；eval精确算术下ΔW=U C Vᵀ，rank至多16。24层q/v共12288坐标是24×2×16²，16是旧预设，不是实证最优。旧principal/random的框架和数值条件也不同于当前公共端口，不能把旧AP直接和当前完整基线排表，更不能把一个配置的失败推广为全部固定基无效；不恢复旧作业。

[RandLoRA，ICLR2025固定v2](https://arxiv.org/html/2502.00987v2) §4使用固定随机Bⱼ与共享A，训练两组对角缩放：

\[
\Delta W=\sum_{j=1}^{N} B_j\operatorname{diag}(\lambda_j)A\operatorname{diag}(\gamma_j).
\]

按文中D≥d、d可被基秩r整除、N=d/r的理想设定，每矩阵训练坐标N(r+d)=d²/r+d；这是基秩，不是ΔW的秩。因而不能把它的r与普通LoRA的r直接当相同预算。多项相加可突破单组U C Vᵀ的rank上限；不保证初始化/每一步都满秩。

**自行推导的边界：** 精确算术中，一般rank(ΔW)≤min(D,d,Nr)，这只是代数上界。即便某矩阵增量满秩，可达集合也可能很小：仅一个标量c控制的cI₂，在c≠0时rank2，但只构成一维直线。RandLoRA的局部像维数至多其可训练坐标数。仅凭更新满秩或局部像维上界，不能断言覆盖任意D×d更新；当可训练坐标数小于Dd时，维数才直接排除全空间覆盖。维数不排除也不等于已证明覆盖，更不能由满秩直接推断等价全参优化或解决本预算下训练不足。旧单组固定方向与这种构造的可达集合不同；这既不证明随机基优于预训练基，也不支持从谱形状直接预测F1。

论文§5.3的“vision-language”是CLIP图像分类；§5.4/C.4的Qwen2-0.5B是语言常识任务，15k/170k样本、3epochs、120验证样本早停，非本1313图文/19阶段/93更新。不能因为骨干名字相近便称已在本小数据持续学习设置验证。随机基的固定存储、共享策略及组合运算也须计成本；少训练坐标不自动等于少驻留内存，静态合并也不让最终稠密基座变小。
