# 更新矩阵不像，不足以排除功能相近的低秩方案

2026-10-22。本次只核对论文、已冻结实现和一个手算反例，0新模型前向/更新/GPU/TEST；没有新实验READY、变体或筛选。科研用途是区分“逐矩阵重建OSFT”和“独立训练更小更新”，避免用前者的谱误差预先否决后者。原LoRA_all完整确认及两机基线继续，源/评价判据不改。

四组完整DEV中，LoRA_all用4,399,104训练坐标得到41.952549，OSFT_all用113,766,144得到40.783801；仅+1.168748pp且组百分位区间跨0，金融下降，尚无完整确认收益。位置/总坐标及跨OSFT投影/LR仍混杂；这是已完成[原小测](../osft_increment_screen/v1/RESULTS_20261022.md)的描述，不是重新分析或证明低秩等效。

旧K59的“最佳每矩阵rank8保留8.20%平方范数”受[已公开上下文更正](../cpu_update_space_20261020/v1/CONTEXT_SCOPE_CORRECTION.md)约束，只是指定重建精度系数几何；不能当实际autocast前向谱，更不能当从头训练LoRA的F1上限。即使先有严格实算的大逐矩阵重建误差，它也只排除那种权重近似，不自动排除另一组权重实现相近功能。

## 自行推导：一个非恒等功能的两层反例

只讨论精确算术、两层线性网络、无偏置/激活/dropout。基座两层均为I₂，功能为x。假设某teacher的两层是

\[
W^*_1=\operatorname{diag}(2,3),\quad W^*_2=\operatorname{diag}(2,2),\quad
W^*_2W^*_1=\operatorname{diag}(4,6).
\]

每个teacher相对基座的变化都是rank2，不能由rank1增量逐矩阵精确重建。但另一个候选可取

\[
\widehat W_1=I+\operatorname{diag}(3,0),\quad
\widehat W_2=I+\operatorname{diag}(0,5).
\]

每层增量只有rank1，而乘积同样为diag(4,6)，对全部输入恰好实现同一个、不同于基座的功能。这个反例否定“teacher各层变化高秩 ⇒ 相同功能必需每层高秩”的一般推断；它不证明当前Qwen/视觉模型r8足够、Adam能学到或泛化/F1等效，也不是给已训练teacher免费压缩的算法。

## 论文能支持什么，不能支持什么

[Zeng与Lee，ICLR2024固定v3](https://arxiv.org/html/2310.17513v3)直接研究模型功能匹配，而非逐层拷贝权重。§2 Lemma1在非奇异假设下给出线性深度与所需rank的关系；其Transformer设置§4.1排除skip connection，Theorem7还涉及指定矩阵和偏置更新。它是存在性/表达性论证，不保证当前带残差/GQA/门控FFN的模型r8、93步优化或最终回答质量。不能用论文的充分rank界倒推我们的最优rank。

[Shuttleworth等，NeurIPS2025最终版](https://papers.nips.cc/paper_files/paper/2025/file/ff541950d1e885af90f523571564a401-Paper-Conference.pdf)§5的持续学习采用RoBERTa六任务，每任务后合并LoRA再重新初始化，评测另重训分类头。我们的冻结TargetLoRA跨19阶段沿用同一组A/B，只重建优化器。只在精确算术中考虑没有其他参数更新的某个LoRA矩阵：前者最终相对基座可写成ΣₜBₜAₜ，rank至多min(Tr,m,n)；后者是单个BA，rank至多r。这是代数上界，不说明实际达到，也不能把任务数当有效维数；不是FP16实际前向的数值谱秩结论。该论文的intruder分析针对适配后权重W的奇异方向相对W₀的关系，不是K59的ΔW截断能量；不因观察到某种谱就直接断言我们存在同一遗忘原因。

[Biderman等，TMLR2024固定v2](https://arxiv.org/html/2405.09673v2)§4.2/4.3将编程/数学目标学习与原有/OOD任务保留分开考察。本项目BWT则比较已学习19任务的后续变化；两种遗忘对象不同。不能把标题“forgets less”当本实验LoRA必定更防遗忘的先验，也不能从OSFT习得较高/BWT较低推出容量唯一因果。
