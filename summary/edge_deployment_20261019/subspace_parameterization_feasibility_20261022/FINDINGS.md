# 下一项参数化研究的准入判断：两条直觉方案均不直接启动

问题是：OSFT较多的训练坐标，能否用功能上有依据的更简洁表示替代。原四组、完整LoRA_all负结果、同坐标对照及去保护包对照均已封存，原条件不再扩展。本文不新增F1、模型前向/反向/优化/GPU/TEST，也没有新READY或排队；新增的是会改变实施优先级的表示成本计算与识别条件。

## A：同保护块的完整核心，显式实现先停止

[已有双向集合推导](../update_geometry_literature_20261022/OSFT_PROTECTED_BLOCK.md)在固定阶段、精确算术下给出：
`Whigh + Ulow diag(Slow) Vlow = Whigh + QL C QRᵀ`，
其中C可为任意(m−h)×(n−h)，QL/QR为完整正交补基。113766144→71245824坐标和其中约束/因子冗余的区分是旧结果，本文不把它重新计数当发现。仅冻结原薄尾基、改用小方形C，在矩形层会缩小空间，不能冒充同空间对照。

新计算检查显式完整补基的代价。对原七位置的每个m×n层，d=min(m,n)、h=3d/4、p=m−h、q=n−h：

- 原全部高/低USV张量元素为`d(m+n+1)`；
- 显式补基为`mp+nq`；
- 核心C为`pq`；
- 高块保存为原因子`h(m+n+1)`或稠密`mn`，按每个位置取二者较省的一项。

| 原目标168矩阵所计张量 | 原USV | 显式完整核心（逐位置选较省高块表示） |
|---|---:|---:|
| 全部权重/基张量元素 | 455064576 | 1929637632 |
| FP32字节 | 1820258304 | 7718550528 |
| 两个同dtype Adam矩张量字节，另列 | 910129152 | 569966592 |
| 训练坐标 | 113766144 | 71245824 |

训练坐标减少37.375%，但所计权重/基张量增加至4.240倍。矩状态另列：原HostAdamW把其持久留在CPU，不能与GPU权重直接相加冒充某设备峰值。这里只计算原目标层；共享模型、bias、梯度、激活、SVD/QR与临时工作区、分配器/标量状态均未计，不是实测RSS/VRAM、整模成本或普遍下界。隐式表示可能不同，但尚未设计，不能凭“可能更省”启动新实现。

**行动：不建立显式full-core模型，不做其GPU小测。** 同表示集合的机制问题仍成立；未来若有明确且可核算的隐式表示，可另行评判。十九阶段各自重SVD后高基可分化，仍不能称全程同一保护块。

## B：固定尾方向只学S，先解决识别条件

[SVFT固定v1](https://arxiv.org/html/2405.19597v1)把更新写成固定完整奇异基中的系数；plain只调对角系数，非对角系数允许交互。其语言任务plain学习率示例为0.05；论文结果不能证明本设置只调标量就足够。

[SVFit固定v1](https://arxiv.org/html/2409.05926v1)训练顶部奇异值，GLUE表I使用0.001–0.02学习率和多epoch；拟议控制则是OSFT原25%尾部，不能称作者复现，也不能借其图像/奇异值能量叙述证明本模型尾部对回答无用。截去高奇异方向后的正交补，不等于整个预训练权重的零空间。

由原形状，只学各阶段Slow需28416标量。这不是实测充分容量或推理压缩：保留原USV张量时，只冻结U/V并不会消除其驻留成本。它可以检验“固定尾方向、调幅度的替代是否保留功能”，不能仅凭坐标少宣布方向学习多余。

两个识别问题阻止当前直接训练：

1. S-only天然仍留在高子空间正交补内，只是一个对角线性子空间；NoProjection允许低因子进入高子空间。两者即使都不执行投影回调，也不共享实际保护约束。若问方向学习，原受保护OSFT才应是主参照，NoProjection只能作背景。
2. 改参数化后相同Adam学习率不匹配权重步幅。直接沿用1e-5/87步所得负结果，只否决这个配方，不能证明方向学习必要；根据现有DEV试多个LR也不提供干净识别。

**行动：不启动S-only训练，不搜LR。** 若未来继续，必须先在不使用DEV/TEST挑尺度的前提下，提出有依据的有限更新预算及步幅安排，再考虑只一个条件对比原保护OSFT。阳性也只支持当前设置下方向更新尚未显示必要，不是等效/普遍可冻结；阴性须先排除明显步幅不足，否则只是又一个固定基负例。
