# 隐式补基的后续阅读线索：未选择新实验

此前显式补基表示的4.24036倍张量计数只是该具体表示的成本，不能作为所有表示的下界。当前归一化先导的阴性结果也不能证明OSFT的全部原始训练坐标都必要。这两个边界仍保持。

本轮只核对了一条可能的表示路线，没有分配张量、运行算子或模型：[LAPACK官方说明](https://www.netlib.org/lapack/lug/node128.html)给出以Householder反射隐式表示并作用Q的方法，无须先形成完整Q。[PyTorch v2.6.0文档源](https://github.com/pytorch/pytorch/blob/v2.6.0/torch/_torch_docs.py)说明geqrf将R与反射信息存于同一数组，ormqr可应用该表示；[同版本反向源码](https://github.com/pytorch/pytorch/blob/v2.6.0/torch/csrc/autograd/FunctionsManual.cpp)的ormqr_backward对other梯度调用转置的ormqr。这里只确认软件原语及其反向规则存在，没有验证本矩阵/设备上的数值、内存或速度。2.6网页未能通过当前网页工具访问，故核对固定v2.6.0源码，不能用main文档的当前行为替代。

尚需论证的问题是：能否固定原高子空间，以隐式完整正交补上的自由矩形核心表达同一允许集合，同时使基、常量、梯度、完整临时矩阵和工作区的合计成本可接受？仅说核心坐标少37.375%不够；完整模型初始化/原forward数值与原阶段重SVD、以及改变参数化后的优化几何/有效步幅仍是未解条件。没有这些证明，不启动新模型或用它替代当前已结束条件。

固定基中间小矩阵也不是原创想法：[LoRA-XS固定v1原论文](https://arxiv.org/html/2405.17604v1)采用截断SVD的冻结左右投影及可训练方形核心。本问题若继续，必须区分小r×r截断子空间和矩形权重的完整正交补，不能把旧rank16负结果当作后者结论，也不能把软件表示替换当作新算法。检索还发现HOFT题名，但其OpenReview正文被验证页面阻断，本轮未读到，尚不能判断其与此问题的关系。

这份阅读记录没有READY、worker、性能结果或自动实验义务。先判断科学区分能力、完整成本和文献关系，再决定是否值得做具体功能对照；不重复旧谱/CPU准入，不恢复显式完整核心或S-only，不搜LR/精度，也不据TEST救旧方案。当前NormOnly固定配方按独立协议结束。
