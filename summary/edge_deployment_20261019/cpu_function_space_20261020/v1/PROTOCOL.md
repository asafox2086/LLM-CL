# CPU小型功能空间对照：权重难低秩，不代表输入上的作用难低秩

## 问题、证据和用途

K59测得正式OSFT更新的最佳逐矩阵rank8近似只覆盖8.20%权重能量；它没有测量真实输入上的输出误差，因此不能据此排除轻量表示。SVD-LLM（ICLR2025）明确区分权重误差与激活加权输出误差。本次借鉴这一视角，**不声称复现其白化／逐层恢复算法，也不包装成原创**。

对同一个实际更新ΔW、相同rank8，比较原始权重SVD与按训练输入学习的输出子空间。若另一组输入上后者仍明显减小误差，继续考察功能空间保存；若仅校准集变好或不改善，不把小参数表示可行性当成既定事实。两种结果都会改变下一选择，原四组GPU小测不变。

这一步与最终端侧目标的关联是检查哪些学习变化能用小空间保留；**只压ΔW不会自动缩小完整基座**，因此不能据此宣布包、RAM、速度或最终F1优势。后续结构改造仍需完整模型质量和成本，不预设两个模块。

## 固定对照

- 使用原正式OSFT最终checkpoint和基座，身份承接K59完整SHA。CPU两线程、nice10、FP16参数／计算条件不变，分析乘法及SVD用FP64，禁止以更换模型dtype获益。无GPU、优化器、生成或TEST读取。
- 只读原TRAIN和已冻结的1213FIT／100DEV划分。按`sha256(cpu-function-space42:原图像组ID)`选每域两个不同FIT图像／场景组，各取ID字典序第一QA：第一组校准、第二组探针，共5＋5QA。两组与原DEV均不重叠。该数量是CPU测量预算，不是最优超参；不覆盖所有19任务，不能证明1%数据本身不足。
- Teacher已按完整1313TRAIN学习，包含上述QA及原DEV。因此这里“探针”仅表示**拟合近似子空间时未用该组输入**，不表示teacher未见数据或任务泛化评价。不读取DEV答案来筛选方案，不用本轮选择GPU四条件或正式主表结果。
- 原图文处理、401408图像面积上限、512答案token上限与EOS沿用封存正式helper。teacher forcing原TRAIN答案，采集每个答案预测位置的真实线性层输入，不删图片、不挑token、不改答案格式。
- 固定全部24层q投影与24层FFN down投影，共48处，不按谱或性能选层。在每层分别测：零更新、ΔW最佳权重rank8、在5个校准QA上对ΔW·X做输出PCA后得到的rank8左投影。输出PCA条件为U8·U8ᵀ·ΔW；与权重rank8具有相同最大秩，但不是同一个空间。
- 所有子空间只由校准输入拟合。独立图像组探针上的参考是同一teacher的ΔW·X，不含跨层误差传播；报告每题、每域、每层误差、校准与探针结果，不选最佳层或方法。少校准数据／teacher forcing／仅48投影是局限。
- OSFT原线性核先在原CPU输入运行一次，再常规折叠为相同实际FP16权重。原CPU首题NLL与折叠后须逐值相同；折叠只是测量准入，不算方法收益。其余9QA各一次前向，总11次图文前向（首题两次），没有反向。折叠后的原参数SHA前后不变，hook仅观察输入不改输出。

## 投入、出口与解释

预计CPU数十分钟至约两小时，原样跑完全部10QA；两线程、不占GPU、不打断基线，所有输入与分析开销计费。120分钟墙钟预算若不足则记INCOMPLETE，不用部分结果冒充完成，不截短原图或答案挽救。

完成需：冻结ID／原图及源SHA、首题原CPU与折叠精确、10题×48处完整输入、原NLL有限、每层两个rank8条件及零更新参考、图像组无交叉、无CUDA初始化、模型参数不变、完整证明。私有激活不入Git。故障保存、独立版本修复，不热改／盲重试。

论文依据：[SVD-LLM原文§3.1](https://mi-zhang.github.io/papers/2025_ICLR_SVD-LLM.pdf)；[Dobi-SVD（ICLR2025）](https://proceedings.iclr.cc/paper_files/paper/2025/hash/218ca0d92e6ed8f9db00621e103dc70c-Abstract-Conference.html)也研究权重截断与激活截断区别。均不是我们的0.5B／1%场景效果证明。本轮不开展量化／精度／算子卡常。
