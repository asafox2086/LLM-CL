# 已有参数、名义mask与实际更新：PaRSP/SpaRTA封存记录审计

## 问题、意义和行动出口

不再靠分钟级存活轮询维持研究。现有四方法分析未系统覆盖完整PaRSP/SpaRTA。这两者能说明“直接更新已有参数”和“新建双秩/路由”的差别，但不能凭方法名、名义40%神经元或低rank认定可删除前向结构。

本轮问题：PaRSP的名义区域限制是否等于实际最终参数变化范围？SpaRTA每200更新的恢复机制在本次93主更新中是否执行？两者最终分数不足，是刚习得与后续变化的哪一种记账现象？

先核对冻结源、原论文、原证明，再只读两组sealed预测/日志重算原Answer F1，读取19阶段PaRSP选择与实际最终权重。原模型/数据/训练和GPU队列完全不改。两个方向的结果都有用途：若实际变化越过名义mask，不以mask比例宣称有效更新自由度或可删性；若没有越过，也不将坐标稀疏当功能无用。未执行的恢复机制不启动昂贵“关闭它”的恒等消融；不据本分析选路由/比例/层/rank或融合TEST答案。

## 固定分析及核验

1. 复用已冻结sealed_baseline_tradeoffs_20261021.py的评分/ID/全部原参考/SHA复算逻辑，只增加PaRSP和SpaRTA两个此前未覆盖的sealed运行。原四组不重算；比较其已封存汇总。各组19正LR/93主更新/74格完整证明仍由原采集器提供，本文重新核S0/习得/最终必要格，不能称再次验证全部74格。
2. 绑定实际run config、runner_source及作者mask/projection源码、19阶段aux选择文件、训练日志与checkpoint SHA。读取PaRSP的stage_19既有完整图并map_location=CPU/mmap，仅检查参数，绝不调用forward/generate/训练。此项会反序列化既有模型图，不假称“没有加载权重”；不加载SpaRTA模型。
3. 由各阶段有效选择构造每个矩阵的**投影前名义mask并集**：q/k及bias不受逐神经元mask；v是行、o是列、gate/up是行、down是列。只计算weight矩阵。未选中的层不计入；有效索引需按GQA真实尺寸过滤，空索引或缺少该层neurons导致没有注册hook时，该阶段视为整矩阵允许。原/最终张量共同提升FP64后精确相减，不能把最终FP32先降FP16。统计168矩阵的实际非零变化、并集外非零/平方范数，不据能量选层或宣称贡献。
4. 独立固定4×4 CPU控制，u=(1,2,3,4)/sqrt(30)，P=uuᵀ，C=I−P，列mask只允许前两列，G=1..16。检验mask→P、P→mask不交换，实际torch梯度hook顺序匹配手算；行mask控制保留零行。另用一个零初始化4×4张量做1次原AdamW（lr=.001, betas=.9/.999, eps=1e-8, decay=0）与SGD几何对照，区分被投影梯度与优化器实际步。只有这个小张量有一次合成optimizer调用，0模型优化/前向/QA/GPU。该控制证明实现性质，不能当0.9B实测效应或F1归因。
5. 从实际SpaRTA日志核93主更新，原run调用链确认after_update每主更新一次、global_step跨stage累计且preflight不调用，推得恢复触发0。读取PaRSP原stdout的[Force]/[Auto]等现存记录，无法唯一解析则保留原文本来源与未解，不拼计数。

## 预算、解释与停止边界

一个低优先级CPU分析进程，1数值线程/interop1，CUDA_VISIBLE_DEVICES为空；预计数十秒至数分钟，上限15分钟，在读取/矩阵工作项边界检查预算。只读完整OLD既有artifact，NEW当前CPU推理继续。输出无模型/原QA/原预测；报告资源峰值只属本分析，不是端侧部署。

来源/映射/维度/SHA有错则留FAILURE，不热改冻结源、盲重试或拼部分结果。未来如需修复另立版本。结论必须分开：源层梯度约束、Adam实际更新、最终累计ΔW、原Answer F1、完整部署成本。PaRSP无weight decay、逐stage重建optimizer仍不保证Adam预条件保留投影子空间；最终并集外变化不能单凭此归因F1。删除训练定位/协方差状态对所有基线公平，不算稠密网络变小。

只在全部记录核验封存后写结论。当前GPU1四条件与CPU两支半宽对照均不改；本分析不能把主表Ours或部署空白填数，完整目标尚未完成。
