# 为什么已有增益值得作功能替代对照

这是一段源码结构与精确算术下的代数解释，不是新的训练、谱测量或质量结果。它说明本先导的干预含义，不由结果倒推机制。

令单处RMSNorm的归一化输出为z，增益为γ。忽略有限精度舍入，在该处固定输入时，后续冻结线性映射的输出是

`y = W diag(γ) z + b`。

因此增益变化δγ在这一线性映射前对应

`δW = W diag(δγ)`。

每个输入通道只有一个缩放量，其列方向被W的原列固定。若多个投影接收同一归一化输出，它们共享δγ：注意力q/k/v同步缩放各自对应的输入列；MLP gate/up同理。原架构的调用与共享输入关系已在固定Transformers4.46.3源码作静态核对，SHA与布尔检查见SOURCE_GRAPH_METADATA.json；不载入模型或新跑前向。

这不是任意新矩阵，也不是直接学习新的跨通道混合方向。另一方面，少量标量不意味着逐矩阵低秩：例如W为二阶单位阵、δγ=(a,b)，且a、b都非零，则δW=diag(a,b)的秩为2，虽然只有两个标量。这是自设精确算术例子，没有合成张量实验；不能外推真实权重的秩、整模Jacobian维数或质量贡献。

由此有一个可检验的功能替代假说：预训练已形成的特征与混合结构若足够，调节其相对通道强度也许能完成当前适应；若需要独立旋转或解除多个投影的耦合，这个更新集合可能不足。两者均未被本代数解释证实。深层网络还有残差、非线性、注意力与上下游增益交互，单处公式不证明整模能表示任意LoRA更新或原OSFT行为。

本先导又明确保持原FP16 forward增益，实际使用的是FP32主副本转回FP16的值；小步幅可能被舍入。因而最终记录要分开主副本与实际增益变化，不把FP32更新数当作实际函数更新数。这个配方与论文的数据、模型和学习率选择均不同；无论结果正负，都不能单独辨别空间限制、优化步幅、预算或数据量效应，也不能宣称已有参数普遍足够或新增参数普遍必要。

这不是“参数少，所以应该有效”的论证。功能替代是否成立仍由固定两锚对照的原Answer F1回答，边界及停止条件保持原PROTOCOL/READY，不追加新条件。
