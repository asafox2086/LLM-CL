# 全冻结TRAIN图像视图统计

把已有五条TRAIN输入的重复现象扩展到完整冻结1313TRAIN／19任务，分别按QA引用和唯一源图像计数。仅处理训练文件和原图，无模型／GPU／TEST，不读取TEST答案，不改问题、答案、图像或划分。不据此选择压缩比例。

按原公共函数完全相同的401408像素上限、BICUBIC和原processor.image_processor处理；五个预定TRAIN请求须先与冻结原输入函数产生的全部视图逐SHA相同。之后对每个源图像各视图的完整像素字节计算SHA；重复哈希还需torch.equal确认。只统计同一原图内部的精确重复，不做近似去重／跨请求缓存或改变视觉位置。

保存每个源图路径、原文件SHA、尺寸、处理后视图数、精确唯一视图、索引映射及哈希；不保存像素、问答正文。原生任务／领域标签仅用于统计，不能用于推理路由。GPU探针科学设置不因统计而改变。

结果仅说明冻结训练池中有多少重复计算候选；不能将少了多少视图直接当作速度、显存或完整质量收益。GPU数值、端到端成本、完整21454QA和跨代表方法／骨干确认仍待。不是1%数据造成冗余的因果证据，也不推广未统计的测试图像。
