# 这项删减为什么值得检验，尚不能证明什么

本说明响应2026-10-20用户“优化要有根据”，仅补充解释，不修改已冻结协议、源码、数据或运行条件。

| 问题 | 当前依据与正在检验的内容 | 可接受的结论 |
| --- | --- | --- |
| 为什么这些通道可能可以替代？ | 假说：部分通道在所测输入上的变化小，其平均输出可用常量补偿。比较同半宽的权重排序与输入波动排序，二者都补偿均值。 | 只有真实质量与成本结果才能支持本方案局部可行；这不是已经证明通道无用。 |
| 为什么删一半？ | 一半是预先固定的完整成本试验点，预计减少约32%参数，并非观测得出的冗余比例。 | 结果只能评价该固定配置，不能称最优比例或“一半参数不需要”。 |
| 是否回答“哪些参数不用新建”？ | 该实验压缩已有模型，没有比较新建与继承。K60也只比较局部近似误差。 | 两者均不能证明新增LoRA没有必要；该问题需独立的新建/继承/更小替代对照。 |
| 什么结果值得继续？ | 三条件保留全部正负结果；若半宽质量明显破坏，停止该配置；若局部质量保留且实际成本改善，才研究独立DEV筛选。 | 五个已见TRAIN探针不代表五域质量；正式提升须完整确认。 |

“训练不充分”只能提出更有效使用有限数据的动机，不能作为直接删除参数的依据。未来优化须满足[参数必要性证据规则](../../../../rules/031_evidence_for_avoiding_parameters_20261020.md)，并公开完整成本与结论边界。
