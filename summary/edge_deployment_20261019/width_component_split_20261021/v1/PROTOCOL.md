# 两支FFN同时半宽失败：补齐视觉/语言隔离对照

## 问题、已有证据与干预意义

K61原完整/同时半宽fluctuation已严格重载，5道固定teacher已见TRAIN平均原Answer F1为47.088608/21.754386，完整包少31.701%。它没有区分视觉半宽、语言半宽和两者组合造成的损失。不能由此判任何一支无用，也不能断言所有无恢复压缩失败。

独立评审建议暂缓PAS固定混合局部拟合：即使可折叠，通常也只是达到OSFT常规折叠的同大基座，不足端侧目标。本轮补齐原2×2缺少的vision_only和text_only，直接测完整模型功能与完整成本，原dense/joint两格完全复用封存结果，不重复原prepare、校准或三条件。

## 结果用途与结束边界

逐题和5题等权：ΔV=F10−F00，ΔL=F01−F00，I=F11−F10−F01+F00，校验F11−F00=ΔV+ΔL+I。I只是在原F1尺度的非加性记账；地板、共同失败和有限题数均会影响，不叫协同机制、显著性或总体因果。

- 某单支五题逐题原F1均不低于dense且实际完整包减少：才仅保留该固定条件用于未来FIT teacher/独立DEV，不立即完整TEST或填Ours；这只是固定TRAIN可行性门槛，不把“不显著”或过门槛当等效/泛化。若均分改善但有题下降，仍不通过本门槛，不自动调整标准。
- 单支崩溃：停止该固定半宽/原mask/无恢复条件，不否定整个视觉/语言压缩类别。
- 两单支保住而joint失败：后续避免直接同时删两支，须解释跨模态功能承接。
- 两单支均失败：停止当前无恢复路线，不调比例追5题。未来恢复必须另立功能依据和成本预算。

无论正负均公开全部两新条件与原两格，不能按TEST挑层、路由或超参。没有从小测自动转21454的路径。若需要后续筛选，必须仅FIT训练teacher、独立100DEV，再全部1313重训及21454确认与同设备完整部署。未达到五域质量与端侧完整目标。

## 成本与保护

仅一个CPU模型worker串行，CUDA_VISIBLE_DEVICES为空、nice10，不占GPU。prepare上限2h，两case各2h（原完整case实际5205.7秒，留共享负载余量），共最多6h串行预算；检查点前预算断言，不是强制杀GPU或旧基线。预计两个新增完整包约各1.4–1.6GiB，实际为准；不是新增预训练数据或训练。原校准/teacher与历史失败费用仍另计。
