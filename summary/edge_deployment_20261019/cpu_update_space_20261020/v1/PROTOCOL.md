# CPU实测：最强方法的实际更新，普通低秩空间能表示多少？

## 意义与出口

已有同骨干正式结果中OSFT优于顺序LoRA，但它同时改变更新位置、训练空间、投影及学习率。此前几何分析只看三个native单步LoRA，本次首次检查**正式1%完整训练后的OSFT与SeqFT权重变化**，不重复单步审计。

问题是：OSFT实际新增的变化集中在哪里，是否主要属于低秩变化？如果普通rank8连这些变化都难表示，不能只靠增加位置假设可复现收益；如果能很好表示，则不把“必须有巨大更新空间”当作既定事实，后续仍需小测验证能否学出来。参数能表示不等于少量数据能学到，权重能量不等于任务重要性。

## 固定测量

- 只读同一OneVision基座，以及已封存的正式SeqFT、OSFT最终checkpoint。绑定原文件SHA、原配置、168个OSFT投影和48个SeqFT q/v实际张量。CPU两线程、nice10，不占GPU，不重训，不读取QA、TEST预测、答案或分数，不改变原模型或活动队列。
- OSFT用原作者核及原output_dtype重建实际前向使用的权重，再减原基座。记录每层每类投影的绝对更新平方范数、相对原权重幅度及完整奇异值谱。
- SeqFT使用原scale×B×A的代数更新（不能宣称合并后逐位等价原混合精度前向）。记录相同量；低秩谱同时用小矩阵QR核独立检查。
- 固定报告rank2/4/8/16/32/64/128/256最佳近似保留的更新能量，以及90%/95%/99%能量所需秩、参与率有效秩。8来自原基线，其余是预先固定的2次幂测量网格，不是DEV/TEST选出的超参。此处不采用任何秩修改模型。
- q/v共同位置报告两方法最终方向余弦，以及OSFT更新投到SeqFT最终LoRA局部切空间的能量，并报告该切空间维数占整个矩阵空间的各向同性参考；不把低覆盖自动判为坏方向。
- 区分可训练坐标数、局部权重空间维数、完整有限更新。OSFT的局部保护块维数不是19阶段整体可达维数，不能用末态切空间替代整个训练轨迹。
- 预定layer0/q与layer23/down另外复算实际更新范数和SVD截断残差，所有168矩阵都检查谱能量与直接范数一致。先小矩阵已知谱和投影正控制，再冻结源码与协议。

## 必须保留的边界

OSFT末态减基座同时包含历次分解、重建和原数值条件下的变化，不能全部命名为有用学习；本次不新增精度试验。比较两种代数权重变化不等于比较输出、梯度或唯一性能原因。不同学习率、参数化和投影未隔离。最终权重空间是训练产生的观测，不用任何TEST答案选择方向、位置或容量。

本轮输出全部谱、位置汇总、相对幅度和可表示性表。没有新F1、部署包、内存或延迟优势可宣布；低秩近似只是端侧结构改造的可行性证据，不能据此删除参数或填Ours。正负结果都会报告，不自动启动完整测试。GPU1原四组小测与两机基线均保持原样。

预计加载两份既有checkpoint并做168个CPU矩阵分解，数分钟至数十分钟；使用两个CPU线程，真实耗时与RSS另记。完成边界为全部168+48矩阵、独立残差核验、原文件身份未变及COMPLETE证明。失败保存原证据，不覆盖、不盲重试。
