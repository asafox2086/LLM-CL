# 题型辅助监督v2：保留学习问题，修正配置检查

目的仍是检验：同一个小q/v-r8，在训练期加入真实题型监督，是否比普通答案CE和同频打乱题型监督更有效地习得金融回答功能，同时保持单图部署成本。当前没有三臂质量结果；v1普通分支在完成训练后的导出检查失败，不能据此否定方法。

已只读加载原可信S15到CPU检查配置，不进行前向、生成或训练。两层generation公开配置与从model config派生的字典完全一致，SHA均为`b44055c7c9efed87ef181b146c0f07fb4f954aa66dce382e1180259785212de6`，非默认generation覆盖为空；保存的Python对象hash在新进程不匹配。证据见[实查JSON](TYPE_AUXILIARY_S15_CONFIG_20261027.json)。这说明不能用进程内hash作为跨进程配置不变性标准；不声称已还原失败plain导出时的丢失对象。

v2只修复该检查及复用来源接口。导出、S15重载及最终严格重载均核公开配置与原S15相等、稳定SHA相等、`_from_model_config`保持true、非默认generation覆盖仍为空。不修改原对象hash缓存、HF生成路径或原最终loader，不改学习损失、数据、split、rank、lambda、优化器、步数、生成上限或评分。

复用v1真实成功的完整S15与RNG，各分支独立从同一点开始。原120条前缀回答未评分，本次与三个后缀共同一次评分；不复用失败plain的后继状态。旧prefix来源、原source map、CP和全部封存文件SHA、原成功EXIT与进程退出单独核验，不把旧证明改写成v2生成。旧失败RUN、18次plain更新和所有费用保留。

训练方式沿用v1：共享q/v-r8共540672坐标，金融阶段辅助头2691参数，lambda=1；普通CE、真实题型、seed42保持频数的打乱题型三臂；头在金融阶段后删除，后续交通训练及最终fold/strict reload不变。训练头初始化不消耗全局训练随机流。原1213FIT/100DEV、19任务、单轮轨迹不变，其中公共前缀959FIT/69更新、各后缀254FIT/18更新。

v2新执行六阶段：plain train/eval、true train/eval、shuffled train/eval，同一原分配器提供GPU并串行。每train2400秒、eval600秒，共9000秒，首次各阶段STARTED计时；首次真实故障关闭本次v2，不热改、不重置预算。新成本555次生成（含15资源窗）、54更新、762FIT；复用历史前缀120生成/69更新/959FIT单独列。完整后唯一评分660对象，未完整不评分、不填Ours。原v1费用不抵消也不冒充新运行费用。

判断：真实监督须在金融刚习得原F1同时胜plain和shuffle，才能支持本训练监督整包的净收益；还须看去头后的最终五域宏、完整参数/权重及原五窗GPU成本。只胜shuffle、题型头准确或单字母减少均不足。真实与打乱同升不能归为题型语义作用。多选DEV仅4题，结果只作方向筛查，不宣称稳健显著或正式胜强基线；不据DEV追调lambda/rank/epoch。负结果关闭此固定配方，不推广为所有辅助监督无效。
