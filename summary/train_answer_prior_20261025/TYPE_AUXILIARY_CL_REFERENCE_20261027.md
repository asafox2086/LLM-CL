# 题型辅助监督的有限CL借鉴

[CPrompt：Consistent Prompting for Rehearsal-Free Continual Learning](https://arxiv.org/html/2403.08568v2)，§3.3 Eq.9及§4.4 Table11：在随机选择这一路径中，当前prompt只有1/t机会被选，作者增加独立辅助分类器，用真实类别监督补足当前prompt训练。1/t不代表所有损失路径的总更新机会；CCL和辅助损失另有当前prompt路径。其推理仍有prompt池和multi-key选择。

可借鉴的是将辅助训练目标与最终预测结构分开考虑；不是把训练模块全部永久带到部署中。该论文的辅助标签是图像类别，不是我们的回答题型；其1/t训练机会机制也不是本项目已经观测到的问题。不能据此声称我们的共享LoRA存在同样的训练饥饿，或将CPrompt称为无路由题型辅助方法。

当前方法从本项目已有的单选／多选回答功能差异出发，使用原TRAIN题型监督同一小LoRA，T16后删除辅助头。这是待实验的适配，不是论文已证明的迁移收益。本次文献核对不更改冻结三臂、不追加任务或超参搜索，也不把已有辅助学习机制称为首次提出。

独立子agent已核原文Eq.6、9、12与Table11，接受上述有限借鉴。我们的共享q/v对每条QA都有答案CE训练，不能套用其随机prompt选择导致的训练机会减少解释。没有新增模型、QA审计或评分。
