# 本轮功能检验能支持多大的论文结论

三臂实验检验的是：额外TRAIN题型监督能否让一个共享小LoRA学到更好的金融回答功能，移除辅助头后仍有效。它不是已经能够追平全部强基线的框架。

依据根README现有1%正式表的三位小数：LLaVA普通LoRA最终五域宏42.186，PAS46.620，差4.434；金融分别15.891与25.223，差9.332。若只把普通LoRA的金融提高到PAS水平、其余四域完全不变，五域宏提高9.332/5=1.8664至44.0524，仍差2.5676。这个替换计算只是量级边界，不是预测、实验结果、质量上界或因果估计；金融也可能超过PAS，其他域也可能变化。不能用它提前填主表。

因此，本轮即使金融有效，也必须报告最终五域DEV，并在正式实验中判断总体质量—内存取舍；仅多选DEV四题的改善不能证明总体竞争力。若功能对照不支持，不继续追辅助权重、换划分或改评分来挽救本配方。

现有已完成的另一项普通共享r8部署测量为1704.550842 MiB完整权重、2166.100586 MiB固定五窗GPU峰；PAS正式保存态2241.552 MiB、同一窗口定义实测2959.415 MiB。相对差约23.96%权重和26.81%固定窗口GPU峰，说明这类小图存在值得检验的成本空间。**这些不是新辅助方法的实测值**，也不是全TEST最坏峰；不同权重的实际激活仍须新方法重新测量。不能把普通LoRA本来已有的低成本单独称为新机制贡献。

本方法若有效，论文证据应是：已观察到的回答功能差异 → 额外监督的有限对照支持 → 同小图保持低成本且总体质量有竞争力。现阶段只有问题观察和实现准备，后两项未证明。原正式表、数据、超参和生成评分设置均未改变。
