# 两项直接相关的先例与本轮边界

2026-10-26，root核原作者库与原论文摘要；仅用于选择功能对照，不新增模型或扩展方向。

1. [HydraLoRA作者库](https://github.com/Clin0212/HydraLoRA)明确展示同参数量下拆分小A/B的对照，并以共享A、多个B实现非对称适应。故“同预算分片”与“共享/专门化”不是本项目的原创新概念。可以借鉴其把功能和参数复制分开的思路；其结果不证明我们的两组r2能承接多模态持续新习得。
2. [Rethinking Parameter Sharing for LLM Fine-Tuning with Multiple LoRAs](https://arxiv.org/abs/2509.25414)指出其研究中的A相似性主要可来自相同初始化，并提出多个A、共享B的另一种设计。此处只援引摘要所述边界，不把它扩展成我们的参数测量结论。不能从相似A、同rank或同初始化推断知识共享，必须比较真实回答。

因此首轮保留Shared、Uniform、Soft三臂即可：Uniform控制私有部分固定缩放，Soft对Uniform检验输入条件功能。没有必要先实现额外W0前向、聚类或复制更多专家。若正结果成立，贡献需落在固定小预算下的新习得与完整部署取舍证据；不能把几个既有组件的组合直接称为已完成创新。若负结果成立，记录并舍弃条件模块，不为追逐新颖性增加结构。

PAS的逐token A响应能量机制来源已在原提议中给出；本轮复用一次dropout后A响应，不宣称复现PAS整包或精确相同路由算子。训练曝光、任务顺序、量化/精度和测试规则不因文献建议修改。
