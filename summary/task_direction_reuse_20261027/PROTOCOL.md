# 当前任务梯度方向：固定预算功能对照

本协议定义独立 FIT 探索，不是正式主表结果。冻结源以随后发布的 binding 为准；尚未启动 GPU。失败及负结果保留，不增加校准样本、rank、训练步数或执行时间救结果。

## 问题与可证伪解释

已有宽 q/v 更新提高质量却增加约 8.14 倍活动训练坐标；这并未证明小 rank 的失败源自方向选择。本实验检验更窄的问题：在相同小活动空间、阶段合并机制、计算和数据曝光下，当前任务梯度提供的初始化方向是否改善新习得和最终回答。

借鉴 LoRA-GA 的任务梯度初始化思想，但不复现其双非零初始化或首步近似定理。每阶段先合并已有 LoRA 到共享权重，再以当前任务梯度的前 8 个右奇异向量初始化 A，B 为零。对照采用随机正交行方向，保持相同行范数。两臂 A、B 都可训练。

## 两臂与训练合同

- aligned：A = (1/sqrt(3)) V_top8，B = 0。
- random：A = (1/sqrt(3)) Q_rows，B = 0；使用独立私有随机生成器。
- 同一 LLaVA-OneVision-Qwen2-0.5B-OV 骨干，q/v-r8，alpha32、scale4、dropout0.1，96 个 FP32 A/B 张量，共 540672 个活动坐标。
- 每臂 1213 FIT、100 DEV、19 任务、87 次原主优化器更新；原数据顺序、训练 AST、学习率、生成与评分合同不改。TRAINING_PLAN.json 记录各任务固定样本数、次序摘要与更新数。
- 每阶段校准只读当前任务原 FIT 顺序前 min(16,n) 条，QA 等权，估计 dense q/v 梯度，无优化器更新。两臂都计算相同梯度和 SVD；random 丢弃梯度方向。每臂额外 208 次校准反传，主反传 1213 次。
- 校准后恢复随机状态、模块模式和 requires_grad；临时 FP32 梯度权重恢复原 dtype。校准数据不是额外主更新，不隐去其训练峰值、反传数和时间成本。

阶段合并可能有 FP16 舍入，必须记录；B=0 保证的是新分支输出为零，而不是所有合并操作精确等函数。每阶段首步 A 梯度为零，单步任务不学习 A，是两臂共有的代价。阶段累计更新秩可能增长，因此不能声称全轨迹只有 rank8 表达容量。

## 评估与证据

每臂保留各任务 before/acquired 共 200 次 DEV 生成，最终独立进程严格重载完整模型后生成 100 条 DEV 与五个原资源窗口。两臂合计 610 次生成，完整四阶段终态后唯一评分 600 条回答；资源窗口不加入质量分数。沿用原 token F1，不另做集合匹配、不改变选项处理。

同时汇报五域及宏平均的新习得、最终 F1，完整参数个数、保存态字节、增量参数、常驻 adapter、五窗口 GPU allocated/reserved、TTFT 和生成速度（以实际 producer 字段为准）。保留每层梯度与方向摘要、谱能量、范数、正交误差和合并舍入，作为执行与解释证据，不能单独作为质量改善原因。

最终合并为原 dense 形状，不保留专家库。完整参数规模与普通折叠 LoRA 相同，不是新的骨干压缩；对 PAS 等保存多个参数分支的方法存在成本优势的可能，但本方法必须以实际质量和 GPU 测量证明取舍。旧历史 shared-r8 仅作参考，不能用跨实现差值归因方向。

## 判定与边界

aligned 相对匹配 random 的跨域新习得和最终宏平均都有净收益，才支持当前任务方向的作用；不要求每域都赢。两臂共同改善只能归于两者共有机制，不能归因任务方向。无净收益则关闭此固定方案，不追 rank、层、校准数量或尺度。成本显著较低且质量可接受的点仍有后续论文价值，但不能把固定探索 DEV 的小差异写成正式强基线胜出。

不研究遗忘，不以最终阶段差异替代刚习得证据。不改 1% 或 10% 主表设置；有效探索须再经过完整正式协议才进入 Ours。

## 执行与留存

只通过现有 OLD 分配器提供的 GPU1 机会串行 aligned/train → aligned/eval → random/train → random/eval。研究前用已有阶段 checkpoint 暂停基线，研究结束进入分析时恢复；不向历史 PID 发信号，不创建第二分配器。

每个 train 5400 秒、eval 1800 秒，总模型预算 14400 秒，从各首次真实 STARTED 计时；不重试或延长。完整终态才运行唯一 verifier，失败保留原证据。最终完整模型、回答、配置、日志、来源及证明均转存耐久目录；tmpfs 不算耐久保存。启动确认后分段 sleep，按阶段完成或异常检查，不忙等。
