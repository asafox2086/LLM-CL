# 后继观测的价值筛选：先辨识事实，不设计方法

## 已否决：仅由PAS温度／logits解释小差异

独立observation_review审查现存原始schema：actual_softmax_input已减max并除温度，只能恢复专家能量差，不能恢复共同能量和；单个冻结温度也不能隔离温度、A范数或训练成因。因此，做softmax闭合或列τ分布不足以产生解释价值，本轮不消费该分支、不启模型。未验证的训练原因不能写成否，也不能靠低gate均值推常量路由。

## 仅接受一次窄核查：功能变化发生在请求内还是请求间

原生全局均值残差仍同时混合两种时间粒度。独立审阅认为，利用现存QA-phase矩及每QA均值，把两者和交叉项分开，能区分“每个请求近常量”与“同请求生成中仍动态变化”，有额外信息量。CL按请求固定的anchor与token路径使此问题尤其可辨识，但公式对PAS同样适用，不预设两法同结论。

只允许描述性统计：每QA完整prefix均值c_q使用未来生成位置，是oracle描述，不是可部署prompt路由；功能分解交叉项不可省，不用各项／总残差冒充解释百分比。仍仅1%两个模型，不能因此宣称多数CL／10%普适，也不设计去掉token路由的方法。源码及协议须先独审，再唯一读取已完成phase矩；无新模型／生成／CE／F1。

## 原论文对证据标准的提醒

[MC-SMoE（ICLR 2024）](https://proceedings.iclr.cc/paper_files/paper/2024/hash/3d09a88c3372cdb79401fde592ca4db8-Abstract-Conference.html)研究专家表示重叠，并将路由统计和实际压缩质量分开；这已有先例，不能把“专家多但有冗余”本身当首次发现。

[Equifinality in Mixture of Experts（2026预印本，§4–5）](https://arxiv.org/html/2604.14419v1)在不同的小规模语言预训练场景，以更新共线和scalar干预区分幅值放大与复杂组合；文中同时报告路由选择大多相同仍不意味着冻结路由无代价。对本项目的启发只是证据标准：描述相似／平均差小必须与实际功能干预、质量和公平容量对照分开。不能把它的预训练结论移植成我们的CL规律，也未由此开启scalar分支。

本轮原1%／10%设置和部署图不变。非扩展法的router指标不适用，不将其计作零变化来补普适性覆盖。FullFT及所有正式基线继续原设置恢复／运行。
