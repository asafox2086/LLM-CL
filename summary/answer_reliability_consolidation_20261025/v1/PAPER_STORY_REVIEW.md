# 论文方向独立评判

本评判只读取已核验的朴素r8、PAS、Qwen资源结果及方案/文献边界，未读取ARC任何partial。当前三臂质量未知，以下是事前解释，不是新结论。

**这个方向有条件成立，但故事应是“固定小模型容量下，何种历史约束值得施加”，而非新压缩结构。** r8训练坐标540,672，门新增0；最终图设计仍893,675,552个系数，与同样fold的朴素LoRA/I-LoRA相同。现有朴素r8的DEV宏38.775370说明容量小本身不足以保质；wide的45.085963伴随约8.14倍训练坐标，也不能算新模块收益。

资源优势可以作为论文的重要结果，但来源须拆清：同骨干相对PAS的完整专家表示，已有约13.61%系数及约25%五窗GPU优势；相对Qwen的约59.56%系数、55.15%–58.80%五窗优势主要来自骨干和表示。PAS/Qwen保留原混合dtype及未fold表示；这些是原实现测量，不是门创造的结构减重或最优部署证明。ARC自身终态峰值尚须等完整核验，不能直接借用朴素模型的数值。

| 三臂完整结果及简单锚 | 对方法选择和论文的影响 |
| --- | --- |
| gate宏同时高于original与shuffle，shuffle实际改变过对应关系，且gate高于Naive | 可保留这一固定答案代理适配，支持相对无条件约束与同数参考打乱的点估计净效用；再判断是否具备正式确认价值。仍不能证明所有中间态更好、梯度安全或视觉语义被保护。 |
| gate未高于original或shuffle | 不支持新增门的既定效用。若original更好，选择已借鉴的I-LoRA适配而去掉门；若Naive更好，承认ER/EMA整包在本点没有联合优势。已有方法可以使用，但不得换名字把负结果包装为创新。 |
| 只胜original、不胜shuffle；或胜两控制但未胜Naive | 前者不能区分样本对应与约束减弱；后者只说明门改善了该巩固配方，尚无相对简单锚的总体收益。均不足以据此选gate为主方法。若总体更高但部分域下降，按用户目标完整报告取舍，不以逐域胜负另设淘汰门。 |

选择性蒸馏、相对gold loss与随机同数控制均有先例，不能独立列为原创；对**真实max-hidden人工目标**作末层答案读出，是可以借鉴后验证的具体适配，不因有先例直接否决，也不因换成多模态CL自动成立。若上述正结果最终在合法正式评价中体现总体F1略高于最强参照，并保有实际资源优势，可讲“少数据多域QA的紧凑单模型学习”，并把完整观察和必要对照作为贡献。当前100探索DEV不能与正式PAS五域宏46.619976、跨骨干Qwen48.972351直接排名；AP另列，不改总体指标取有利口径。

**唯一后续决策原则：由完整自由生成收益和对照所证明的必要性决定保留哪些组件。** 门的NLL改善、开门率和较小最终图都不能替代这个判断；没有完整收益与必要性证据，就保留实际更好的简单已有方法及负结果，不按结果另开配置搜索。本评判不预设新实验或分支。
