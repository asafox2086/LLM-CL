# 四状态实测：未支持 OSFT 整体配对支持增加更多的假说

## 问题、实验和结果

本次检验：OSFT 相对 q/v 的合法 FIT 末态优势，是否伴随更多的原图文配对 gold 回答支持。原图和事前固定的同任务错图使用同一条问题、context 和完整原回答。两方法各自当前重建起点及原 1213FIT 末态，共四个独立状态，在同一 OLD GPU0、同安装环境和共同 processor 下完成。

61 条固定几何条件 DEV、488 次回答 NLL 已全部完成并由原唯一 verifier 核验。原图/错图实际 text token、占位、mask、position、grid 与 packed 形状一致；供图 SHA 与缓存键绑定，四状态同 view 特征内容及目标摘要相同，每个状态内，测量前后的全部模型参数和权重 buffer 摘要相同。0 新训练、生成、AnswerF1 或 bootstrap。完整标量、输入/特征绑定和成本保留，旧评分未重跑。

定义 C=NLL错图−NLL原图；DeltaC 为末态 C 减起点 C；D=DeltaC_OSFT−DeltaC_q/v。NLL 越低，模型在正确答案前缀条件下对该回答的支持越强；这不是自由生成 F1 或知识量。下表各域内部 QA 等权；总体严格沿事前五域等权。

OSFT 原图改善与自身 DeltaC 为正，但相对 q/v 的总体 D 为负，事前第三项方向未满足。故本固定诊断未支持“OSFT 整体增强原图文配对支持更多”这一候选依据。不能因此宣布两方法等效、无图像贡献或所有视觉机制被否定。金融 D 虽正，但两者 DeltaC 都负，只能说 OSFT 的配对支持下降稍少，不能写成金融配对支持增加。

## 比单一性能分数多说明了什么

医学中，OSFT 原图平均 NLL 从 9.1848 降至 1.4358，错图从 9.2867 降至 1.6622；q/v 原图从 9.1843 降至 1.3597，错图从 9.2883 降至 1.6254。换成所选错图后，大幅回答似然改善仍然出现，而原图相对错图的支持差只增加 0.1245/0.1618。不能把这批医学回答似然改善直接叙述为图像识别学习；同样不能把比值转成“约98%不用图像”或“98%来自答案先验”。

自然域两方法末态明显偏好原配对，OSFT 原图 NLL 1.2071、错图 4.2502，q/v 为 1.2507/4.3268；但它们自身的配对支持增加仍未呈现 OSFT 更大的方向。这说明必须区分“模型对图片替换有反应”和“OSFT 相对优势由该功能增加解释”。本次没有认定哪个领域所有能力更强，也没有将 teacher-forcing 支持当生成正确率。

## 结论、行动和未解问题

撤回用这项整体配对支持增加为 OSFT 相对 q/v 优势提供机制依据，不沿此结果增加视觉适应参数或决定删视觉。该固定诊断已完成，**不再换置换、放宽尺寸、追加 seed/题目、重做 NLL 或重算旧 F1 来追方向**。

答案先验、格式/语言适应、回答前缀、校准、可用知识提取及具体更新空间各自的作用仍未识别；“错图下也改善”不能在它们之间作唯一归因。当前也未解释 ShortFixed 的机制。后续若设计更小载体，仍须明确哪些原有功能可由它承接、怎样保留有限预算适应，再用同规模最少对照和完整权重/原 AnswerF1 验证。不能凭本负方向选择稀疏、缩宽或低秩结构，更不能把方法命名当创新。

这是对一个具体竞争解释的输入干预证据，尚未形成保质紧凑框架、参数可删性证明或端侧收益。论文与总科研目标未实现，没有自动后续模型/训练/完整 TEST。
