# 固定共享载体的起点功能检查：单构造方案

## 问题、依据和行动

主目标仍是论文型紧凑持续学习框架：最终完整权重下降、原 Answer F1 保留或改善；目前没有该成果。本检查只补一个必要地基，不能用它替代新框架。

现有 r200 起点和最终质量均不理想；四状态换图诊断又没有支持 OSFT 整体更强图文配对支持的解释。因此不能继续按“删视觉”或“每层低秩已足够”设计。新假说是：**用跨层共享和稀疏私有系数减少重复存储，同时从完整输入维数开始恢复，可否在一个固定完整成本点保留可用的首任务回答起点？** 它不声称满秩保证保真，也不证明 OSFT 的优势原因。

FiPS v6 §3 提供共享字典、稀疏私有系数及过完备初始化这一已知工具；其 §4.2 的恢复数据和预算不等于本研究条件。来源：https://arxiv.org/html/2411.09816v6 。本方案借用这一载体思想，不宣称发明 FiPS；联合 SwiGLU 功能恢复本身也不作为原创主张。

正结果只保留一个实际较小、首任务检查可用的起点，供后续框架必要性讨论；负结果关闭这个固定构造。均不自动启动 U/V 对照、完整持续训练、DEV/TEST，或另一个压缩工具。若没有起点，继续设计其持续适应律没有依据；若有起点，后续才可讨论哪些共享/私有更新必要。

## 唯一结构与真实成本

- 原 OneVision 基座与原输入政策。仅 72 个语言 FFN 的 gate/up/down 被替代；视觉、连接器、注意力、共享词表及其它参数完整保留。原稠密残差不暗存。
- 24 层按相邻四层分成六组。每组把 gate/up 的转置和 down 沿长轴拼接，执行 FP32 完整 896 维 SVD；不先逐层截断。共享 U 扩展为 896×1152，原有 896 列全部保留，额外 U 列为零；对应额外 V 取前 256 行除以 32。实数表示依据不等于 FP16 初态逐值相同。
- 每个 V 为 1152×4864。每组 U 联合服务该组全部四层、三投影；不是逐层依次改 U 后假定其它层不变。最终每个 V 固定保留 25% 的位置。
- 最终仅存 FP16 U、FP16 非零 V 与逐位 bitmap。U 每组只存一次；不得保存全部稠密 V、原始 W、完整旧 SVD 基或训练缓存。前向只临时展开当前 V，以两次线性乘法完成，不永久展开全模型；不实现新稀疏 kernel，不预判延迟优势。
- 事前设计值：最终权重系数 686,942,240；V bitmap 50,429,952 bytes；FP16 值加 bitmap 1,424,314,432 bytes，约为原 FP16 完整权重的 79.69%。这些是设计断言，不是实测。真实所有参数、权重 buffers、共享别名、bitmap、持久辅助状态及序列化容器都须计入。
- 同一原父也保存不含运行缓存/优化器的完整基准包。主要成本门同时要求最终完整权重值数与实际完整包 bytes 均不超过原父的 80%；参数减少但实际包不过不放行。其它运行内存、临时展开与计算费用另列，不能由包小推出端侧 RAM/延迟好。

## 合法数据、缓存与可观测范围

- 只原 S1 的 327 FIT QA / 325 已知组。使用原 SPLIT 的 FIT ID，严格排除历史 TRAIN 容器中的 DEV 行；不打开未来任务 TRAIN、原 DEV 或 TEST 作为模型输入/统计。325 组不代表独立图像。
- 以 `sha256('shared-fullspan-v1|' + group_id)` 排序；前 65 组仅作诊断，随后 32 组仅作恢复；每组按 ID 字典序取一个原 QA。固定后不按长度、损失、图像或分数换样本。图像 SHA、全部参考、输入合同绑定；公开报告不含 QA 正文。
- 教师只为未适应原父，未进行本地训练。32 个恢复 QA 各一次完整回答 teacher-forced 前向，捕获 24 层实际 FFN 输入和完整 SwiGLU 输出；不是 pooled 特征或分别三个 FC 的误差。包含实际有效视觉/问题/回答 token；不截取 token 子集来省成本。原父不更新。
- 缓存转为原 FP16，输入/输出均 CPU 独立保存。总 tensor storage payload 上限 8 GiB，元数据字节另计；超过即停止，不删 QA/截 token/换样本。恢复进程 RSS 与同 PID GPU allocated/reserved/NVML另记，8 GiB 不叫整机内存上限。
- 65 组诊断与恢复组已知 group disjoint。原父与最终实际打包重载模型各对这 65 QA：完整回答 NLL 一次、原 greedy 生成一次。原输入/生成 cap/全部参考/唯一 AnswerF1 口径不变；完整 NLL 不使用旧 TRAIN 的 512-token 答案截断，差别公开。总长超过原上下文即停止，不救截断。
- 诊断只覆盖 S1，不认证五域或全部预训练功能。该 65 组用于投入选择，不能再叫干净评测。

## 唯一恢复配方

- 逐组独立恢复，六组顺序固定。每组一次共同完整初始化；40 epochs，32 QA 固定 ID 顺序，每 QA 一次共同 optimizer update，合计每组 1280 步、六组 7680 步。每步同时评价该 QA 在组内四层的原缓存输入/输出，四层损失取平均；不改变组内顺序来逐层更新 U。
- 每层 normalized MSE：所有有效 token×hidden 元素的误差均值，除以该 QA/层原输出平方均值 `clamp_min(1e-8)`；四层等权。无 gold NLL/生成分数/诊断组反馈用于恢复。不进行整模型端到端恢复。
- U/V 为 FP32 master、原 CUDA FP16 autocast 前向，误差归约 FP32；父与最终诊断 FP16，数值路径公开。AdamW lr=2e-5、betas=(.9,.999)、eps=1e-8、weight_decay=.1；逐更新 cosine 到 1e-6；GradScaler init=1，clip=1。seed42，每组 optimizer/moments reset；不搜 LR/精度/阻尼。
- 初始不剪连接。GMP 每 50 次实际更新后更新一次，各 V 独立按幅值单调剪除，平局用 flat index；目标稀疏率 `0.75*(1-(1-min(t/960,1))**3)`；第 960 步强制最终 75%，之后固定到 1280。每步 mask 梯度、参数和 moments；不长回剪掉的位置。未被 mask 的实际有效更新、loss、LR、有限性和每次 mask 事件持久记录。
- 原作者代码只作已知算法依据，本配方含明确的联合 SwiGLU 目标和固定数据批量，不能声称逐项复现其默认。32 教师 QA、7680 group updates / 30720 cached-layer exposures、130 生成及130诊断 NLL分别计费；缓存教师前向也执行了32次回答 NLL，不能漏算。非完整87步持续学习，也不声称与旧方法同算量。

## 结束、唯一结果入口与去留

- 一次模型入口 STARTED→COMPLETE最多3600秒，包括加载、原父130次诊断、32次捕获、六组SVD和恢复、打包/基准包/最终包保存、最终重载和130次诊断及全部观察。源码准入、运输、唯一独立核验另外计费。
- 首次 STARTED 后失败、中断、超预算或非有限即关闭本固定点；保留原证据，不续 CP/延时/改配方/自动v2。仅实际STARTED/CUDA前资源变化可作为未尝试wait，不抢占他人或基线。
- 必须以最终物理包重载后进行全部压缩诊断；布局/计数/别名、实际权重和包SHA、原父与非FFN冻结不变性、输入/目标/生成token与停止、缓存/更新/剪枝/预算均完整后才唯一 verify，原 AnswerF1 仅一次。未完成不读 partial质量，不新 bootstrap，不重旧分数。
- 预定保守投入门：真实完整成本两门均过，压缩 S1 F1 ≥ 原父，压缩 S1 平均 gold NLL ≤ 原父；其它完整性/预算全通过。此零退步门是本次资源投入出口，不是人类容许掉分标准、非劣界、全领域保真或新方法成果。
- 通过只进入后续必要性评审；未过关闭此点，不按分数选择 rank/组/稀疏率/轮数/QA，亦不自动试其它载体。Ours/正式表/FWT/BWT不填，旧实验不恢复，研究目标仍未完成。
