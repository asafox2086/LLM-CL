# 本次对照与已有工作的重叠

本说明只约束论文解释，不修改已冻结实验、预算或候选。

- [AdaLoRA（ICLR 2023）](https://arxiv.org/abs/2303.10512)已经按重要性在权重矩阵间分配低秩更新预算；[ALoRA（NAACL 2024）](https://aclanthology.org/2024.naacl-long.35/)已研究裁剪、重分配rank。不能把“相同训练参数量可以有不同有效分配”称为新发现或新方法。
- [Zhou 等，Findings ACL 2024](https://aclanthology.org/2024.findings-acl.598/)已经系统研究多模态LLM中PEFT位置、参数量和数据规模；摘要还报告连接器微调的收益。它不证明当前原S1桥失败的唯一原因，也不授权事后追加桥训练。仅比较all与q/v本身不足以构成新的论文贡献。
- 本次需要检验的是已实际减少完整前向权重的固定载体，是否与极少数据下的有效更新分配相互依赖。若最终F1仍不保留，不能用既有参数分配技术或图权重节约来替代失败结论。若两表示下收益相似，也不能包装为压缩特有机制。
