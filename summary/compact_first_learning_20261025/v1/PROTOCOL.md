# 紧凑表示先行：有限预算学习是否必须发生在最终表示上

## 问题、证据与设计分叉

已有893675552系数wide-q/v父在1213 FIT/19阶段/87更新后宏F1 43.791987；语言在大视觉输入上学习后，再换为固定581213056小视觉图，宏降至38.966256，自然域61.5→29.166667。附加同图OCR能提高两图，但父子差距反而扩大，未证明词面补偿足以承接相对功能。这些结果尚未检验语言从一开始就在最终紧凑表示上学习。

本项唯一新假设：在固定少数据/更新预算下，有效适应需要在最终实际视觉表示上习得；先在大视觉学习再替换与先固定小视觉再学习可能不同。新臂从原始OneVision语言base出发，固定原小塔/原S1仿射桥，使用原wide-q/v精确初始化、样本顺序和87步。它不是接旧S19学生继续87步，不增加恢复步、rank、LR、桥容量或拟合数据。

阳性才支持把紧凑表示先行作为框架必要组件；阴性关闭这个固定载体/1%配方，不滚动解冻/加步/救桥。这是表示和有限适应的功能对照，不是已成新方法，不解释OSFT全部优势，也不将训练顺序本身宣称原创。

两子agent已接受科学必要性，并明确认可对旧“不训练救分”自设条款作这一个不同训练顺序问题的窄修订。旧事后替换的源、CP、质量失败和OCR通路终态保持，均不续跑。
