# 作者机制及小模型适配边界

所有方法统一 Qwen2-VL-2B、100训练／50测试／无验证、seed42、一轮、microbatch1／累积16。比较的是公开作者机制在同一小模型协议的适配，不冒称逐项复现原论文7B、原数据量或所有原超参。源版本与SHA锁定在 code/<method>/，CPU机制检查在 preflight/，正式训练前还需六类新任务GPU反向检查。无历史QA回放。

| 方法 | 保留的作者机制 | 本轮变化或限制 |
|---|---|---|
| SMoLoRA | 作者双路由与专家前向、rank128、8专家，首阶段门控训练后冻结 | 基座及统一样本预算；反向激活CPU卸载 |
| PASs-MoE | 作者路径激活子空间、路由与专家投影 | 基座及统一预算；优化器状态CPU保存；UTF-8显式写文件 |
| Hyper-LLaVA | 作者专家前向、Poincare几何、Bhattacharyya模态分离权重、top1路由 | 10个任务专家，每专家rank8；Qwen原生冻结视觉特征和MiniLM文本特征替代原CLIP。文本任务只用存在的模态，不能给它伪造图像；这属于公开跨模态适配 |
| OSFT | 作者完整SVD分解、低谱参数训练、正交梯度／参数投影，URR=.25 | 应用于Qwen decoder196个投影；每任务边界重新保护当前权重高谱；CPU优化器。约4.11亿可训练低谱参数，是较重参考，不称为轻量LoRA |
| SpaRTA | 作者原双rank前向（2/8）、上下文路由、每四层逐任务增长8组件、正交约束β10、随机恢复 | 10任务池；按作者默认project=0路由。每200update的恢复周期保留，本轮70update达不到首次触发，不降低周期假装触发；源码仍使用旧名DATA，论文正式名SpaRTA |
| ALER | 作者10步潜提示搜索（32候选、8提示、长度8）、原逆KL修复loss、前一阶段参考 | 全decoder FP32训练，视觉冻结，参考模型仅RAM；原搜索超参保留，CPU优化器／激活卸载。明显比适配器方法重，需单报成本 |
| PaRSP | 待完整核验归因、区域选择与旧子空间投影 | 作者Qwen代码面向纯文本模型，图像token与GQA区域及历史协方差的接口尚未核验，不用普通微调冒充 |
| FV-guided Training | 待完整核验函数向量干预及双KL／head正则 | 作者universal head列表依赖原Llama等基座的层／head索引，不能直接套用28层12头Qwen；需要作者因果head选取和真实多图ICL接口，禁止取模／随便截断索引 |

各方法学习率按适配器／作者设置记录到每次 config；训练轮数、样本数、累积batch等以用户统一小数据协议为准。函数向量、归因和模态统计只可使用各阶段训练池，不可通过测试集挑选head或阈值。adapter_pending 不会被调度器正式训练；通过CPU测试也不等于已通过GPU预检。
