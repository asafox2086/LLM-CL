## 1. 任务顺序：每领域先文本后图像

领域固定为自然/通用、医学、法律、金融、地理/遥感。OCR、图表和文档是任务形式，不单独算 Domain。按下表顺序执行，不在主实验中改序。

| 任务 | Domain | 模态 | 默认数据配对与使用方式 | 数据准备状态 |
|---|---|---|---|---|
| T1 | 自然/通用 | 文本 | SQuAD 1.1 非专业领域的阅读问答，去除医学、法律、金融和地理样本 | 拟补充，需锁定领域筛选 |
| T2 | 自然/通用 | 图像 | VQAv2 + GQA + TextVQA 的开放式子集，合为一个任务 | 已下载整理；待全局重划分 |
| T3 | 医学 | 文本 | MedQuAD 中公开可用的非空回答，疾病/症状/治疗等生成式问答 | 拟补充；不能把仓库总条数当可用回答数 |
| T4 | 医学 | 图像 | PathVQA + SLAKE + VQA-RAD 的开放式子集，合为一个任务 | 已下载整理；待全局重划分 |
| T5 | 法律 | 文本 | CUAD 中有真实条款证据的问答，生成条款文本，剔除 yes/no 与无答案问题 | 拟补充；属于合同法律，不代表全部司法推理 |
| T6 | 法律 | 图像 | SEC_Contracts_VQA，合同页图像 → 非布尔字段答案 | 已下载整理；自动标签质量需核查 |
| T7 | 金融 | 文本 | FinQA 的财报文本/表格 → 数值答案，保留推导与单位 | 拟补充 |
| T8 | 金融 | 图像 | TAT-DQA 原始财报页图像 → 自由答案，不能以纯文本 TAT-QA 替代 | 拟补充；图像与答案须实际核验 |
| T9 | 地理/遥感 | 文本 | 从 SQuAD 1.1 按文章与问题内容人工核验的地理问答子集 | 拟构建，非上游现成命名数据集 |
| T10 | 地理/遥感 | 图像 | GeoChat-Instruct 的图像问答/解释对话子集 | 拟补充；剔除场景分类、选择题、yes/no、纯框坐标输出 |

文本任务只输入文字或序列化表格；图像任务输入真实图像和问题。任务均生成自然语言或数值答案，不设分类头、不提供答案选项。T1/T9 的文章集合互斥，地理问答必须依赖地理内容，不能仅按文章标题把无关问题归为地理。

一个任务可以混合多个同领域数据集，因此仍是十任务，不把 T2 中三个数据集变成三个连续阶段。混合任务使用固定 shuffle，让各样本每 epoch 出现一次；数据集配比由实际样本量决定，另报子数据集成绩。

已下载的 ChartQA/DocVQA 不直接冒充金融域；先保留为辅助 OCR/文档评测资源。只有确认来源和问题属于金融的样本才可考虑补充 T8，不能按图表外观自动改领域。

来源：[SQuAD](https://rajpurkar.github.io/SQuAD-explorer/)、[MedQuAD](https://github.com/abachaa/MedQuAD)、[CUAD](https://www.atticusprojectai.org/cuad/)、[FinQA](https://github.com/czyssrs/FinQA)、[TAT-DQA](https://github.com/NExTplusplus/TAT-DQA)、[GeoChat](https://github.com/mbzuai-oryx/GeoChat)。TAT-DQA 是已有文档图像问答资源；GeoChat 官方混合集中含分类等任务，全部 318k instruction pairs 不能算本实验合格 QA 数。数据集年代不等于所收集持续学习论文年代，不声称这些新增数据均出自 2024–2026 的持续学习论文。

## 2. 数据划分与用量

全局分组约 80/10/10 train/dev/test，先分组，再创建十任务清单。使用全部经过核验的训练数据，不再限制每任务 1,000 条。新文本、金融图像与遥感数据尚未整理，暂不编造十任务总量或精确训练数。实际每任务问题数、独立来源组数、答案长度、过滤量均由 manifest 输出。

组身份与隔离规则：

- 文本按原始文章/文档分组，医学同来源疾病页面归组；T1/T9 同一文章不能重复出现。
- 图像按 SHA-256、来源图像身份及经复核的同源图像连接；VQAv2/GQA 的同图跨集连接。
- 医学有病例/患者 ID 时按病例/患者归组；缺失时只保证已知图像组隔离，不能声称患者隔离。
- 法律按公司/完整合同分组；金融按公司和财报来源分组，报告同公司/同报告不跨划分。
- 同一报告的文本与图像、同一合同的文本与图像跨模态也连接成一组。需要从 raw 回填来源映射；缺失身份单独报告。
- 遥感按原始地理位置/母图/航片归组，邻近裁块不跨划分。有可识别的空间覆盖时增加空间缓冲；缺少经纬度不能声称地理空间完全隔离。

训练组跨任务复用可以作为同一领域知识的跨模态迁移，但任何训练组都不能进入任何任务 dev/test。训练中只能读取当前任务 train 和方法允许的历史记忆；未来 train、所有 dev/test 不参与梯度、回放和伪样本生成。

固定 split seed 42，三个训练种子共享划分。领域筛选和人工核验不依据模型测试得分。开发集用于预检和预先规定的调参，测试集只用于锁定协议的评测；自建划分结果不宣称官方榜单成绩。

法律图像目前是合同字段抽取，标签由上游自动生成，需要字段分层人工核查；这项质量限制进入最终报告。医学小数据本身仍小，不能复制凑到大任务规模。

## 3. 同一个模型连续训练十任务

主模型 Qwen2-VL-2B-Instruct；文本阶段不给图像，图像阶段给真实视觉输入。每种方法从相同原始权重独立开始，十阶段继承自身 adapter 与方法记忆，不继承上一轮已训练 adapter。

冻结视觉编码器、merger 和语言基座；训练语言 q_proj/v_proj 的 LoRA，rank 8、alpha 32、dropout 0.1。AdamW，lr 1e-4，weight decay 0，clip 1.0；当前任务有效 batch 32，micro-batch 1，梯度累积。FP16 基座/视觉、FP32 adapter/优化器、AMP 和 gradient checkpointing。

每任务完整 1 epoch，当前样本曝光一次；阶段更新数 ceil(N_train/32)。阶段末使用最后更新 checkpoint；切换任务继承模型参数和方法状态，重置优化器动量与调度器，每阶段 3% warmup 后线性衰减。医学小任务 3 epochs 为独立消融。

文本与图像都使用官方 chat template，问题/上下文不计算答案 loss，只对答案与结束标记计算自回归交叉熵。纯文本 FinQA 的输入表格不得带答案推导结果；推导可作保存的参考，不在问题中泄漏答案。

单图计划视觉预算 512 merged tokens；常规上下文上限 2,048，长医学回答/合同/财报计划上限 4,096，长回答最大生成 512 token。不能把长答案默默截断后仍称完整监督。多页输入保留全部证据页；超过预算的文档整组移至长文档扩展并公布排除数。预算先在真实 train/dev 长样本上验证 11GB GPU 可运行，再锁定到所有方法。

冻结视觉特征可缓存，键包括图像、processor、模型版本及分辨率；不能复用上一轮 128-token 缓存充当 512-token 输入。训练种子 42/123/2026；模型分词器、提示、样本顺序和目标选择规则一致。

比较 SeqLoRA、ER-LoRA、MIGU-LoRA、O-LoRA、SAPT-LoRA，另设 Frozen/Joint-LoRA 参照。ER 最多保存 5,000 条已见历史训练 QA，每个更新额外回放 8 条，损失 `(L_current+0.25*L_replay)/1.25`；两个 loss 分别按本组均值计算，阶段 1 无回放。记忆按已学任务等额配额并保存固定优先级，不能重新扫描全部历史数据或读取未来数据。

报告回放/辅助生成额外 token、运行时间、参数增长和推理成本；不把相同当前样本曝光等同于完全相同计算量。方法若须真实 task ID，另列 oracle 结果，主评测不提供真实任务编号。

## 4. 评测全部十任务，计算全部四项 CL 指标

`R[i,j]`：完成第 i 个训练任务后，在第 j 个固定测试集的成绩。i=0 是原始基座，i=1..10 是十个阶段；j=1..10 是十任务。因此每种方法/种子共 11×10=110 个任务级评测单元。

阶段 0 评测全部十任务；每个阶段结束仍评测全部十任务，包括旧任务、当前任务和未来任务。提示、测试 ID 和生成规则固定。未来任务测试分数不用于提前训练或选择超参数。

为衔接上一轮，ROUGE-L（0–100）矩阵仍计算原定义的 AP/ForgetRate/FWT/BWT；再对共同 EM/Token F1 矩阵各计算同样指标。保留完整回答和全部参考。长医学回答与短答案的词面分不能当事实正确率，所以逐任务另报合适评分，不能只看一个宏平均。

最终 T=10 的定义：

```text
AP         = (1/10) * sum[j=1..10] R[10,j]
BWT        = (1/9)  * sum[j=1..9]  (R[10,j] - R[j,j])
ForgetRate = (1/9)  * sum[j=1..9]  (max[k=j..9] R[k,j] - R[10,j])
FWT        = (1/9)  * sum[j=2..10] (R[j-1,j] - R[0,j])
```

AP 越高越好，ForgetRate 越低越好，BWT/FWT 越高越好。ForgetRate 沿用旧定义：历史最好分减最终分，不除以历史分，不转成相对百分比，不强制截断负数。BWT/ForgetRate 不计最后任务；FWT 不计第一任务。差值的单位是分数点。

阶段 s 的已学 AP 为 mean(R[s,1..s])；同时画固定十任务平均 mean(R[s,1..10])，两者不混写。阶段 s≥2 的 BWT/ForgetRate 将最终阶段替换为 s、旧任务范围换成 1..s-1；累计 FWT 使用 j=2..s 的学前差，s<2 时留空，不能填零冒充测量值。

按领域汇报两个任务的平均；按模态分别汇报五个文本任务与五个图像任务。最终各领域都有两个任务，因此任务等权与领域等权的总体 AP 相同；中间阶段任务数不等时则分别计算。

逐任务补充评分：SQuAD/CUAD 的生成答案 EM/F1；MedQuAD ROUGE-L/词覆盖与人工医学正确性抽样；自然 VQA 保留参考频次的共识评分及 EM；医学 VQA EM/F1；FinQA/TAT-DQA 官方答案归一化与数值/单位正确性；SEC 字段 EM；遥感描述/关系问答 token overlap 加固定人工或冻结 judge 量表的事实正确性抽样。描述型答案不能只用 EM 判断正确。Judge 的版本、提示、盲评顺序和人类校准均固定，不让其反馈训练。

先给全量逐任务矩阵，再给 AP/ForgetRate/FWT/BWT、领域与模态曲线、即时收益/最终保留。三个训练种子报告均值/标准差；按文章/图像/公司/遥感母图组做 cluster bootstrap，不把同图多个问题当独立样本。
