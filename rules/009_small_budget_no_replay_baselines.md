# 十任务小预算实验：当前执行协议

> 当前执行以 [010 等量、单 seed 协议](010_equal_budget_execution.md) 为准：十任务均为 2000/100/200，只用 seed 42。本文件旧预算/状态是历史准备记录。

更新：2026-10-12。用户确认去掉回放类比较方法，其他方法保留作者原设置。本文件覆盖 006/008 的训练量和第一批方法选择；008 的源数据计数仍然有效。没有启动训练。

## 数据预算

保持五个领域各一个文本任务、一个图像任务，按 T1–T10 依次训练。每个任务训练最多 **3,000 条**，验证最多 **100 条**，测试最多 **200 条**；不足使用已有合格样本，不复制补齐。原始下载规模与实验使用规模分别记录，不需要重新下载或删改原始数据。

| 阶段 | 领域 / 模态 | 训练上限 | 验证上限 | 测试上限 | 使用前提 |
|---|---|---:|---:|---:|---|
| T1 | 自然 / 文本 | 3,000 | 100 | 200 | 官方 dev 的开发/测试角色须先明确且互不重叠 |
| T2 | 自然 / 图像 | 3,000 | 100 | 200 | 三个来源的配额、带标签评测集和跨集同图重叠须锁定 |
| T3 | 医学 / 文本 | 3,000 | 100 | 200 | 从已固定 MedQuAD train/dev/test 分别取样 |
| T4 | 医学 / 图像 | 3,000 | 100 | 200 | 三个来源的配额须记录；RAD 无官方 dev，不能借用 test 调参 |
| T5 | 法律 / 文本 | 3,000 | 100 | 200 | train 内按合同留开发集；官方 test 只供测试 |
| T6 | 法律 / 图像 | 3,000 | 100 | 200 | 输入与 QA 协议尚未锁定，上限不是已就绪数量 |
| T7 | 金融 / 文本 | 3,000 | 100 | 200 | 官方 train/dev/test 分别取样 |
| T8 | 金融 / 图像 | 3,000 | 100 | 200 | 官方 train/dev/test 分别取样 |
| T9 | 艺术 / 文本 | 3,000 | 100 | 200 | 独立文本输入协议尚未锁定 |
| T10 | 艺术 / 图像 | 3,000 | 100 | 200 | 图像资产及开放式任务核验尚未完成 |

这些是预算上限，不是已生成的十任务样本清单。先锁定输入协议、源划分及泄漏检查，再生成固定样本 ID manifest。采样 seed=42，各方法及训练随机种子共用同一份清单；训练随机种子不重新抽数据。仅改变实验选用的 ID，不改题目、答案、图像或标注。

多数据源任务在采样前明确每个来源的配额，不从拼接大池直接采样而让小来源消失。同一合同/图像/文档不能跨训练与评测集合；跨集重叠按来源和文档 ID 核查，不能仅凭问题 ID 不同认定无泄漏。需要从训练集留开发集时，记录为本项目开发划分，不能称为作者官方划分。

## 方法与训练

第一批适配 **DGG、PaRSP、SMoLoRA、PASs-MoE、Hyper-LLaVA**；对照为 SeqLoRA 与 Frozen。去掉 FOREVER 及其他回放类比较方法，已下载源码和论文索引保留。

“去掉回放类方法”不等于禁止所有历史样本：DGG 等非回放分类的方法若作者协议包含历史样本或辅助步骤，保留原设置，单独记录 buffer、历史样本曝光次数、额外 token、前向/反向次数与耗时。不能删掉核心步骤后仍声称完整原方法，也不能把这轮实验称作完全无回放。

当前任务每阶段一轮，最多 3,000 条新样本；十阶段每个方法每个训练种子最多 30,000 条当前任务样本曝光，不含作者方法的历史样本与辅助计算。使用同一 Qwen2-VL-2B-Instruct 起点，依次传递模型及方法状态。架构方法保留其专家和路由等核心模块，不能统一冻结其必要训练模块。

先做单种子的 train/dev 适配预检，测显存和耗时；通过后进行三个固定训练种子的正式比较。数据不足不做过采样，不因样本变少增加 epoch。源码下载状态与可运行状态分别记录，目前五个方法尚未完成十任务适配。

每个训练阶段必须保存独立的模型、优化器、调度器、混合精度、方法内部状态及随机状态，并记录该阶段全部十任务的评测结果。T1–T10 全部保留，阶段内另做周期性 last 保存。本轮日志和检查点放在 `exp/ten_task_cl_20261012/runs/<method>/seed_<seed>/<run_id>/`，报告放在 `summary/ten_task_cl_20261012/`。保存/恢复接口及详细目录见 [运行目录说明](../exp/ten_task_cl_20261012/README.md)；作者训练器接入与恢复核验是正式训练的前置条件。

## 评测预算与指标

训练前和每个阶段后仍评测 **全部十个任务**，形成 11×10 矩阵；“全部任务”不要求评测源数据的全部条目。每任务固定最多 200 条测试 QA，完整流程每个方法/种子最多 22,000 次测试 QA 生成。各方法使用相同测试 ID 和生成/评分规则，测试集不用于适配或选超参。

AP、ForgetRate、FWT、BWT 保留现有定义。ForgetRate 沿用现有分数差定义，不转换成百分比比值。200 条是快速比较预算，正式论文可在模型和配置冻结后对更大的固定测试集补充核验，并保持预算差异透明。
