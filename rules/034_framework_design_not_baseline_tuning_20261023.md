# 借鉴强基线设计新的紧凑持续学习框架

用户最新明确：“不是要你专门优化一个强基线，你只要借鉴、分析他的做法，然后提出全新的框架，让我们的开销很小，性能又不掉太多甚至超过。”本条与032/033共同优先于旧实验路线。

- 强基线用于分析有效功能、提供评价参照，不能将不断冻结OSFT、减少它的训练状态或给它加普通压缩步骤当作主方法设计完成。
- 主线是紧凑模型的表示、适应与持续学习机制共同设计；完整权重下降和原Answer F1是主指标。结构、算法新颖性须查原论文并由必要对照支持，不因组合已有模块或起新名字就宣称新框架。
- 小模型性能可保留或超过是待验证目标，不是承诺。“不掉太多”的可容许损失尚未由人类定量，不能自行宣布非劣或等效；报告完整规模—质量取舍。
- 普通物理FFN低秩替换加原q/v LoRA的factor_pilot_v1在仅CPU准入后、激活/STARTED前按方向修正关闭。原五源、CPU_GATE及READY保留，DIRECTION_CLOSED为终态；不activate、不将它自动当新主方法/科研收益，也不伪称质量阴性。
- 后续设计先明确功能替代假说、与已有共享/低秩/持续保护方法的差异、最少同规模对照、全部成本与正负出口。当前设计备忘录不是实验协议/READY，不自动启动新模型。旧PAS/ShortFixed及其它已结束条件不恢复，正式基线保全。
