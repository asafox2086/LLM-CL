## 采样与隔离规则

T1–T4、T7、T9–T10 直接逐字节冻结已经核验的 100/50 视图，不另抽一批。来源池、官方角色及各子数据集数量逐项保留在 `manifest.json`。多源任务仍按来源分层选样；100/50 指整个任务，不是每个子数据集。医学原官方 QA 划分可能共享图像，保持原角色且披露这一限制，不声称全部十任务都图像隔离。

T5 使用原始发布中的计数／人口单数值问答条件，实际合并池 175 条。seed42 打乱固定问题 ID，100 训练、50 测试、25 不使用；问题 ID 与完整问题文本跨角色无重叠。论文报告 143 计数＋28 人口，但未公布精确 ID，本发布条件实际得到 146＋32（交集3）；不强凑论文数量，也不冒称完全复现作者子集或官方划分。

T6 从 GeoChat 作者原始 instruction 混合数据保留开放计数／空间描述 QA，排除显式分类和 referring 标记。seed42 按不同原始图像选 150 张，每图只取一条原始 QA；100 训练、50 测试，图像路径／内容哈希跨角色无重叠。只在输入序列化时去掉结构性 `<image>` 标记及首尾空白，原完整对话另存于数据来源目录。

T8 限定作者 `image_style=PC`，图像类型 candlestick／indicator／statistic，问答能力限定开放描述、空间、数值、解释、建议及风险；排除文档、表格、OCR 和实体识别任务。153 条候选 QA 按底层图表目录分组，内容相同图像合并。seed42 打乱图表组，以整组精确分配100条训练，再从其余组抽50条测试（3条不使用）；训练25个图表组、测试22个图表组，图表及图像内容跨角色无重叠。150 是 QA 数，不是150张独立图表。

T5/T6/T8 都是本研究固定 holdout，**不是作者官方 train/test split**。原数据提出论文、实际使用论文、源码版本和限制见 [数据依据审计](../../DATASET_VERIFICATION_20261014.md)，生成脚本见 [prepare_geo_fin_revision.py](../prepare_geo_fin_revision.py)。

## 所有方法使用同一顺序

样本选定后，统一为第 s 阶段用 `random.Random(42+s).shuffle(range(100))` 生成一次训练 ID 顺序，写入 `training_order_seed42.json`。训练时读取这个文件，不受各方法初始化、路由或潜变量搜索消耗的 RNG 状态影响。方法额外归因／函数向量／路由统计只许使用当前100条训练池，不能读取测试标注；额外计算需记录，不能把辅助次数算作新增训练 QA。

20个 JSONL、manifest、split_lock 和训练顺序均设为0444。每次进程启动验证 manifest SHA、全部数据文件 SHA、各任务数量、训练顺序 SHA；不一致立即停止。各方法 config 和 split_identity 保存同一个 SHA，汇总器拒绝别的实验 ID 或不同划分。
